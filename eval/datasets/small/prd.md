# 需求 A：用户登录与权限（小型样例）

## 背景

内部管理系统需要账号体系，支持登录认证与基础角色区分。

## 功能需求

### FR-1 用户登录

用户使用用户名 + 密码登录；连续 5 次失败锁定 10 分钟；登录成功颁发 JWT（12 小时有效）。

验收标准：
- 正确账密返回 token 与用户信息
- 错误密码返回统一错误提示（不泄漏"用户不存在"）
- 第 5 次失败后返回 429 并提示剩余锁定时间

### FR-2 角色权限

角色分 ADMIN 与 MEMBER：ADMIN 可访问系统设置接口；MEMBER 访问返回 403。

验收标准：
- MEMBER 请求 ADMIN 接口返回 403 且无数据泄漏
