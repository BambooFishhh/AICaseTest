## 一、改动点

### 1.1 project store — 轮询时读取 progress + errorMessage

文件：`frontend/src/stores/project.js`

轮询回调中读取 project 的 progress 和 errorMessage：

```js
async startPolling(projectId, callback) {
  const poll = async () => {
    try {
      const res = await getProject(projectId)
      const project = res.data

      // v1.6: 实时更新进度信息
      if (project.progress) {
        this.progressMessage = project.progress
      }

      if (['completed', 'failed'].includes(project.status)) {
        // v1.6: 失败时传递 errorMessage
        callback(project.status, project.errorMessage)
        this.stopPolling()
      } else {
        this.timer = setTimeout(poll, 3000)
      }
    } catch {
      this.timer = setTimeout(poll, 3000)
    }
  }
  poll()
}
```

### 1.2 TestCaseList.vue — 展示进度和错误详情

文件：`frontend/src/views/TestCaseList.vue`

**进度展示（替换原 pollingMessage）：**

```html
<el-alert
  v-if="pollingMessage"
  :title="pollingMessage"
  type="info"
  :closable="false"
  show-icon
  class="polling-alert"
/>

<el-alert
  v-if="generationError"
  :title="`生成失败: ${generationError}`"
  type="error"
  :closable="false"
  show-icon
  class="polling-alert"
/>
```

**轮询回调改动：**

```js
projectStore.startPolling(projectId, async (status, errorMessage) => {
  pollingMessage.value = ''
  regenerating.value = false
  if (status === 'completed') {
    ElMessage.success('用例生成完成')
    page.value = 1
    await Promise.all([loadList(), loadAllForStats(), loadCoverageMatrix()])
  } else if (status === 'failed') {
    // v1.6: 展示错误详情
    generationError.value = errorMessage || '未知错误'
    ElMessage.error('用例生成失败')
  }
})
```

**新增状态：**

```js
const generationError = ref('')
```

**开始生成时清除上次错误：**

```js
generationError.value = ''
```
