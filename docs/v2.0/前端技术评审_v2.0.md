# 前端技术评审文档 v2.0 — Skill 工具层 + 执行数据模型

**版本**: v2.0（前端）
**基线**: v1.12
**日期**: 2026-08-09

---

## 一、改动点

### 1.1 新增 API 封装

文件：`api/execution.js`
```js
export function executeTestCase(projectId, caseId)
export function getExecution(eid)
export function getExecutions(projectId)
export function getExecutionSteps(eid)
```

### 1.2 TestCaseCard 新增"执行"按钮

文件：`components/TestCaseCard.vue`

在操作栏新增"执行"按钮，点击后调 `executeTestCase`，跳转到执行结果页。

### 1.3 新增 ExecutionResult.vue

文件：`views/ExecutionResult.vue`

展示：
- 执行概览：用例标题、状态（passed/failed）、耗时、步骤通过率
- 步骤列表：每步的 action、strategy、result、截图（前后对比）
- 失败步骤高亮 + 错误信息

### 1.4 新增路由

```js
{ path: '/projects/:id/executions/:eid', component: ExecutionResult }
```

### 1.5 文件变更清单

| 文件 | 类型 | 说明 |
|------|------|------|
| `api/execution.js` | 新建 | 执行 API 封装 |
| `views/ExecutionResult.vue` | 新建 | 执行结果展示页 |
| `components/TestCaseCard.vue` | 修改 | 新增"执行"按钮 |
| `router/index.js` | 修改 | 新增执行结果路由 |
