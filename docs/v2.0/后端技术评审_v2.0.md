### 1.2 Skill 工具 — BrowserSkill

文件：`skill/BrowserSkill.java`

```java
@Component
public class BrowserSkill {
    private Map<String, WebDriver> sessions = new ConcurrentHashMap<>();

    public String browserLaunch(boolean headless, int width, int height);
    public void browserNavigate(String sessionId, String url);
    public String takeScreenshot(String sessionId);  // 返回文件路径
    public void visualClick(String sessionId, int x, int y);
    public void domClick(String sessionId, String selectorType, String selectorValue);
    public Map<String, String> getPageStatus(String sessionId);
    public void closeSession(String sessionId);
}
```

### 1.4 执行数据模型

**ExecutionRecord.java**
```java
@Entity
public class ExecutionRecord {
    @Id private String id;
    private String projectId;
    private String testCaseId;
    private String testCaseTitle;
    private String status; // pending/running/passed/failed
    private LocalDateTime startTime;
    private LocalDateTime endTime;
    private String summary;
    private String errorMessage;
}
```

**ExecutionStep.java**
```java
@Entity
public class ExecutionStep {
    @Id private String id;
    private String executionId;
    private int stepIndex;
    private String action;
    private String target;
    private String strategy; // visual/dom/manual/skipped
    private String result;   // passed/failed/skipped
    private String screenshotBefore;
    private String screenshotAfter;
    private String coordinates;
    private String error;
}
```

### 1.5 ExecutionService — 程序化执行

```java
@Service
public class ExecutionService {
    public ExecutionRecord execute(String projectId, String testCaseId) {
        // 1. 创建 ExecutionRecord (status=running)
        // 2. 读取 TestCase.structuredSteps
        // 3. browser_launch
        // 4. 逐步骤执行：
        //    - ui_action → dom_click (v2.0 用 DOM, v2.1 接多模态)
        //    - state_assert → get_page_status
        //    - api_call → 跳过 (v2.1)
        //    - 每步骤: take_screenshot(前) → 执行 → take_screenshot(后) → 记录 ExecutionStep
        // 5. 汇总结果，更新 ExecutionRecord (status=passed/failed)
        // 6. save_test_evidence
    }
}
```
