# 前端技术评审 v5.9

**版本**: v5.9
**主题**: 项目上下文与操作体验优化（项目详情布局 + Cookie 配置 + PRD 面板改版）

> 评审版本：v5.9。一旦确定，尽量不要轻易改动。

## 一、变更点

### 1. API 封装

`frontend/src/api/project.js` 新增：

```js
export function getExecutionCookies(projectId) {
  return request.get(`/projects/${projectId}/execution-cookies`)
}

export function updateExecutionCookies(projectId, cookies) {
  return request.put(`/projects/${projectId}/execution-cookies`, { cookies })
}

export function getProjectContext(projectId) {
  return request.get(`/projects/${projectId}/context`)
}

export function updateProjectContext(projectId, payload) {
  return request.put(`/projects/${projectId}/context`, payload)
}
```

### 2. 项目详情页

- 操作区与只读提示从 PRD 下方移到 PRD 上方
- 新增"Cookie 配置"按钮与弹窗
- Cookie 弹窗复用创建页的表单结构：名称、值、域名/URL，支持添加/删除/保存

模板顺序：

```html
基本信息 → 操作区 → 只读提示 → 轮询状态 → PrdPanel
```

### 3. PRD 面板改版

`PrdPanel.vue`：

- 有 PRD 时默认折叠为摘要，点击"编辑 PRD"才展开编辑器
- 编辑器 `minRows: 4, maxRows: 10`
- 新增"额外 Prompt"文本域
- 新增"上下文文档"列表 + 新增/编辑/删除弹窗
- 数据源改为 `getProjectContext / updateProjectContext`，旧 PRD 接口保留兼容

数据流：

```text
PrdPanel onMounted
  → getProjectContext(projectId)
  → prdContent / extraPrompt / contextDocs
保存 PRD → updatePrd(projectId, content)
保存 Prompt/文档 → updateProjectContext(projectId, { extraPrompt, contextDocs })
```

## 二、props/emit 变化

- `PrdPanel`：props 不变，仍为 `{ projectId }`，无新增 emit
- `ProjectDetail`：无新增 props/emit

## 三、向后兼容性

- 旧项目无 `extraPrompt/contextDocs` 时前端显示空值
- 有 PRD 的老数据仍然可读，折叠摘要渲染沿用现有 marked + DOMPurify
- Cookie 为空时弹窗显示空列表

## 四、测试验证方案

- `scripts/verify-frontend.ps1`：npm run build 成功
- 手工验证：
  1. 项目详情首屏可见操作区，PRD 位于操作区下方
  2. 创建项目后打开 Cookie 配置，保存后刷新仍存在
  3. PRD 有内容时默认摘要，编辑后可保存
  4. 额外 Prompt 与多篇上下文文档可保存并重新加载
