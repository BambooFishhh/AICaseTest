# 后端技术评审 v5.9

**版本**: v5.9
**主题**: 项目上下文与操作体验优化（Cookie 可编辑 + 额外 Prompt/上下文文档 + 生成注入）

> 评审版本：v5.9。一旦确定，尽量不要轻易改动。

## 一、变更点

### 1. 执行 Cookie 读写

新增 `ProjectService.getExecutionCookies / updateExecutionCookies`：

```java
public List<Map<String, Object>> getExecutionCookies(String projectId) {
    projectAccessService.assertViewAccess(projectId);
    // 从 settings.executionCookies 解析
}

@Transactional
public List<Map<String, Object>> updateExecutionCookies(
        String projectId, List<Map<String, Object>> cookies) {
    projectAccessService.assertOperateAccess(projectId);
    // settings.set("executionCookies", valueToTree(cookies)); save
}
```

新增 Controller：

```java
@GetMapping("/{projectId}/execution-cookies")
@PutMapping("/{projectId}/execution-cookies")
```

### 2. 项目上下文聚合接口

新增 `ProjectService.getProjectContext / updateProjectContext`：

```java
public Map<String, Object> getProjectContext(String projectId) {
    // prdContent / prdSourceType / prdSourceRef / extraPrompt / contextDocs
}

@Transactional
public Map<String, Object> updateProjectContext(
        String projectId, Map<String, Object> payload) {
    // settings.extraPrompt / settings.contextDocs
}
```

Controller：

```java
@GetMapping("/{projectId}/context")
@PutMapping("/{projectId}/context")
```

数据存储沿用 `Project.settings` JSON：

```json
{
  "generationParams": {},
  "executionCookies": [],
  "extraPrompt": "请额外关注支付失败场景",
  "contextDocs": [
    { "id": "doc-1", "title": "接口文档", "content": "..." }
  ]
}
```

### 3. 生成链路注入

`PrdAnalysisResult` 新增字段：

```java
private String extraPrompt;
private List<Map<String, Object>> contextDocs;
```

`OrchestratorAgent.loadGenerationContext` 读取 settings 并赋值：

```java
prdResult.setExtraPrompt(extraPrompt);
prdResult.setContextDocs(contextDocs);
```

`TestGeneratorAgent.generateByLlmWithPrd` 注入 context：

```java
context.put("extraPrompt", prdResult.getExtraPrompt());
context.put("contextDocs", prdResult.getContextDocs());
```

## 三、API 契约变化

### 新增

| Method | Path | Body | 返回 |
|---|---|---|---|
| GET | `/api/projects/{id}/execution-cookies` | - | `{cookies:[...]}` |
| PUT | `/api/projects/{id}/execution-cookies` | `{cookies:[...]}` | `{cookies:[...]}` |
| GET | `/api/projects/{id}/context` | - | `{prdContent, prdSourceType, prdSourceRef, extraPrompt, contextDocs}` |
| PUT | `/api/projects/{id}/context` | `{extraPrompt, contextDocs}` | 同上 |

### 兼容性

- 旧 `GET/PUT /prd`、`/prd/upload`、`/prd/fetch` 保持可用
- 旧项目 `settings` 无新字段时返回空字符串/空数组
- 权限：读接口 VIEW，写接口 OPERATE/OWNER

## 四、测试验证方案

- `scripts/verify-backend.ps1`：mvn compile BUILD SUCCESS
- 手工验证：
  1. 创建项目 → 调用 PUT execution-cookies → GET 回读
  2. 调用 PUT context 保存额外 Prompt 和多篇文档 → GET 回读
  3. 触发生成，检查 LLM 上下文包含 extraPrompt/contextDocs
