# 前端技术评审 v4.1

**版本**：v4.1，一旦确定尽量不要轻易改动
**日期**：2026-08-12

## 变更点

### 1. 修改密码

- `api/auth.js` 新增 `changePassword`
- `App.vue` 用户菜单新增"修改密码"→ 弹窗（旧密码/新密码/确认，新密码规则同注册）

### 2. 注册密码规则

- `Register.vue` 校验与提示改为"8-64 位，包含字母和数字"

### 3. 批量评审

- `TestCaseList.vue` 移除评审人输入弹窗（后端取登录态），调用 `reviewTestCases(..., null)`

## 数据流

改密：弹窗 → changePassword → 成功提示；下次登录使用新密码。
