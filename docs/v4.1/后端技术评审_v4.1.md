# 后端技术评审 v4.1

**版本**：v4.1，一旦确定尽量不要轻易改动
**日期**：2026-08-12

## 变更点

### 1. 登录防爆破（LoginAttemptService）

内存计数（ConcurrentHashMap）：5 次失败锁定 5 分钟；成功清除计数。

```java
public void loginFailed(String username) { ... }
public void loginSucceeded(String username) { ... }
public void checkLocked(String username) { ... throws BusinessException(40104, 剩余时间) }
```

`AuthService.login`：先 checkLocked，失败 → loginFailed，成功 → loginSucceeded。

### 2. 密码策略与改密

- `RegisterRequest.password` 改为 `@Pattern("^(?=.*[A-Za-z])(?=.*\\d).{8,64}$")`
- 新增 `ChangePasswordRequest` + `POST /api/auth/change-password`（校验旧密码 → 新密码策略 → 更新）

### 3. CORS 收敛

- application.yml：`app.cors.allowed-origins`（默认 localhost:3000/5173/8080）
- WebConfig 读取配置白名单，替换 `allowedOriginPatterns("*")`

### 4. 审计

- `ExecutionRecord.operator`：执行启动时记录 `SecurityUtils.currentUsername()`
- `TestCaseService.batchUpdateReviewStatus`：评审人取登录态，忽略前端传参

### 5. 修复 v4.0 异步断言 bug

- 移除 `TestCaseService.runGenerate`（@Async）内的 `assertProjectAccess`——越权校验已在 `ProjectService.triggerGenerate` 同步调用中完成，异步线程无 SecurityContext 会误报 401
