## 一、变更点

### 1.1 api/project.js — generation-params 接口

```js
// v3.4: 获取生成参数
export function getGenerationParams(projectId) {
  return request.get(`/projects/${projectId}/generation-params`)
}

// v3.4: 更新生成参数
export function updateGenerationParams(projectId, params) {
  return request.put(`/projects/${projectId}/generation-params`, params)
}
```

**脚本**：

```js
import { getGenerationParams, updateGenerationParams } from '@/api/project'

const showGenParamsDialog = ref(false)
const savingParams = ref(false)
const genParams = ref({
  caseDensity: 'medium',
  temperature: 0.4,
  focusTypes: []
})

// 打开对话框时拉取当前参数
async function handleOpenGenParams() {
  showGenParamsDialog.value = true
  try {
    const res = await getGenerationParams(projectId)
    if (res.data) {
      genParams.value = { ...res.data }
      if (!genParams.value.focusTypes) genParams.value.focusTypes = []
    }
  } catch {
    // 拉取失败用默认值
  }
}

async function handleSaveGenParams() {
  savingParams.value = true
  try {
    await updateGenerationParams(projectId, genParams.value)
    ElMessage.success('生成参数已保存')
    showGenParamsDialog.value = false
  } catch {
    ElMessage.error('保存失败')
  } finally {
    savingParams.value = false
  }
}
```

## 三、数据流

```
用户点击"生成参数"
  → handleOpenGenParams: GET /generation-params
  → 对话框展示当前参数
  → 用户调整 caseDensity/temperature/focusTypes
  → 点击保存: PUT /generation-params
  → 后端写入 Project.settings JSON
  → 下次"重新生成"时 OrchestratorAgent 读取 params → 动态 prompt + temperature
```

## 四、向后兼容

- 旧项目 settings={} → GET 返回默认值，对话框显示 medium/0.4/[]
- focusTypes 为空时表示全部类型（后端不筛选）

## 五、测试验证

1. `npm run build` 构建通过
2. 打开参数对话框 → 显示当前参数
3. 调整参数 → 保存 → 重新打开确认已保存
4. 不选聚焦类型 → 保存成功（空数组）
5. 保存后重新生成 → 用例数量/多样性符合预期
