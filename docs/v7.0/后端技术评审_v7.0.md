### 1.2 worker 收尾前复查状态（防覆盖）

两处收尾（runAgentAsync L468、runAsync L767）在写终态前复查：

```java
ExecutionRecord finalRecord = executionRecordRepository.findById(executionId).orElse(null);
if (finalRecord != null) {
    // v7.0(E1): 已被取消的记录不被 worker 覆盖（取消可能发生在收尾前瞬间）
    if (!"cancelled".equals(finalRecord.getStatus())) {
        finalRecord.setStatus(status);
        finalRecord.setEndTime(LocalDateTime.now());
        finalRecord.setSummary(summary);
        finalRecord.setErrorMessage(errorMessage);
        finalRecord.setRecordingVideoPath(videoPath);
        executionRecordRepository.save(finalRecord);
    }
}
```

同时 worker 主循环结束后，若 DB 状态已是 cancelled 而本地 `cancelled=false`（用户在最后一步之后、收尾之前点取消），强制对齐：

```java
ExecutionRecord probe = executionRecordRepository.findById(executionId).orElse(null);
if (probe != null && "cancelled".equals(probe.getStatus())) cancelled = true;
```

（agentTask 终态调用已有 cancelled 分支处理。）

## 2. E2：调度器过滤执行任务

`HaTaskScheduler.dispatchQueuedTasks`：

```java
List<AgentTask> queued = agentTaskService.findQueued();
for (AgentTask task : queued) {
    // v7.0(E2): 执行任务由 executionExecutor 专属路径驱动，QUEUED→start 的窗口内
    // 被通用分发抢占会误标 NEEDS_REVIEW(UNSUPPORTED_RETRY)，跳过
    if (AgentTask.TYPE_EXECUTION.equals(task.getTaskType())) continue;
    dispatchQuietly(task.getId());
}
```

需要确认 AgentTask 常量名（TYPE_EXECUTION / type 字段名），以实际代码为准；若类型常量不存在则在 AgentTask 中补充。事件流消费路径（taskEventStreamService.consume）同样过滤。

## 3. E3：errorMessage 参与状态判定

两处收尾的状态判定改为：


## 4. E4：state_assert 最小诚实断言

`runAsync` 的 `case "state_assert"` 改为（新增私有方法 `assertExpected`，便于单测）：

```java
case "state_assert": {
    Map<String, String> status = playwrightSkill.getPageStatus(sessionId);
    String expected = node.path("expected").asText("");
    String verdict = assertExpected(expected, status);   // passed / failed / skipped
    stepBuilder.strategy("manual").result(verdict)
            .coordinates("url=" + status.get("url"));
    if ("skipped".equals(verdict)) {
        stepBuilder.error("UI 层暂无法验证: " + expected);
        skipped++;
    } else if ("failed".equals(verdict)) {
        stepBuilder.error("断言不匹配: 期望[" + expected + "] 实际[" + status.get("url") + " | " + status.get("title") + "]");
        failed++;
    } else passed++;
    break;
}
```
