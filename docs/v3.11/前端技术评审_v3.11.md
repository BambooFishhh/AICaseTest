## 变更点

### 1. 新增执行历史页（ExecutionHistory.vue）

- 路由 `/projects/:id/executions`（放在 `/executions/:eid` 之前注册）
- 数据：`getExecutions(projectId)`（api/execution.js 已存在）
- 页面结构（沿用 v4.0 重构后的 section 设计语言）：
  - `page-header`：返回 + 标题 + 刷新按钮
  - 统计卡：总计 / 通过 / 失败 / 运行中 / 通过率

- 跳转：`router.push('/projects/:id/executions/' + row.id)`；下载报告 `window.open('/api/executions/' + id + '/report')`

### 3. 覆盖率矩阵跳转修复（TestCaseList.vue）

```js
const idFilter = ref([])

const displayTestCases = computed(() => {
  let base = streaming.value
    ? (currentGenMode.value === 'append' ? [...streamedCases.value, ...testCases.value] : streamedCases.value)
    : testCases.value
  if (idFilter.value.length > 0) {
    base = base.filter((tc) => idFilter.value.includes(tc.id))
  }
  if (filters.priority) {
    base = base.filter((tc) => tc.priority === filters.priority)
  }
  return base
})

function handleFilterByIds(ids) {
  idFilter.value = ids || []
  filters.keyword = ''
}

function clearCoverageFilter() {
  idFilter.value = []
}
```

- 表格上方新增筛选横幅（命中 N 条 + 清除筛选）
- 移除旧的"keyword = ids[0] + handleFilter()"逻辑
