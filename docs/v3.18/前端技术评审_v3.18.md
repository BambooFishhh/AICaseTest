# 前端技术评审 v3.18

**版本**：v3.18，一旦确定尽量不要轻易改动
**日期**：2026-08-12

## 变更点（全部为前端）

### 1. App.vue

- `import pkg from '../package.json'` → 顶栏版本号 `v${pkg.version}`
- 深色主题开关：`html.dark` class + localStorage `aicase-theme`；onMounted 初始化
- 窄屏自动折叠：resize 监听 ≤1024px → `sidebarCollapsed = true`
- `router-view` 包裹 `transition name="fade-slide" mode="out-in"`

### 2. main.js / styles/index.scss

- main.js 引入 `element-plus/theme-chalk/dark/css-vars.css`
- index.scss 增加 `html.dark` 令牌覆盖（背景/卡片/文字/边框/滚动条）+ fade-slide 过渡类

### 3. TestCaseList.vue

- 列设置 Popover：类型/优先级/前置/步骤/预期/质量/执行/评审 显隐（localStorage `tcl-columns`）
- 表格密度开关（`size="small"`，localStorage `tcl-size`）
- filters 变化写入 localStorage `tcl-filters`，挂载时恢复
- 空状态：无用例时显示引导区（生成/导入 XMind/新增用例）
- 加载骨架屏：loading 且无数据时显示 el-skeleton 行

### 4. ExecutionResult.vue

- 失败步骤高亮（`.step-failed`）
- "仅显示失败"过滤开关

### 5. MindMapPreview.vue

- "导出 PNG"按钮：markmap SVG → canvas → 下载

## 向后兼容性

纯前端新增；默认值与原行为一致。
