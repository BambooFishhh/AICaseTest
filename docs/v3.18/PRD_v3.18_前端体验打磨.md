# PRD v3.18 — 前端体验打磨

**版本**：v3.18
**基线**：v3.17
**日期**：2026-08-12
**主题**：表格列设置/密度/筛选持久化 + 窄屏适配 + 骨架屏/过渡 + 空状态引导 + 步骤折叠 + 版本号动态化 + 深色主题 + 脑图导出 PNG

## 一、背景与痛点

1. 用例列表 9 列无法按需显隐、无密度切换；筛选条件刷新即丢
2. 窄屏（≤1024px）侧边栏占屏过大
3. 页面加载只有遮罩、无过渡动画
4. 空列表无操作引导
5. 执行步骤多时平铺过长、失败不突出
6. 顶栏版本号硬编码（v4.0），每次迭代要手改
7. 无深色主题；脑图无法导出 PNG

## 二、范围

### In scope

- 用例列表：列显隐设置 + 紧凑/舒适密度 + 筛选条件 localStorage 持久化
- 侧边栏窄屏自动折叠；路由切换过渡动画；加载骨架屏
- 用例列表/脑图等空状态操作引导
- 执行结果页：失败步骤高亮 + "仅显示失败"过滤
- 顶栏版本号从 package.json 动态读取
- 深色主题（跟随开关，localStorage 记忆）
- 脑图导出 PNG

### Out of scope

- 安全、并发、性能

## 三、验收标准

1. 列设置/密度/筛选刷新后保留
2. ≤1024px 侧边栏自动折叠；路由切换有过渡
3. 空列表有引导按钮；失败步骤高亮可过滤
4. 顶栏版本号与 package.json 一致
5. 深色主题可切换并记忆；脑图可导出 PNG
6. mvn test + npm run build 通过
