# 后端技术评审 v4.3

**版本**：v4.3，一旦确定尽量不要轻易改动
**日期**：2026-08-13

## 变更点

### 1. 实体与仓库

- `ProjectGroup`（id/name/description/ownerId/createdAt/updatedAt）+ `GroupMember`（id/groupId/userId/role：VIEWER|OPERATOR/createdAt）
- `ProjectRepository`/`GroupMemberRepository`/`ProjectGroupRepository`
- `Project.groupId`（可空，旧项目为空保持 owner-only）

### 2. 接口

- `GroupController`：`/api/groups` CRUD（owner 才能改/删）；`/api/groups/{id}/members` 列表/添加/改角色/移除（owner）
- `UserController`：`GET /api/users?keyword=` 成员候选列表（登录用户可见 id/username/displayName）
- `ProjectController`：create 支持 `groupId`
- `ExecutionController`：`POST /api/projects/{id}/testcases/copy-execute`（{caseIds,targetUrl,mode}）

### 3. 访问控制（ProjectAccessService）

```java
AccessLevel getAccessLevel(projectId)   // NONE/VIEWER/OPERATOR/OWNER
void assertViewAccess(projectId)
void assertOperateAccess(projectId)
```

- 读接口 → view；写/执行接口 → operate；创建者与 ADMIN 恒为 OWNER
- listProjects：返回"我是创建者或所在组成员"的项目，DTO 附 `accessLevel`

### 4. 复制执行隔离

- `ExecutionService.executeBatch(..., boolean writeBack)`；writeBack=false 时：
  - 不回写原用例 executionStatus（原用例状态完全不受影响）
  - 不做"已有 running 记录"幂等拦截（副本执行可重复）
- copy-execute 仅要求 VIEW 权限

## 测试验证
