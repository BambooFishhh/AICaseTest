# 前端技术评审 v4.3

**版本**：v4.3，一旦确定尽量不要轻易改动
**日期**：2026-08-13

## 变更点

### 1. 项目组管理页（Groups.vue）

- 路由 `/groups` + 侧边栏入口（图标 Connection）
- 列表：组名/成员数/我的角色；创建/重命名/删除（仅 owner）
- 成员管理对话框：添加成员（用户搜索）、角色切换 VIEWER/OPERATOR、移除

### 2. 项目归属与标识

- ProjectCreate 增加"所属项目组"下拉（可空）
- ProjectList 卡片显示组徽标；按 accessLevel 显示"只读"标记

### 3. 权限门控

- ProjectDetail / TestCaseList 根据 `project.accessLevel`：
  - VIEWER：隐藏/禁用 新增/编辑/删除/生成/分析/脑图/导出备份/批量执行，显示只读提示；保留 复制执行
  - OPERATOR/OWNER：全部可用
- 操作列"标记"对 VIEWER 隐藏

### 4. 复制执行

- TestCaseList 选中用例后工具栏出现"复制执行"：输入 URL/模式 → `copy-execute` → 跳转批次页
- 结果独立记录，不影响原用例状态

## 数据流

组管理：GroupService → members；项目：create 带 groupId；访问：ProjectDTO.accessLevel 驱动 UI 门控；复制执行：caseIds → copy-execute → batchId。
