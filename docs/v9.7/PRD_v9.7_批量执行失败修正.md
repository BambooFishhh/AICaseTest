# PRD v9.7：批量执行失败修正

> 版本：v9.7 ｜ 类型：稳定性修复 ｜ 基线：v9.6

## 一、背景与痛点

`b9d451db`（litemall 会员中心收藏足迹）最新批量执行 `batch-c6c8790679244e56`：**23 条用例，6 通过 / 17 失败**。失败步骤 27 个，根因分为四类：

1. **断言锚点问题（9 步）**：固定数量「浏览足迹 5」、虚构统计「专题收藏/订单数/商品收藏数/足迹数」、商品夹具「蔓越莓曲奇/￥36」与真实商品不符、页面换行导致「user123 欢迎回来」「0 待付款 1 待发货」字面锚点不命中。
2. **假选择器与不可达 UI（8 步）**：`.collect-icon`、`.footprint-item .checkbox` 不在真实 DOM 池；`text=删除选中` 在足迹列表为空时按钮不存在；LLM 仍生成「左滑」手势步骤（12.17 禁令漏守）。
3. **数据状态冲突（6 步）**：环境前置已登录，未登录用例仍以登录态执行；空收藏态用例实际有收藏；足迹 count=11 但 list 为空（孤儿足迹）；无效商品 ID（/goods/1、/goods/1008002）触发系统内部错误。
4. **Agent 点击未生效（2 步）**：收藏/足迹商品卡片的 visual_click 定位错误，页面未跳转。

## 二、范围

### In Scope

- 引擎层：断言空白归一；评审层手势步骤硬拒绝；enrich 对 LLM 自填选择器按当前路由真实池校验并剔除假选择器。
- 用例层：22 条用例按真实 UI 文案/选择器/有效商品 ID 修正；未登录用例自带退出登录准备步骤；删除/取消类用例走详情页可执行路径。
- 验证：后端全量测试、前端构建、批量重跑。

### Out of Scope

- 执行器浏览器内 API 调用能力（接口存在但 UI 不可达的端点仍由后续卡处理）。
- 共享用户并发数据污染的彻底治理（依赖 12.17 preDataSteps UI 编辑器或按用户隔离执行上下文）。
- 孤儿足迹数据清理脚本（当前通过用例前置步骤访问有效商品生成可见足迹规避）。

## 三、功能详情

### F1 引擎修复

- `ExecutionAssert`：页面文本与引号短语先折叠连续空白（换行/标签边界），再大小写不敏感比对；`'user123 欢迎回来'`、`'0 待付款 1 待发货'` 不再因换行误判。
- `ReviewQualityChecker.hasGestureViolation`：检测左滑/右滑/上滑/长按/swipe 步骤，`ruleReview` 直接拒绝该类用例，形成 12.17 后置兜底。
- `TestGeneratorAgent`：enrich 时对已有 `uiSelector` 按当前路由作用域内的真实选择器池校验，不在池内则剔除并尝试补真实选择器，避免 `.collect-icon` 类假选择器固化。

### F2 用例修正

- 聚合/用户中心：只断言真实文案（`待付款/待发货/待收货/待评价/我的收藏/浏览足迹/欢迎回来`），删除固定数字与虚构统计断言。
- 收藏：点击商品改用真实 `.collect-item`；取消收藏改为「商品详情页收藏按钮」路径；空状态用例先自清理收藏再断言 `暂无收藏/共 0 件收藏`。
- 足迹：用例先打开有效商品 `/goods/1006002` 生成足迹；勾选用 `.fp-item .van-checkbox`、删除选用 `text=删除选中`、全选用 `text=全选`；删除无真实 UI 语义的 TC-908。
- 商品/订单列表：使用真实商品名「轻奢纯棉刺绣水洗四件套」「￥899.00」与 `订单号：/合计` 断言。
- 未登录用例：先打开 `/user` 点「退出登录」清除环境注入的登录态，再访问目标页断言重定向。

## 四、验收标准

1. `ExecutionAssertTest` 新增换行/空白归一回归用例通过。
2. `TestGeneratorAgentSelectorScopeTest` 覆盖假选择器剔除并替换为真实池选择器。
3. `TestCaseReviewQualityTest` 覆盖手势步骤违规检测。
4. 后端 565/565 绿；前端 `npm run build` 通过。
5. 批量重跑后不再出现假选择器超时、固定夹具断言、未登录态被环境登录污染三类失败。

## 五、风险与规避

- 共享 user123 状态仍可能并发互踩：批量执行同项目并发上限为 3，用例自带准备步骤降低但无法完全消除偶发数据竞争。
- 足迹复选框不在分析器选择器池内，执行依赖 Agent 定位或手动 css；后续 12.16 提取规则需补充 van-checkbox 类。
