# 后端技术评审 v9.7

**版本**：v9.7（一经确定不再轻易改动） ｜ **主题**：批量执行失败修正

## 一、变更点

### 1. `ExecutionAssert`

新增 `normalizeSpace`：页面文本与引号短语折叠连续空白后再比较，保留 `N/X` 占位符大写形态供正则匹配。

```java
String pageText = normalizeSpace(title + " " + snippet).toLowerCase();
String q = normalizeSpace((String) qc[0]);       // 占位符规则需保留大写 N
haystack.contains(q.toLowerCase());              // 普通匹配再大小写不敏感
```

### 2. `ReviewQualityChecker` / `TestCaseReviewAgent`

`ReviewQualityChecker.hasGestureViolation` 检测步骤 action/target 中的左滑/右滑/上滑/长按/swipe；`ruleReview` 命中即拒绝并 WARN，形成生成 prompt 之后的第二道闸。

### 3. `TestGeneratorAgent`

`enrichStructuredSteps` 增加选择器真实性校验：

- 计算当前路由作用域内的真实选择器键集合（`type:value`）；
- LLM 已填的 css/text 选择器若不在集合中则剔除，并尝试用 `bestSelectorForRoute` 补真实选择器；
- route 型选择器不参与校验；路由未知时保守保留原选择器。
