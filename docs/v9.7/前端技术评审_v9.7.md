# 前端技术评审 v9.7

**版本**：v9.7（一经确定不再轻易改动） ｜ **主题**：批量执行失败修正

## 一、变更点

本版本为执行/生成链路修正，`frontend/src` 无源码变更：

- 断言空白归一、手势拒绝、选择器真实池校验均发生在后端执行/生成链路；
- 用例修正直接作用于 `test_cases` 数据。

## 二、props/emit 变化

无。

## 三、数据流

生成/编辑后的用例 → enrich 按路由池校验选择器 → 落库 → 执行器断言归一空白。前端展示与交互无变化。

## 四、向后兼容性

- 历史用例与前端行为不受影响。
- 执行结果中的断言描述更贴近真实页面换行文本，无前端协议变化。

## 五、测试验证方案

- `npm run build` 通过。
- 后端批量重跑作为端到端验证。
