## 一、改动点

### 1.1 TestCaseController 新增 DELETE 接口

文件：`backend/src/main/java/com/testagent/controller/TestCaseController.java`

```java
@DeleteMapping("/{testcaseId}")
public ApiResponse<Void> deleteTestCase(
        @PathVariable String projectId,
        @PathVariable String testcaseId) {
    testCaseService.deleteTestCase(projectId, testcaseId);
    return ApiResponse.success(null);
}
```

### 1.2 TestCaseService 新增 deleteTestCase

文件：`backend/src/main/java/com/testagent/service/TestCaseService.java`

```java
@Transactional
public void deleteTestCase(String projectId, String testcaseId) {
    TestCase tc = findTestCase(projectId, testcaseId);
    testCaseRepository.delete(tc);
}
```

复用已有 `findTestCase()` 方法定位用例，不存在时抛 `BusinessException.notFound`。

### 1.3 TestCaseService.listTestCases 新增 keyword 参数

文件：`backend/src/main/java/com/testagent/service/TestCaseService.java`

方法签名扩展：

```java
public TestCaseListResponse listTestCases(String projectId, int page, int pageSize,
        String type, String module, String keyword)
```

过滤逻辑新增（在 module 筛选之后）：

```java
if (keyword != null && !keyword.isBlank()) {
    String kw = keyword.toLowerCase();
    all = all.stream()
            .filter(tc -> (tc.getTitle() != null && tc.getTitle().toLowerCase().contains(kw))
                    || (tc.getModule() != null && tc.getModule().toLowerCase().contains(kw)))
            .collect(Collectors.toList());
}
```

### 1.4 TestCaseController.listTestCases 新增 keyword 参数

```java
@GetMapping
public ApiResponse<TestCaseListResponse> listTestCases(
        @PathVariable String projectId,
        @RequestParam(defaultValue = "1") int page,
        @RequestParam(defaultValue = "20") int pageSize,
        @RequestParam(required = false) String type,
        @RequestParam(required = false) String module,
        @RequestParam(required = false) String keyword) {
    return ApiResponse.success(
            testCaseService.listTestCases(projectId, page, pageSize, type, module, keyword));
}
```

### 1.5 UpdateTestCaseRequest 无需改动

v1.1 已新增 `structuredSteps` 字段，v1.3 前端编辑后直接提交即可，后端 update 逻辑已支持。

## 三、API 契约变更

### 3.1 新增端点

```
DELETE /api/projects/{projectId}/testcases/{testcaseId}   删除单个用例
```

响应：`ApiResponse<Void>`（success: true）

### 3.2 列表端点扩展

```
GET /api/projects/{projectId}/testcases?keyword=订单
```

新增 `keyword` 查询参数（可选），对标题和模块做模糊匹配。
