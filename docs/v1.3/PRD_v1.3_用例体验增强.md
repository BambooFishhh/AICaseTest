# PRD v1.3 — 用例体验增强

**版本**: v1.3（迭代版本）
**基线**: v1.2（用例生成质量增强）
**日期**: 2026-08-09
**迭代主题**: 提升用例日常使用体验——搜索、安全确认、结构化步骤可编辑、上下条导航

---

## 一、迭代背景

### 1.1 痛点分析

v1.2 已让用例"生成质量可度量"，但日常使用体验仍有明显短板：

| 编号 | 痛点 | 现状 | 影响 |
|------|------|------|------|
| P1 | 重新生成直接删除所有旧用例 | `handleRegenerate()` 无确认，直接覆盖 | 用户误点丢失全部人工修改 |
| P2 | 无法搜索用例 | 列表只能按 module/type/priority 筛选，无关键字搜索 | 用例多时找不到目标 |
| P3 | 结构化步骤不可编辑 | 编辑模式仅编辑旧 `steps` 字符串数组，structuredSteps 无法修改 | v1.1 结构化字段无法人工修正 |
| P4 | 详情无上下条导航 | 每次只能关闭对话框再点下一行 | 浏览大量用例效率低 |
| P5 | 无法删除单个用例 | 无删除接口 | 低质量用例无法手动清理 |

### 1.2 v1.3 目标

让用例的**查看、搜索、编辑、删除**体验达到日常可用的产品水平。

### 1.3 路线位置

```
v1.0 用例生成（自然语言）       ✅
v1.1 结构化可执行用例模型        ✅
v1.2 用例生成质量增强            ✅
v1.3 用例体验增强                ◀── 本次迭代
v1.4 生成质量增强II              （未来）
v1.5 可视化增强                  （未来）
v2.0 AI 用例执行引擎             （未来）
```

## 三、功能详述

### 3.1 重新生成确认提示（F1）

**现状**：点击"重新生成"直接调用 `triggerGenerate`，后端 `deleteAll` 清空旧用例。

**v1.3**：点击后弹出确认框：

```
即将重新生成测试用例，当前所有用例（含人工修改）将被覆盖删除。
确定要继续吗？
```

- 确认 → 继续生成
- 取消 → 不执行

### 3.2 用例关键字搜索（F2）

**现状**：列表仅支持 module/type/priority 下拉筛选。

**v1.3**：筛选区新增搜索输入框，支持标题和模块的模糊匹配（不区分大小写）。

**交互**：
- 输入关键字后回车或点击搜索按钮触发
- 支持与 module/type 筛选组合使用
- 后端新增 `keyword` 查询参数

### 3.3 结构化步骤可编辑（F3）

**现状**：编辑模式仅有 preconditions/steps/expectedResults 的文本数组编辑器。

**v1.3**：编辑模式新增"结构化步骤"编辑区块：

每个结构化步骤为一行表单：
- 序号（自动编号，只读）
- action（输入框）
- target（输入框，如 `POST /api/order/create`）
- expected（输入框）
- type（下拉：接口调用/界面操作/状态断言/人工）
- 删除按钮

底部"添加结构化步骤"按钮追加空步骤。

保存时：将编辑的结构化步骤通过 `UpdateTestCaseRequest.structuredSteps` 提交后端。

### 3.4 详情上下条导航（F4）

**现状**：打开用例详情对话框后，只能关闭再点下一行。

**v1.3**：对话框 footer 新增"上一条"/"下一条"按钮：
- 基于当前列表的 `testCases` 数组定位当前用例索引
- 到首条时"上一条"禁用，末条时"下一条"禁用
- 切换时不关闭对话框，直接更新 `currentTestCase`

### 3.5 单个用例删除（F5）

**现状**：无删除接口，用例只能通过重新生成被间接清空。

**v1.3**：
- 后端新增 `DELETE /api/projects/{projectId}/testcases/{testcaseId}` 接口
- 前端 TestCaseCard 对话框新增"删除"按钮（需二次确认）
- 删除后关闭对话框并刷新列表

## 四、验收标准

| 编号 | 验收项 | 验证方式 |
|------|--------|----------|
| AC1 | 点击重新生成弹出确认提示，取消不执行 | 操作验证 |
| AC2 | 搜索框输入关键字后列表按标题/模块模糊匹配 | 搜索验证 |
| AC3 | 编辑模式可增删改结构化步骤，保存后详情正确展示 | 编辑验证 |
| AC4 | 详情对话框可上一条/下一条导航，首末条按钮禁用 | 导航验证 |
| AC5 | 可删除单个用例，删除后列表刷新 | 删除验证 |
| AC6 | 后端编译通过，前端构建通过 | 构建 |
| AC7 | 旧用例（无 structuredSteps）编辑不报错 | 兼容验证 |

## 五、风险与对策

| 风险 | 对策 |
|------|------|
| 结构化步骤编辑数据格式错误 | 前端 type 下拉限制枚举值，提交前校验 |
| 搜索增加后端查询负担 | 数据量有限（百级），内存过滤足够 |
| 上下条导航与分页交互复杂 | 仅在当前页内导航，不跨页 |
