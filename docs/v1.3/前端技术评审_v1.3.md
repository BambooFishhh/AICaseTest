### 1.3 TestCaseList.vue — 上下条导航（F4）

详情对话框 footer 区域新增导航按钮。由于当前对话框在 TestCaseList 中管理，需在此组件实现：

```html
<el-dialog ...>
  <test-case-card ... />
  <template #footer>
    <div class="dialog-footer-nav">
      <el-button @click="handlePrev" :disabled="currentIndex <= 0">上一条</el-button>
      <el-button @click="handleNext" :disabled="currentIndex >= testCases.length - 1">下一条</el-button>
    </div>
  </template>
</el-dialog>
```

```js
const currentIndex = computed(() => {
  if (!currentTestCase.value) return -1
  return testCases.value.findIndex(tc => tc.id === currentTestCase.value.id)
})

function handlePrev() {
  if (currentIndex.value > 0) {
    currentTestCase.value = testCases.value[currentIndex.value - 1]
  }
}
function handleNext() {
  if (currentIndex.value < testCases.value.length - 1) {
    currentTestCase.value = testCases.value[currentIndex.value + 1]
  }
}
```

**限制**：仅当前页内导航，不跨页。如果到末条提示"已是当前页最后一条"。

#### 1.4.4 新增方法

```js
const addStructuredStep = () => {
  formData.structuredSteps.push({
    order: formData.structuredSteps.length + 1,
    action: '', target: '', expected: '', data: {}, type: 'api_call'
  })
}
const removeStructuredStep = (idx) => {
  formData.structuredSteps.splice(idx, 1)
  // 重新编号
  formData.structuredSteps.forEach((s, i) => { s.order = i + 1 })
}
```

### 1.5 TestCaseCard.vue — 删除按钮（F5）

对话框 footer 新增"删除"按钮（查看模式下）：

```html
<template v-if="!editMode">
  <el-button @click="handleClose">关闭</el-button>
  <el-button type="danger" :icon="Delete" @click="handleDelete">删除</el-button>
  <el-button v-if="editable" type="primary" :icon="EditPen" @click="enterEditMode">编辑</el-button>

```

**注意**：导航按钮放在 TestCaseCard 的 footer 中，通过 props 传入 `canGoPrev`/`canGoNext` 和 emit `prev`/`next` 事件。

#### 删除逻辑：

```js
const handleDelete = async () => {
  try {
    await ElMessageBox.confirm('确定要删除该用例吗？此操作不可撤销。', '确认删除', {
      confirmButtonText: '确定删除', cancelButtonText: '取消', type: 'warning'
    })
    emit('delete', props.testCase.id)
  } catch { /* 取消 */ }
}
```

TestCaseList 监听 `@delete` 事件，调用删除 API：

```js
async function handleDeleteTestCase(testcaseId) {
  await deleteTestCase(projectId, testcaseId)
  ElMessage.success('用例已删除')
  dialogVisible.value = false
  await Promise.all([loadList(), loadAllForStats()])
}
```

## 三、数据流

```
搜索：filters.keyword → loadList() params.keyword → 后端 → 过滤后返回
导航：TestCaseList handlePrev/Next → currentTestCase 更新 → TestCaseCard props.testCase 更新
编辑：TestCaseCard formData.structuredSteps → handleSave emit('save') → TestCaseList handleSaveTestCase → PUT API
删除：TestCaseCard emit('delete') → TestCaseList handleDeleteTestCase → DELETE API → 刷新列表
```
