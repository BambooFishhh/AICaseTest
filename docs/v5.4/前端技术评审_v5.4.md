# 前端技术评审 v5.4：Milvus 语义检索层

> 版本 v5.4，一旦确定尽量不要轻易改动。

## 1. 变更点

- `api/testcase.js` 新增 `semanticSearch(projectId, q)`。
- `TestCaseList.vue` 新增"语义搜索"按钮与对话框：
  - 输入自然语言 → 调用语义搜索 API
  - 结果表格展示编号/标题/模块/类型
  - 点击"查看"打开用例详情

## 2. 数据流

```text
语义搜索按钮
  └─ semanticSearch(projectId, q)
        └─ GET /testcases/semantic-search?q=
              └─ 结果表 → 查看 → 用例详情对话框
```

## 3. 向后兼容性

- 新增按钮与对话框为增量功能，不影响列表、筛选、批量操作。
- Milvus 未启用时后端返回空结果，前端展示"暂无结果"。

## 4. 测试验证方案

- `npm run build`。
- 语义搜索对话框：空输入提示、有结果展示、无结果空状态、查看跳转详情。
