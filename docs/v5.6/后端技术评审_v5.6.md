# 后端技术评审 v5.6：数据一致性与生命周期

> 版本 v5.6，一旦确定尽量不要轻易改动。

## 1. 变更点

### 1.1 事务落库

```java
@Service
public class TestCasePersistenceService {
    @Transactional
    public List<TestCase> replaceAll(String projectId, List<TestCase> cases) {
        testCaseVersionRepository.deleteByProjectId(projectId);
        testCaseRepository.deleteAll(testCaseRepository.findByProjectId(projectId));
        for (TestCase tc : cases) {
            tc.setProjectId(projectId);
            testCaseRepository.save(tc);
        }
        return cases;
    }
}
```

### 1.2 Milvus 删除能力

- `deleteByIds(collection, projectId, ids)`：`project_id == "x" and id in [...]`
- `deleteByModule(collection, projectId, module)`：`project_id == "x" and module == "prd"`

### 1.3 生命周期接入

- `ProjectService.deleteProject` 级联删除并清理语义。
- `TestCaseService` 增删改/导入/复制同步索引。
- `ProjectService` / `AnalysisService` 上下文改为 replace。
