# 前端技术评审 v6.7

> 版本 v6.7，一旦确定尽量不要轻易改动。主题：任务中心与退化可视化。

## 1. 变更点

- `api/task.js` 新增 `listTasks/getTask/retryTask`。
- 新增 `views/TaskCenter.vue`：
  - 任务类型/状态/项目 ID 筛选；
  - 分页表格：类型、状态、阶段、尝试次数、降级、项目、创建时间；
  - 详情抽屉：error/lease/checkpoint 等；
  - FAILED/DLQ/NEEDS_REVIEW 重试按钮。
- 路由 `/tasks`（`meta.admin=true`），侧边栏"任务中心"仅 ADMIN 展示。

## 2. props / emit 变化

无公共组件 props/emit 变化；TaskCenter 为独立页面。

## 3. 数据流

- 页面调用 `/api/admin/tasks`；重试后刷新当前列表并重载详情。
- axios 拦截器自动携带 Bearer；401 跳登录，403 提示拒绝访问。

## 4. 向后兼容性

- 既有 `/api/tasks/stats` 不变。
- 非 ADMIN 用户不显示入口，直接访问由后端 403 兜底。

## 5. 测试验证方案

- `npm test` / `npm run build` 通过。
- 管理员手工验证筛选/详情/重试；普通用户访问 `/tasks` 修复后显示"拒绝访问"。
