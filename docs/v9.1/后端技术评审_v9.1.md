# 后端技术评审 v9.1 — 生成与 SSE 解耦

> 版本 v9.1，一旦确定尽量不要轻易改动。基线 v9.0。

## 一、变更点

### 1.1 生命周期解耦（TestCaseService）

- **删除 v8.9.8 宽限机制**（`app.sse.reconnect-grace-seconds` 相关路径）：SSE 断连仅从广播器订阅者列表摘除连接，生成任务照常执行到终态；
- **广播器结构**：生成会话持有 `bc.subscribers`（活跃 SseEmitter 列表），`send` 循环对单个失败连接 catch + 移除，多订阅者互不影响；客户端主动断开由容器回调清理。

### 1.2 事件持久化（AgentTaskService）

- `recordGenerationEvent(taskId, phase, status, payloadJson)`：progress/case 事件逐条落 `agent_task_events`（复用 v6.5 任务表，不新建表）；
- 生成链路在广播同时落库：progress 更新（phase=progress）与每条用例草稿（phase=case）。

### 1.3 attach 端点（ProjectController）

```java
@GetMapping("/{projectId}/testcases/generate-stream-attach")
public SseEmitter generateStreamAttach(@PathVariable String projectId)
```

- 三分支路由（GenerationReattachTest 覆盖）：
  1. RUNNING + 本实例广播器在 → `bc.subscribers.add(emitter)` 续播实况，不查 DB timeline；
  2. 终态（SUCCEEDED/FAILED/CANCELLED）或无任务 → 一次性回放 `agentTaskService.timeline(taskId)` 中的 progress+case 事件，按终态 complete；
  3. 他实例（无本地任务）→ 同 2（依赖 agent_task_events 落库跨实例可读）；
- SseTicket 白名单按 URI 含 "generate-stream" 匹配，attach 无需新增票据配置。

## 二、文件变更清单

service/TestCaseService.java（+215/-x）、service/AgentTaskService.java（recordGenerationEvent/latestGenerationTask）、controller/ProjectController.java（+13）；test/service/GenerationReattachTest.java 新增（6 例）。

## 三、API 契约变化

- 新增 `GET /api/projects/{projectId}/testcases/generate-stream-attach`（SSE，事件名与 generate-stream 一致：progress/case/complete/error）。

## 四、验证结果

- GenerationReattachTest 6 例绿；全量 542/542 绿。
- 实测：litemall 生成中刷新页面 → attach 回放历史事件并续播，终态整表重载；生成不再因断连被取消。
