# 前端技术评审 v5.7：数据索引与查询性能

> 版本 v5.7，一旦确定尽量不要轻易改动。

## 1. 变更点

- `ExecutionHistory.vue` 适配新响应结构：`items / total / page / pageSize / stats / trend`。
- 表格增加 `el-pagination`，切换页重新拉取。
- 统计卡改用后端 `stats`，趋势图改用后端 `trend`。

## 2. 数据流

```text
loadExecutions({page, pageSize})
  └─ GET /executions?page=&pageSize=
        └─ items → 表格；stats → 统计卡；trend → 趋势图；total → 分页器
```

## 3. 向后兼容性

- 页面交互不变，仅数据来源与分页结构升级。

## 4. 测试验证方案

- `npm run build`。
- 多页数据切换分页，统计卡/趋势图保持全量口径。
