# 前端技术评审 v4.0

**版本**：v4.0，一旦确定尽量不要轻易改动
**日期**：2026-08-12

## 变更点

### 1. 认证基础设施

- `api/auth.js`：register/login/me
- `stores/auth.js`（Pinia）：token/user + localStorage（aicase-token/aicase-user）；login/register/logout/fetchMe
- `api/request.js`：请求拦截器附加 Bearer；响应 401 → 清 token 跳 `/login`

### 2. 登录/注册页

- `views/Login.vue`、`views/Register.vue`：居中卡片，成功后跳 `redirect` 参数或 `/projects`

### 3. 路由与守卫

- `router/index.js`：新增 `/login`、`/register`（meta.public）；`beforeEach`：未登录 → `/login?redirect=...`；已登录访问登录页 → `/projects`

### 4. 用户菜单与角色

- `App.vue` 顶栏用户菜单（头像/用户名/退出登录）
- 侧边栏仪表盘/系统设置仅 `role === 'ADMIN'` 显示

## 数据流

登录 → token 存 localStorage → axios 自动带 token → 401 时清 token 跳登录。

## 向后兼容性

破坏性变更：所有业务请求需登录态；未登录一律跳登录页。
