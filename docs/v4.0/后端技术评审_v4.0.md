# 后端技术评审 v4.0

**版本**：v4.0，一旦确定尽量不要轻易改动
**日期**：2026-08-12

## 变更点

### 1. 依赖与配置

- pom：`spring-boot-starter-security`、`jjwt-api/impl/jackson 0.11.5`
- application.yml：`app.jwt.secret`（默认开发密钥）、`app.jwt.expiration-hours: 12`、`app.admin.password`（默认 admin123）

### 2. 用户与认证

- `entity/User`、`repository/UserRepository`（findByUsername/existsByUsername）
- `dto/RegisterRequest/LoginRequest/UserDTO`
- `security/JwtUtil`：HS256 签发/解析，subject=username，claim role
- `security/JwtAuthFilter`：OncePerRequestFilter，Bearer → SecurityContext
- `security/SecurityConfig`：SecurityFilterChain，BCryptPasswordEncoder；放行 `/api/auth/**`、`/api/health`、`/swagger-ui/**`、`/v3/api-docs/**`、`/h2-console/**`；`/api/settings/**`、`/api/stats/**` hasRole(ADMIN)；其余 authenticated；stateless，禁用 CSRF
- `service/AuthService` + `controller/AuthController`：register/login/me

### 3. 数据归属

- `Project.userId`；`ProjectDTO` 透传 userId
- `security/SecurityUtils`：currentUsername/isAdmin
- `service/ProjectAccessService.assertProjectAccess(projectId)`：ADMIN 放行；否则校验 owner
- 接入点：ProjectService（get/delete/analyze/generate/prd/params/environments）、TestCaseService（全部项目级方法）、ExecutionService（execute/batch/history/get/batch status）、MindMapService、AnalysisController、CoverageController、TestSuiteService、BackupService

### 4. 初始化与迁移

- `config/DataInitializer`（CommandLineRunner）：无用户 → 创建 admin；存量项目 userId 为空 → 归 admin

- 新增 `/api/auth/register|login|me`
- 除放行路径外，所有接口需 `Authorization: Bearer <token>`
- ProjectDTO 新增 userId
