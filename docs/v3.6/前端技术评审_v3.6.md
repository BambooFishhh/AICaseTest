# 前端技术评审 v3.6 — 用例列表体验优化

## 一、变更点

### 1. 修复追加生成闪烁 (TestCaseList.vue)

**现状**：`displayTestCases` 在 `streaming=true` 时仅返回 `streamedCases`，已有用例消失。

**修改**：追加模式下合并展示。

```javascript
// 修改前
const displayTestCases = computed(() => {
  if (streaming.value) {
    if (!filters.priority) return streamedCases.value
    return streamedCases.value.filter((tc) => tc.priority === filters.priority)
  }
  if (!filters.priority) return testCases.value
  return testCases.value.filter((tc) => tc.priority === filters.priority)
})

// 修改后
const displayTestCases = computed(() => {
  if (streaming.value) {
    // v3.6: 追加模式合并已有用例 + 新用例；重新生成模式仅展示新用例
    const base = currentGenMode.value === 'append'
      ? [...streamedCases.value, ...testCases.value]
      : streamedCases.value
    if (!filters.priority) return base
    return base.filter((tc) => tc.priority === filters.priority)
  }
  if (!filters.priority) return testCases.value
  return testCases.value.filter((tc) => tc.priority === filters.priority)
})
```

### 3. 手动添加用例 (TestCaseList.vue + TestCaseCard.vue)

#### 3.1 TestCaseList.vue 新增按钮和创建逻辑

工具栏新增"新增用例"按钮：
```html
<el-button type="success" :icon="Plus" @click="handleCreateTestCase">新增用例</el-button>
```

创建逻辑：
```javascript
const createMode = ref(false)
const createDialogVisible = ref(false)

function handleCreateTestCase() {
  createMode.value = true
  createDialogVisible.value = true
}

async function handleSaveNewTestCase(data) {
  const res = await createTestCase(projectId, data)
  ElMessage.success('用例创建成功')
  createDialogVisible.value = false
  createMode.value = false
  await Promise.all([loadList(), loadAllForStats(), loadCoverageMatrix()])
}
```

#### 3.2 TestCaseCard.vue 支持创建模式

新增 `mode` prop：
```javascript
const props = defineProps({
  testCase: { type: Object, default: () => ({}) },
  editable: { type: Boolean, default: false },
  visible: { type: Boolean, default: false },
  canGoPrev: { type: Boolean, default: false },
  canGoNext: { type: Boolean, default: false },
  mode: { type: String, default: 'view' }  // v3.6: 'view' | 'create'
})
```

创建模式下：
- `editMode` 初始为 `true`
- `dialogTitle` 显示"新增用例"
- `formData` 初始化为空
- 保存时 emit `create` 事件（而非 `save`）
- 隐藏"删除"、"历史版本"、"执行"、"上一条/下一条"按钮

#### 3.3 testcase.js 新增 API

```javascript
export function createTestCase(projectId, data) {
  return request.post(`/projects/${projectId}/testcases`, data)
}
```

## 三、数据流

### 创建用例流程
```
用户点击"新增用例"
  → TestCaseList 打开 TestCaseCard (mode='create')
  → TestCaseCard 初始化空表单 + editMode=true
  → 用户填写后点击保存
  → TestCaseCard emit('create', formData)
  → TestCaseList 调用 createTestCase(projectId, data)
  → 后端 POST /api/projects/{projectId}/testcases
  → 返回新用例（含 TC 编号）
  → 前端刷新列表
```

## 四、向后兼容

- `mode` prop 默认 'view'，不影响现有查看/编辑行为
- 现有 `save` emit 不变，新增 `create` emit
