## 二、BrowserSkill 截图标注

### 2.1 新增方法
```java
/**
 * v2.5: 截图并标注点击位置。
 * @param sessionId 浏览器会话 ID
 * @param clickX 点击 X 坐标（0 表示不标注）
 * @param clickY 点击 Y 坐标（0 表示不标注）
 * @return 截图文件路径
 */
public String takeScreenshotWithMarker(String sessionId, int clickX, int clickY) {
    String path = takeScreenshot(sessionId);  // 先截原图
    if (clickX > 0 && clickY > 0) {
        annotateScreenshot(path, clickX, clickY);
    }
    return path;
}

private void annotateScreenshot(String imagePath, int x, int y) {
    BufferedImage image = ImageIO.read(new File(imagePath));
    Graphics2D g = image.createGraphics();
    // 红色圆圈
    g.setColor(Color.RED);
    g.setStroke(new BasicStroke(3));
    g.drawOval(x - 20, y - 20, 40, 40);
    // 十字准星
    g.drawLine(x - 30, y, x + 30, y);
    g.drawLine(x, y - 30, x, y + 30);
    // 坐标文本
    g.setFont(new Font("Arial", Font.BOLD, 14));
    g.drawString("click: (" + x + ", " + y + ")", x + 25, y - 25);
    g.dispose();
    ImageIO.write(image, "png", new File(imagePath));
}
```

需要添加 import:
- java.awt.Color
- java.awt.Font
- java.awt.Graphics2D
- java.awt.image.BufferedImage
- java.io.File
- javax.imageio.ImageIO

## 三、ExecutionService 集成

### 3.1 步骤截图改用带标注版本
在执行每步操作后：
```java
// v2.4: screenshotAfter = browserSkill.takeScreenshot(sessionId)
// v2.5: 
String screenshotAfter = browserSkill.takeScreenshotWithMarker(
    sessionId, step.getClickX(), step.getClickY());
```

### 3.2 录屏帧合并步骤截图
在每步执行后，将步骤截图加入 recordingFrames：
```java
// 每步执行后
if (screenshotAfter != null) {
    stepRecordingFrames.add(screenshotAfter);
}
```
在执行结束时：
```java
// 合并周期截图 + 步骤截图
List<String> allFrames = browserSkill.stopRecording();  // 周期截图
allFrames.addAll(stepRecordingFrames);                   // 步骤截图
record.setRecordingFrames(objectMapper.writeValueAsString(allFrames));
```
