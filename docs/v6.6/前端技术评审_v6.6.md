# 前端技术评审 v6.6

> 版本 v6.6，一旦确定尽量不要轻易改动。主题：高可用 P1 - 执行接入与工具超时。

## 1. 变更点

- 本版本无前端源码变更。
- 后端新增任务/工具 Prometheus 指标与执行任务状态机，不改变现有 REST 响应契约。
- `/api/tasks/stats` 继续返回 `agentTasks` 状态计数，前端无需改动。

## 2. props / emit 变化

无。

## 3. 数据流

- 执行接口返回 executionId 不变。
- 任务状态由后端 `agent_task` 持久化，前端仍通过执行记录/批次状态接口获取结果。
- 新增指标仅供 Prometheus/Grafana 使用。

## 4. 向后兼容性

- 所有既有接口字段不变。
- 无新增前端依赖，构建产物不变。

## 5. 测试验证方案

- `npm run build` 回归通过。
- 有权限时手工验证执行任务在 `/api/admin/tasks?taskType=execution` 中可见。
