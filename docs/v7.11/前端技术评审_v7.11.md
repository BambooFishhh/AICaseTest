> 结论：**本版无前端代码变更**，仅回归构建验证。

## 1. 变更影响分析

| 后端变更 | 前端感知 | 是否需要改动 |
|---|---|---|
| L14 流式错误处理 | 流式生成的 error 事件从"误报取消"变为真实错误消息——错误提示更准确 | 否（消息透传展示） |
| T1/T2 用例全局唯一编号 | 用例 ID 从"项目内 TC-001 连续"变为"全局唯一递增"（项目间起始号不同） | 否（前端按 id 字符串透传，无解析/排序依赖编号连续性；列表按 createdAt/序号列展示） |
| E12 Playwright 多会话 | 并发执行的截图/视频不再串台 | 否（路径展示不变） |
| G21/T3/E13/E14 | 后端内部行为 | 否 |

确认项：
- 用例列表/详情/执行记录页对 `testCase.id` 均为字符串透传（路由参数、关联展示），无 `parseInt(id)` 或按编号连续性分页的逻辑；
- XMind 导入解析出的旧编号仅作标题前缀展示参考，落库 ID 由后端统一分配。
