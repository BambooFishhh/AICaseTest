# 后端技术评审 v2.6 — MCP Client 多 Server 架构

> 版本：v2.6 | 主题：MCP Client 多 Server 架构 | 基线：v2.5
> 一旦确定尽量不要轻易改动

## 一、改动概述

将单例 `McpClient` 重构为 `McpClientManager` + `McpConnection` 两层架构，支持同时管理多个 MCP Server 连接，为 v2.7 接入 Playwright MCP 做基础设施准备。

## 二、变更点详解

### 2.1 新建 McpConnection — 单 Server 连接封装

从现有 `McpClient` 中抽取连接级逻辑，封装单个 MCP Server 的进程管理 + JSON-RPC 通信。

```java
package com.testagent.mcp;

/**
 * v2.6: 单个 MCP Server 连接封装。
 * 管理 Process + stdin/stdout + JSON-RPC 2.0 通信。
 * 不是 Spring Bean，由 McpClientManager 创建和管理。
 */
public class McpConnection {

    private final String name;           // Server 名称（如 "llm"、"playwright"）
    private final String nodePath;       // Node.js 可执行路径
    private final String scriptPath;     // MCP Server 脚本路径
    private final List<String> extraArgs; // 额外 CLI 参数（如 --headless）
    private final Map<String, String> env; // 环境变量

    private Process process;
    private BufferedWriter stdin;
    private BufferedReader stdout;
    private volatile boolean initialized = false;
    private final AtomicInteger requestId = new AtomicInteger(0);

    /**
     * 启动子进程 + MCP 握手。
     */
    public void start() {
        ProcessBuilder pb = new ProcessBuilder(buildCommand());
        pb.redirectErrorStream(false);
        pb.environment().putAll(env);
        process = pb.start();
        stdin = new BufferedWriter(new OutputStreamWriter(process.getOutputStream()));
        stdout = new BufferedReader(new InputStreamReader(process.getInputStream()));
        initialize();  // MCP initialize 握手
    }

    /**
     * 调用工具（synchronized 防止 stdio 并发乱序）。
     */
    public synchronized String callTool(String toolName, Map<String, Object> args) throws Exception {
        if (!initialized || process == null || !process.isAlive()) {
            start();  // 尝试重启
            if (!initialized) throw new IllegalStateException("MCP Server [" + name + "] 未启动");
        }
        // ... JSON-RPC tools/call 请求（逻辑同原 McpClient.callTool）
    }

    public boolean isAvailable() {
        return initialized && process != null && process.isAlive();
    }

    public void stop() {
        initialized = false;
        if (process != null && process.isAlive()) {
            process.destroyForcibly();
        }
    }
}
```

**关键设计**：
- `synchronized callTool`：同一 Server 的调用串行化，防止 stdio 读写乱序
- 不持有 Spring 依赖，纯 POJO，由 McpClientManager 管理生命周期
- `start()` 内置自动重启逻辑（进程挂掉时重新拉起）

### 2.2 新建 McpClientManager — 多 Server 管理器

替代原 `McpClient`，成为 Spring `@Component`，管理所有 MCP Server 连接。

```java
package com.testagent.mcp;

@Component
public class McpClientManager {

    private final Map<String, McpConnection> connections = new ConcurrentHashMap<>();

    @Value("${mcp.servers.llm.node-path:node}")
    private String llmNodePath;
    @Value("${mcp.servers.llm.script-path:mcp-server/index.js}")
    private String llmScriptPath;
    // ... LLM 环境变量

    @PostConstruct
    public void start() {
        // 创建并启动 "llm" Server
        McpConnection llmConn = new McpConnection("llm", llmNodePath, llmScriptPath, ...);
        llmConn.start();
        connections.put("llm", llmConn);
        // v2.7 将在此处创建 "playwright" Server
    }

    /**
     * 路由调用到指定 Server。
     */
    public String callTool(String serverName, String toolName, Map<String, Object> args) throws Exception {
        McpConnection conn = connections.get(serverName);
        if (conn == null) {
            throw new IllegalArgumentException("未知 MCP Server: " + serverName);
        }
        return conn.callTool(toolName, args);
    }

    public boolean isAvailable(String serverName) {
        McpConnection conn = connections.get(serverName);
        return conn != null && conn.isAvailable();
    }

    @PreDestroy
    public void stopAll() {
        connections.values().forEach(McpConnection::stop);
    }
}
```

### 2.3 配置文件改造

`application.yml`：

```yaml
# v2.6: MCP 多 Server 配置
mcp:
  servers:
    llm:
      node-path: ${MCP_NODE_PATH:node}
      script-path: mcp-server/index.js
      env:
        OPENAI_API_KEY: ${LLM_API_KEY:}
        OPENAI_BASE_URL: ${LLM_BASE_URL:https://api.xiaomimimo.com/v1}
        OPENAI_MODEL: ${LLM_MODEL:gpt-4o}
```

### 2.4 LlmService 适配

```java
// 改动前
@Autowired
private McpClient mcpClient;

public boolean isConfigured() {
    return mcpClient.isAvailable();
}
public String chat(...) {
    return mcpClient.callTool("llm_chat", Map.of(...));
}

// 改动后
@Autowired
private McpClientManager mcpClientManager;

public boolean isConfigured() {
    return mcpClientManager.isAvailable("llm");
}
public String chat(...) {
    return mcpClientManager.callTool("llm", "llm_chat", Map.of(...));
}
```

### 2.5 McpBridgeService 适配

```java
// 改动前
@Autowired
private McpClient mcpClient;

if (!mcpClient.isAvailable()) { ... }
String response = mcpClient.callTool("multimodal_element_locate", Map.of(...));

// 改动后
@Autowired
private McpClientManager mcpClientManager;

if (!mcpClientManager.isAvailable("llm")) { ... }
String response = mcpClientManager.callTool("llm", "multimodal_element_locate", Map.of(...));
```

## 三、文件变更清单

| 文件 | 操作 | 改动说明 |
|------|------|----------|
| `mcp/McpConnection.java` | 新建 | 单 Server 连接封装（从 McpClient 抽取） |
| `mcp/McpClientManager.java` | 新建 | 多 Server 管理器（替代 McpClient） |
| `mcp/McpClient.java` | 删除 | 逻辑已拆分到 McpConnection + McpClientManager |
| `service/LlmService.java` | 修改 | McpClient → McpClientManager，callTool 加 serverName 参数 |
| `service/McpBridgeService.java` | 修改 | McpClient → McpClientManager，callTool 加 serverName 参数 |
| `resources/application.yml` | 修改 | `mcp.server.*` → `mcp.servers.llm.*` |

## 四、API 契约变更

无 API 变更。v2.6 是内部架构重构，对外接口不变。
