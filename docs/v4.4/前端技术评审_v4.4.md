# 前端技术评审 v4.4

**版本**：v4.4，一旦确定尽量不要轻易改动
**日期**：2026-08-13

## 变更点

### ProjectDetail.vue

- 移除 `triggerAnalysis` 调用与轮询式提示，改用 EventSource：

```js
let analyzeEs = null

function handleAnalyze() {
  ElMessage.success('分析已启动')
  pollingMessage.value = '正在启动分析...'
  analyzeEs = new EventSource(`/api/projects/${projectId}/analyze-stream`)
  analyzeEs.addEventListener('progress', (e) => {
    try { pollingMessage.value = JSON.parse(e.data).message } catch {}
  })
  analyzeEs.addEventListener('complete', () => { ...刷新 + 提示... })
  analyzeEs.addEventListener('error', (e) => { ...提示失败 + 刷新... })
}
```

- `onUnmounted` 关闭 EventSource + stopPolling

## 数据流

开始分析 → SSE progress → 横幅实时文案 → complete/error → 刷新项目。

## 向后兼容性

`triggerAnalysis`（POST /analyze）保留，仍可用于非流式触发。
