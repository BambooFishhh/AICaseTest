# 后端技术评审 v4.4

**版本**：v4.4，一旦确定尽量不要轻易改动
**日期**：2026-08-13

## 变更点

### 1. AnalysisService 进度回调

```java
@FunctionalInterface
public interface ProgressCallback { void update(String message); }

public void runAnalysisWithProgress(String projectId, String sourcePath, ProgressCallback progressCb)
```

- 原 `runAnalysis` 保留为无回调入口（内部转调带回调版本）
- 阶段点：扫描结构 / 后端解析 / 前端解析 / 状态机提取 / 完成

### 2. SSE 流式端点

```java
@Async("analysisExecutor")
public void runAnalysisStream(String projectId, SseEmitter emitter)
```

- 事件：`progress`（阶段文案）/ `complete` / `error`
- `onCompletion/onTimeout` 置 clientGone，断开后不再发送

### 3. ProjectController

`GET /api/projects/{projectId}/analyze-stream`：

- `ProjectAccessService.assertOperateAccess`（分析属写操作）
- 仅 `created/failed` 状态可触发；否则立即 error 事件
- 5 分钟超时（与 generate-stream 一致）
