# 后端技术评审 v2.9 — Selenium 清理

**版本**: v2.9
**基线**: v2.8
**日期**: 2026-08-09
**一旦确定尽量不要轻易改动**

---

## 1. 改动总览

v2.8 已将执行链路完整切换到 PlaywrightRecordSkill，`BrowserSkill` 成为死代码。本迭代清理 Selenium 相关代码与依赖，降低包体积与维护成本。

## 2. 改动点

### 2.1 删除 `skill/BrowserSkill.java`

整个文件删除。v2.8 前已确认全代码库仅以下文件提及 `BrowserSkill`：

- `ExecutionAgent.java` — v2.8 已切换为 `PlaywrightRecordSkill`（仅类注释保留历史说明）
- `ExecutionService.java` — v2.8 已切换为 `PlaywrightRecordSkill`
- `PlaywrightRecordSkill.java` — 仅注释引用（本迭代更新）
- `pom.xml` — 依赖（本迭代移除）

无运行时引用，删除安全。

### 2.2 `pom.xml` 移除 Selenium 依赖

移除以下两个依赖块：

```xml
<!-- v2.0: Selenium WebDriver -->
<dependency>
    <groupId>org.seleniumhq.selenium</groupId>
    <artifactId>selenium-java</artifactId>
    <version>4.21.0</version>
</dependency>

<dependency>
    <groupId>io.github.bonigarcia</groupId>
    <artifactId>webdrivermanager</artifactId>
    <version>5.9.1</version>
</dependency>
```

### 2.3 `PlaywrightRecordSkill.java` 注释更新

类注释从：

```
* 过渡期与 BrowserSkill 共存，v2.8 切换执行链路，v2.9 清理 Selenium。
```

更新为：

```
* v2.9 起 BrowserSkill(Selenium) 已移除，本类为唯一浏览器操作实现。
```

其余方法注释中的"兼容 BrowserSkill"说明保留（描述选择器类型兼容性，仍有意义）。
