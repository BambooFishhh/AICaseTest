# 前端技术评审 v2.9 — 录屏回放升级为视频播放

**版本**: v2.9
**基线**: v2.8
**日期**: 2026-08-09
**一旦确定尽量不要轻易改动**

---

## 1. 改动总览

v2.8 后端已产出 WebM 视频录屏（`recordingVideoPath`），但前端 `ExecutionResult.vue` 仍是图片帧轮播方案，无法播放新记录的视频。本迭代将录屏回放升级为 `<video>` 标签播放 WebM，并保留图片轮播回退以兼容历史记录。

## 2. 改动点

### 2.1 `api/execution.js` 新增视频 URL 辅助函数

```js
// v2.9: 执行录屏视频 URL（WebM）
export function getExecutionVideoUrl(eid) {
  return `/api/executions/${eid}/video`
}
```

视频通过文件流返回，前端直接用作 `<video :src>`，无需 axios 封装。

### 2.2 `ExecutionResult.vue` 录屏回放区域改造

#### Template 改动

录屏回放 `<el-card>` 改为双模式渲染：

```vue
<!-- 录屏播放器 -->
<el-card
  v-if="hasRecording"
  class="recording-card"
>
  <template #header>
    录屏回放
    <el-tag v-if="recordingVideoUrl" size="small" type="success" class="recording-tag">WebM 视频</el-tag>
    <el-tag v-else size="small" type="info" class="recording-tag">图片帧</el-tag>
  </template>

  <!-- 视频模式（优先） -->
  <div v-if="recordingVideoUrl" class="video-player">
    <video
      :src="recordingVideoUrl"
      controls
      autoplay
      class="video-element"
    />
    <div class="video-controls">
      <el-button :icon="Download" @click="downloadVideo">下载视频</el-button>
    </div>
  </div>

  <!-- 图片轮播模式（回退，兼容历史记录） -->
  <div v-else class="recording-player">
    <div class="frame-display">
      <img
        v-if="currentFrameUrl"
        :src="currentFrameUrl"
        :alt="`帧 ${currentFrameIndex + 1}`"
        class="frame-image"
      />
    </div>
    <div class="player-controls">
      <el-button
        :icon="isPlaying ? VideoPause : VideoPlay"
        circle
        type="primary"
        @click="togglePlay"
      />
      <el-slider
        v-model="currentFrameIndex"
        :max="Math.max(0, recordingFrames.length - 1)"
        :show-tooltip="false"
        class="frame-slider"
      />
      <span class="frame-counter">
        {{ currentFrameIndex + 1 }} / {{ recordingFrames.length }}
      </span>
    </div>
  </div>
</el-card>
```

#### Script 改动

新增计算属性与下载方法，并引入 `getExecutionVideoUrl`：

```js
import { getExecution, getExecutionSteps, getExecutionVideoUrl } from '@/api/execution'

// v2.9: 视频录屏 URL（优先使用）
const recordingVideoUrl = computed(() => {
  return execution.value?.recordingVideoPath
    ? getExecutionVideoUrl(executionId.value)
    : ''
})

// 是否有任何形式的录屏
const hasRecording = computed(() => {
  return !!recordingVideoUrl.value || (recordingFrames.value && recordingFrames.value.length > 0)
})

// v2.9: 下载视频
function downloadVideo() {
  window.open(recordingVideoUrl.value, '_blank')
}
```

原 `recordingFrames` / `currentFrameUrl` / `togglePlay` / `startPlay` / `pausePlay` 等图片轮播逻辑保留，仅在无视频时生效。

## 3. 数据流

```
后端 ExecutionRecord.recordingVideoPath (v2.8)
    ↓ GET /api/executions/{eid}
前端 execution.recordingVideoPath
    ↓ computed recordingVideoUrl
<video :src="recordingVideoUrl" controls>
    ↓ GET /api/executions/{eid}/video (v2.8)
后端返回 video/webm 流
```
