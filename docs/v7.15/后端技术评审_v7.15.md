## 1. 变更点

### 1.1 流式推送跨轮去重（wrapPushDedup）

`TestGeneratorAgent.runPrdPipeline` 推送链改为：

```java
// v7.15: 外层再套跨轮推送去重——同题草稿只推首见那次，后续补齐轮不再重复发 SSE
CaseCallback effectiveCb = wrapPushDedup(wrapFocusFilter(params, caseCb));
```

```java
static CaseCallback wrapPushDedup(CaseCallback caseCb) {
    if (caseCb == null) return null;
    Set<String> seenTitles = new HashSet<>();
    return tc -> {
        String key = tc == null || tc.getTitle() == null ? "" : tc.getTitle().trim().toLowerCase();
        if (!seenTitles.add(key)) return;
        caseCb.onCase(tc);
    };
}
```

- 仅收敛 SSE 展示；轮次收集（G8 collected）与落库侧 `deduplicate()` 语义不变。
- 背景：运行镜像曾以回退前源码构建（standard 档误为 6 轮），多轮不收敛放大了重复推送。

### 1.2 执行数据防御三件套

**A. Prompt 硬约束**（TestGeneratorAgent 系统提示词）：

- ui_action 的 target 必须是页面元素人话描述，严禁 `METHOD /path` 格式；
- uiSelector.type 白名单对齐执行器真实能力：`id/css/class/data-testid/aria-label/xpath`
  （旧提示词中的 text/path/ref 为执行器不支持类型，系 TC-171 步骤 5 失败根因）；
- 无精确匹配时省略 uiSelector（enrichStructuredSteps 自动补齐），禁止虚构。

**B. 解析期白名单清洗**（parseAndCallback / parseTestCases 两处 LLM 输出 + enrichStructuredSteps 写回）：

```java
String sanitizeUiSelectors(String stepsJson)  // 非 id/css/class/data-testid/aria-label/xpath 的 uiSelector 整体剔除
```

**C. 执行期防御分流**（ExecutionAgent.executeStep，位于 api_call 分流之后）：

```java
if ("ui_action".equals(stepType)
        && target != null && target.trim().matches(
                "(?i)^(GET|POST|PUT|DELETE|PATCH|HEAD|OPTIONS)\\s+/\\S+$")) {
    // strategy=skip, result=skipped, error="target 为接口引用而非页面元素（生成数据缺陷），已自动跳过点击"
}
```

### 1.3 用例双编号制（2a）

- 实体：`TestCase.projectSeq`（`project_seq INT NULL`）；DTO 透出。
- 新组件 `ProjectSeqAllocator`：per-project AtomicInteger 缓存，冷启动 `findMaxProjectSeq`
  （新增 repository @Query）。`reset(projectId)` 供全量重生成前丢弃缓存（replaceAll 清库后从 1 重计）。
- 六条创建路径接线：
  | 路径 | 位置 |
  |---|---|
  | 全量生成 | TestCasePersistenceService.replaceAll（先 reset 再逐条分配） |
  | 追加生成 | TestCaseService runGenerateStreamAppend 持久化循环 |
  | JSON 导入 / XMind 导入 / 复制到项目 / 手动创建 | 各自 setId(idAllocator.nextId()) 处同步 setProjectSeq |
- 迁移 `V12__add_project_seq.sql`：加列 + ROW_NUMBER 物化派生表 JOIN 回填（规避 MySQL 1093）
  + `(project_id, project_seq)` 索引。仅 mysql profile Flyway 执行；H2 dev 由 JPA ddl-auto 建列。
- 序号语义：删除用例的空洞不回收（与全局 id 同策略）；全量重生成归 1 重计。

### 1.4 未覆盖接口清单（3b）

`CoverageService.uncoveredEndpoints(projectId)`：分母取最新 CodeAnalysis 的 endpoints；
covered 集合 = 全部用例 coverageRefs.endpointIds ∪ 已执行用例 apiEndpoints（normalize 精确命中，
与用例列表页接口覆盖率完全同口径）。返回 `{total, covered, uncoveredCount, uncovered[]}`。

新端点：`GET /api/projects/{projectId}/coverage/uncovered-endpoints`（VIEW 权限，assertViewAccess）。
