### 1.3 ExecutionAgent — LLM 驱动的执行引擎

文件：`agent/ExecutionAgent.java`（新建）

```java
@Component
public class ExecutionAgent {
    private static final String SYSTEM_PROMPT = """
        你是测试执行Agent，基于自然语言测试用例完成Web测试。
        你只能调用Skill和MCP工具，禁止自己模拟浏览器。

        执行单步测试操作遵循完整流程：
        1. 分析步骤描述，生成要在页面上查找的元素的自然语言描述
        2. 调用 take_screenshot 截图
        3. 调用 multimodal_element_locate 视觉识别
        4. 根据返回结果自主分支判断：
           ① found=false → 调用 dom_click 兜底
           ② found=true → 调用 visual_click 坐标点击 → get_page_status 判断是否生效
              ✘ 无效 → 调用 dom_click 重试
        5. 操作后截图，组装证据

        异常处理：
        - MCP 超时/报错 → 直接 dom_click 兜底
        - Skill 报错 → 标记失败，继续下一步骤

        禁止：手写硬编码脚本；在内部解析图片；让 Skill 做判断
        """;

    // Agent 执行单步
    public ExecutionStep executeStep(String sessionId, JsonNode step, String testCaseContext) {
        // 1. LLM 生成元素查找描述
        // 2. take_screenshot
        // 3. multimodal_element_locate
        // 4. LLM 决策执行策略 (visual/dom/skip)
        // 5. 执行点击
        // 6. get_page_status + LLM 判断生效
        // 7. 不生效 → LLM 决策兜底
        // 8. 截图 + 组装证据
    }
}
```
