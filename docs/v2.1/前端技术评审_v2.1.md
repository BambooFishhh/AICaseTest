## 一、改动点

### 1.1 新增批量执行 API

文件：`api/execution.js` 修改
```js
export function executeBatch(projectId, caseIds, targetUrl) {
  return request.post(`/projects/${projectId}/testcases/batch-execute`, { caseIds, targetUrl })
}
export function getBatch(batchId) {
  return request.get(`/batches/${batchId}`)
}
```

### 1.2 TestCaseList 新增批量执行

文件：`views/TestCaseList.vue` 修改
- 表格多选后，顶部操作栏新增"批量执行"按钮
- 点击弹出 URL 输入对话框
- 确认后调 executeBatch，跳转到批次结果页

### 1.3 新增 BatchResult.vue

文件：`views/BatchResult.vue` 新建
- 批次概览：总数/已完成/通过/失败，进度条
- 用例执行列表：每条用例标题、状态标签、执行时长、查看详情链接
- 轮询直到全部完成

### 1.4 TestCaseCard 执行按钮增加模式选择

文件：`components/TestCaseCard.vue` 修改
- 执行对话框新增"执行模式"单选：Agent 模式（默认）/ 程序化模式
- Agent 模式调 executeTestCase 传 mode=agent

### 1.5 文件变更清单

| 文件 | 类型 | 说明 |
|------|------|------|
| `api/execution.js` | 修改 | 新增 executeBatch + getBatch |
| `views/TestCaseList.vue` | 修改 | 新增批量执行按钮 |
