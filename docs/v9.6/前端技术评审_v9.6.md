# 前端技术评审 v9.6

**版本**：v9.6（一经确定不再轻易改动） ｜ **主题**：评审质量检查与选择器作用域

## 一、变更点

本版本为纯后端质量增强：

- 评审层静态检查（语义重复、预期与动作一致性）不涉及前端展示。
- 选择器 enrich 作用域收敛发生在生成链路，前端直接用最终 `uiSelector`，无协议变化。

因此 **frontend/src 无源码变更**。

## 二、props/emit 变化

无。

## 三、数据流

生成用例 → 前后端分析结果 → enrich 按路由/组件补 `uiSelector` → 落库 → 执行器消费。前端无需感知 `reviewChecks` 与选择器池内部变化。

## 四、向后兼容性

- `executionHints` 新增 `reviewChecks` 键，属于补充元数据，前端忽略即可。
- 已有用例的 `uiSelector` 不受影响；只有重新生成/编辑时按新逻辑补选择器。

## 五、测试验证方案

- `npm run build` 通过（无源码变更回归验证）。
- 后端单测覆盖选择器作用域与评审检查，前端无新增单测。
