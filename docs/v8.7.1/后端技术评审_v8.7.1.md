# 后端技术评审 v8.7.1 — 指标埋点 + MDC 标准化

> 版本 v8.7.1，一旦确定尽量不要轻易改动。基线 v8.6.2。任务 9.5.1–9.5.4。纯后端版本。

## 一、变更点

### 1.1 MetricsFacade（9.5.1）

新增 `observability/MetricsFacade.java`（@Component）：

```java
public void increment(String name, String... tagPairs);          // Counter，_total 结尾
public void recordMillis(String name, long millis, String... tagPairs); // Timer
public void gauge(String name, Supplier<Number> supplier, String... tagPairs); // 幂等注册+强引用
```

- MeterRegistry 经 @Autowired(required=false) setter 注入；未注入（直 new 单测/无 actuator 场景）时全部方法 no-op——**调用方零判空**。
- gauge 强引用存 ConcurrentHashMap 防 GC 回收；同 name+tags 只注册一次。
- 命名遵循计划书前缀约定（gen_/milvus_/executor_/llm_/rag_）；既有 aicasetest.* 前缀指标不动。

消费方统一模式：

```java
private MetricsFacade metrics = new MetricsFacade();      // no-op 兜底
@Autowired(required = false) void setMetrics(MetricsFacade m) { this.metrics = m; }
```

### 1.2 埋点接线（9.5.2/9.5.3）

见 PRD 指标清单表，逐项落位：

- **TestGeneratorAgent**：parseTestCases 单条跳过 catch 分支 `gen_parse_skipped_total`；轮次出口按 report.roundsNotConverged/coverageCappedByLimit 打 result 标签 `gen_rounds_total{completed|not_converged|capped_by_limit}`；返回前累加 `gen_cases_generated_total`。
- **LlmService**：retryResetHook 触发处 `gen_retry_reset_total`；看门狗超时 throw 前 `gen_stream_truncated_total`。
- **MilvusService**：insert 截断 warn 处 `milvus_insert_truncated_total`；insert/deleteByProject/deleteByIds/search/countCollection/queryIdsByProject 的异常捕获统一 `milvus_op_failed_total{op=...}`。
- **VectorOpCompensationTask**：构造后注册 `vector_pending_ops_size` Gauge ← repository.countByStatus(PENDING)（仓库新增派生 count）。
- **ReconciliationService**：reconcileAll 结束更新 volatile lastMaxDriftRatio 并注册 `reconciliation_drift_ratio` Gauge。
- **AsyncConfig**：快速拒绝 handler 内 `executor_rejected_total{pool}`（pool 取线程名前缀去尾横线）。
- **LlmSchemaValidator**：validateStructured 与 chatJson 共用 `recordViolation(agent)` → `llm_schema_violation_total{agent=schemaName}`。
- **SemanticService.retrieveContexts**：全程 Timer `rag_latency_seconds`；出口命中数累加 `rag_recall_count`；空召回 `rag_empty_recall_total`。

### 1.3 MDC 标准化（9.5.4）

新增 `observability/ObservabilityMdc.java`：`putProjectId/remove` 静态工具（try/finally 配对使用）。新增 `observability/MdcTaskDecorator.java`：提交时快照 MDC，执行前置入、结束后还原调用方上下文。

接线点：

| 入口 | 键 |
|---|---|
| TestCaseService.runGenerateStream / runGenerateStreamAppend | projectId |
| SemanticService indexCase/indexCases/retrieveContexts(核心)/isDuplicate | projectId |
| MilvusService insert/deleteByProject/deleteByIds | projectId（参数可得处） |
| ReconciliationService.reconcileProject 循环体 | projectId |

AsyncConfig 四个池统一 setTaskDecorator(new MdcTaskDecorator())。logstash-encoder JSON 日志自动携带 MDC 字段，无需改 logback 配置。
