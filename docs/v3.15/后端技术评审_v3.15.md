# 后端技术评审 v3.15

**版本**：v3.15，一旦确定尽量不要轻易改动
**日期**：2026-08-12

## 变更点

### 1. TestSuite 实体与接口

- `entity/TestSuite.java`：id/projectId/name/caseIds(TEXT JSON)/createdAt
- `repository/TestSuiteRepository.java`：`findByProjectIdOrderByCreatedAtDesc`
- `service/TestSuiteService.java`：create/list/delete/run（run 复用 executeBatch）
- `controller/TestSuiteController.java`：
  - `POST /api/projects/{id}/test-suites`（name + caseIds）
  - `GET /api/projects/{id}/test-suites`
  - `DELETE /api/projects/{id}/test-suites/{suiteId}`
  - `POST /api/projects/{id}/test-suites/{suiteId}/execute`（targetUrl）

### 2. 多执行环境

`ProjectService` 新增：

```java
// settings.executionEnvironments = { environments: [{name,url}], active: "name" }
public Map<String, Object> getExecutionEnvironments(String projectId)

@Transactional
public Map<String, Object> updateExecutionEnvironments(String projectId, Map<String, Object> payload)
```

保存时若激活环境含 URL，同步写入 `generationParams.defaultTargetUrl`。

`ProjectController` 新增 `GET/PUT /{projectId}/environments`。
