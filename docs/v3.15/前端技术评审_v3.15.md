# 前端技术评审 v3.15

**版本**：v3.15，一旦确定尽量不要轻易改动
**日期**：2026-08-12

## 变更点

### 1. 测试集（TestCaseList.vue）

- 工具栏新增"测试集"按钮 → 管理对话框：
  - 列表：名称/用例数/创建时间 + 执行/删除
  - 新建：名称输入 + 当前选中 ids
  - 执行：复用 `executeSuite`，成功后跳转批次页
- `api/suite.js` 新增 createSuite/listSuites/deleteSuite/executeSuite

### 2. 多执行环境（TestCaseList.vue）

- 工具栏新增"执行环境"按钮 → 对话框：环境行（名称+URL）增删、激活单选
- 保存调用 `updateExecutionEnvironments`，随后刷新 `defaultTargetUrl`
- `api/project.js` 新增 getExecutionEnvironments/updateExecutionEnvironments

### 3. 通过率趋势（ExecutionHistory.vue）

- 引入 echarts，统计最近 20 次执行的滚动通过率，渲染折线图

## 数据流

- 测试集：选中 ids → 保存 → 列表展示 → 一键执行 → batchId → 批次页
- 环境：表单 → PUT environments → defaultTargetUrl 同步

## 向后兼容性

纯新增，兼容既有调用。
