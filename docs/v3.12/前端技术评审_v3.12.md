# 前端技术评审 v3.12

**版本**：v3.12，一旦确定尽量不要轻易改动
**日期**：2026-08-12

## 变更点

### 1. TestCaseList

- filters 增加 `executionStatus`，筛选区新增下拉
- 表格新增"执行状态"列（复用 status-pill 样式：通过/失败/执行中/未执行）
- 工具栏新增：
  - "重跑失败（N）"：`handleRerunFailed()` → 过滤 executionStatus=failed → `selectedRows` → 批量执行对话框
  - "执行已批准（N）"：`handleExecuteApproved()` → 过滤 reviewStatus=approved → 批量执行对话框
- 生成参数对话框新增"默认执行 URL"输入（`genParams.defaultTargetUrl`）
- `onMounted` 拉取生成参数作为默认 URL；批量执行对话框 `batchTargetUrl` 初始值使用默认 URL
- 用例详情 `<test-case-card>` 传入 `:default-target-url="defaultTargetUrl"`（新增可选 prop）

### 2. TestCaseCard

```js
const props = defineProps({
  ...,

const openExecuteDialog = () => {
  targetUrl.value = props.defaultTargetUrl || 'http://localhost:5173'

```

### 3. ProjectDetail 生成预检

```js
const hasPrd = computed(() => !!project.value?.prdContent && project.value.prdContent.trim() !== '')
const canGenerate = computed(() => {
  const s = project.value?.status
  if (s === 'analyzing' || s === 'generating') return false
  if (s === 'created' && !hasPrd.value) return false   // 无任何上下文不可生成
  return true
})
```

按钮 title 提示"请先提供 PRD 或完成代码分析"。

### 4. BatchResult 修复 + 失败摘要

- `executions` 读取 `batch.executions`（后端已补别名）
- 行跳转 `row.id`；标题用 `row.testCaseTitle`
- 新增"失败用例（N）"折叠区：`failedExecutions` computed → el-collapse 列表（标题 + errorMessage + 查看详情）
