# 后端技术评审 v3.12

**版本**：v3.12，一旦确定尽量不要轻易改动
**日期**：2026-08-12

## 变更点

### 1. listTestCases 新增 executionStatus 筛选

`TestCaseService.listTestCases` 增加参数 `executionStatus`，与现有筛选链一致：

```java
if (executionStatus != null && !executionStatus.isBlank()) {
    all = all.stream()
            .filter(tc -> executionStatus.equals(tc.getExecutionStatus()))
            .collect(Collectors.toList());
}
```

`TestCaseController.listTestCases` 同步增加 `@RequestParam(required = false) String executionStatus`。

### 2. GenerationParams 新增 defaultTargetUrl

```java
private String defaultTargetUrl;   // 项目默认执行 URL，可为空
```

`ProjectService.parseGenerationParams` 对 null 不做兜底（允许空）。

### 3. getBatchStatus 增加 executions 别名

`ExecutionService.getBatchStatus` 增加：

```java
result.put("executions", records);
```

修复前端读取 `executions`（原仅有 `records`）导致批次列表为空的问题。

## API 契约变化

- `GET /testcases` 新增可选参数 `executionStatus`
- `GET/PUT /generation-params` 载荷新增可选字段 `defaultTargetUrl`
- `GET /batches/{id}` 响应新增 `executions`（与 records 相同内容）

向后兼容：全部为可选新增，旧调用不受影响。
