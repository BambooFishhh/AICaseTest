## 三、BrowserSkill 录屏

### 3.1 录屏实现方案
```java
// 定时截图线程
private ScheduledExecutorService recordingScheduler;
private final Map<String, List<String>> recordingFrames = new ConcurrentHashMap<>();

public void startRecording(String sessionId, String outputDir) {
    recordingScheduler = Executors.newSingleThreadScheduledExecutor();
    recordingScheduler.scheduleAtFixedRate(() -> {
        try {
            String path = takeScreenshot(sessionId);
            recordingFrames.get(sessionId).add(path);
        } catch (Exception e) { /* 忽略单帧失败 */ }
    }, 0, 2, TimeUnit.SECONDS);
}

public List<String> stopRecording(String sessionId) {
    recordingScheduler.shutdown();
    return recordingFrames.get(sessionId);
}
```

### 3.2 帧数限制
- 最多 60 帧（2分钟 @ 2s/帧）
- 超过 60 帧自动停止
