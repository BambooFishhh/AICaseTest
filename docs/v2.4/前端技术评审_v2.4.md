## 二、ExecutionResult.vue 改动

### 2.1 下载报告按钮
```html
<el-button type="primary" @click="downloadReport">
  下载报告
</el-button>
```
```javascript
function downloadReport() {
  window.open(`/api/executions/${executionId}/report`, '_blank')
}
```
使用 `window.open` 直接下载 HTML 文件，无需 blob 处理。

### 2.2 录屏播放器
```html
<div class="recording-player" v-if="recordingFrames.length > 0">
  <div class="frame-container">
    <img :src="currentFrameUrl" />
  </div>
  <el-slider v-model="currentFrameIndex" :max="recordingFrames.length - 1" />
  <div class="controls">
    <el-button @click="togglePlay">{{ playing ? '暂停' : '播放' }}</el-button>
    <span>{{ currentFrameIndex + 1 }} / {{ recordingFrames.length }}</span>
  </div>
</div>
```

### 2.3 播放逻辑
```javascript
const playing = ref(false)
const currentFrameIndex = ref(0)
let playTimer = null

function togglePlay() {
  if (playing.value) {
    clearInterval(playTimer)
    playing.value = false
  } else {
    playTimer = setInterval(() => {
      if (currentFrameIndex.value < recordingFrames.value.length - 1) {
        currentFrameIndex.value++
      } else {
        clearInterval(playTimer)
        playing.value = false
      }
    }, 500) // 500ms/帧
    playing.value = true
  }
}
```

### 2.4 数据来源
- 执行结果 API 已返回 ExecutionRecord
- 新增 `recordingFrames` 字段（JSON 数组，每项为截图路径）
- 前端通过 `/api/files/screenshot/xxx.png` 或后端静态资源访问截图
