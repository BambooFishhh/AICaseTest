# 后端技术评审文档 v1.12 — VueAnalyzer LLM 增强

**版本**: v1.12（后端）
**基线**: v1.11
**日期**: 2026-08-09

---

## 一、改动点

### 1.1 VueAnalyzer 注入 LlmService

文件：`analyzer/VueAnalyzer.java`

```java
@Component
public class VueAnalyzer {
    @Autowired
    private LlmService llmService;  // v1.12 新增
```

### 1.2 新增 enhanceWithLlm 方法

在 analyze() 中，正则提取完成后调用：

```java
// v1.12: LLM 补充
if (llmService.isConfigured()) {
    enhanceWithLlm(forms, componentStates, domSelectors, pageFlows, dir);
}
```

方法逻辑：
1. 收集 .vue 文件源码摘要（每文件截断 1500 字符）
2. 构建 system prompt + user prompt（含正则结果 + 源码摘要）
3. 调 LLM，解析返回的 JSON
4. 合并到正则结果（按 component 去重）

### 1.3 LLM Prompt 设计

**System Prompt**:
```
你是前端代码分析专家。正则已提取了部分结果，请你阅读源码，补充正则遗漏的内容。
只返回正则没提取到的，不要重复已有结果。
返回 JSON 格式：
{"supplementalForms":[...], "supplementalStates":[...], "supplementalSelectors":[...], "supplementalFlows":[...]}
```

**User Prompt**:
```
正则已提取结果：
forms: [...]
componentStates: [...]
domSelectors: [...]
pageFlows: [...]

源码摘要：
=== LoginForm.vue ===
<template>...</template>
<script>...</script>
=== OrderList.vue ===
...
```
