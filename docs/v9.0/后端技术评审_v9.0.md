# 后端技术评审 v9.0 — 本期范围全自动

> 版本 v9.0，一旦确定尽量不要轻易改动。基线 v8.9.8。

## 一、变更点

### 1.1 autoSyncAfterAnalysis（ScopeService）

- 分析完成双路径挂钩（AnalysisService 同步分析路径 + 异步任务路径各一处）；
- 语义：分析成功 → 自动以默认主干为基线 diff 识别范围并锁定；已有旧范围先清除重建（重新分析=刷新范围）；
- 幂等：识别为空时不落空范围，保留旧范围并记日志。

### 1.2 detectDefaultBaseline（GitDiffService）

```java
// origin/HEAD → master → main 三级探测
refs.contains("origin/HEAD") → resolve
else refs.contains("master") → "master"
else refs.contains("main")   → "main"
else null（回落手动选基线）
```

- `git-refs` 接口透出 `defaultBaseline` 供前端预填。

### 1.3 范围接口全量进上下文（G17 顺序修复）

- 根因：范围上下文构建顺序在 G17 关键词过滤**之后**取接口，激活范围时 11/11 接口被关键词误杀；
- 修复：范围激活时 endpoint context 直接 = 范围目标集合（`ScopeSlice` targets 全量），绕过 G17；
- 生成侧（v9.2 同步收口）：`TestGeneratorAgent.scopeRoutePaths/coveredEndpointIds` 以范围目标集合为覆盖口径。

### 1.4 ScopeSlice 扩展

- `ScopeSlice` 构造器新增参数（targetPageRefs，v8.9.8 已落）；`ScopeItem` 实体微调；CoverageService 两处测试同步构造器签名。

## 二、文件变更清单

service/ScopeService.java（+213）、service/GitDiffService.java（+38）、service/AnalysisService.java（+19）、service/ScopeSlicingService.java、entity/ScopeItem.java；新增 test：GitDiffServiceTest（4 例）、ScopeServiceAutoSyncTest（含空范围/幂等/重建路径）、ScopeServiceFrontendMappingTest（3 例）；CoverageService 两测试适配。

## 三、API 契约变化

- `GET .../git-refs` 响应新增 `defaultBaseline` 字段（可选）。
- 范围确认后条目增删接口放开（操作权限校验不变）。

## 四、验证结果

- 新增单测全绿；litemall 实测：分析完成自动锁定范围，生成上下文 endpoint context = 11/11 全量。
