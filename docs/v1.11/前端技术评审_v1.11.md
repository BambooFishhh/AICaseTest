## 一、改动点

### 1.1 CodeAnalysis.vue 展示增强

文件：`frontend/src/views/CodeAnalysis.vue`

变更：在前端分析结果区域新增 4 个展示面板

#### 表单字段面板
```html
<el-card v-if="frontendForms.length" header="表单字段与校验">
  <el-table :data="frontendForms" border>
    <el-table-column prop="component" label="组件" width="150" />
    <el-table-column label="字段">
      <template #default="{ row }">
        <el-tag v-for="f in row.fields" :key="f.name" class="mr-1" :type="f.required ? 'danger' : 'info'">
          {{ f.name }} ({{ f.type }})
        </el-tag>
      </template>
    </el-table-column>
    <el-table-column prop="file" label="文件" width="180" />
  </el-table>
</el-card>
```

#### 组件交互状态面板
```html
<el-card v-if="componentStates.length" header="组件交互状态">
  <el-table :data="componentStates" border>
    <el-table-column prop="component" label="组件" width="150" />
    <el-table-column prop="type" label="类型" width="100" />
    <el-table-column prop="stateVar" label="状态变量" width="150" />
    <el-table-column prop="trigger" label="触发方式" />
    <el-table-column prop="file" label="文件" width="180" />
  </el-table>
</el-card>
```

#### DOM 选择器面板
```html
<el-card v-if="domSelectors.length" header="DOM 选择器">
  <el-table :data="domSelectors" border>
    <el-table-column prop="component" label="组件" width="150" />
    <el-table-column label="选择器">
      <template #default="{ row }">
        <el-tag v-for="s in row.selectors" :key="s.value" class="mr-1">
          {{ s.type }}="{{ s.value }}" ({{ s.element }})
        </el-tag>
      </template>
    </el-table-column>
    <el-table-column prop="file" label="文件" width="180" />
  </el-table>
</el-card>
```

#### 页面跳转关系面板
```html
<el-card v-if="pageFlows.length" header="页面跳转关系">
  <el-table :data="pageFlows" border>
    <el-table-column prop="from" label="来源页面" width="150" />
    <el-table-column prop="to" label="目标页面" width="150" />
    <el-table-column prop="trigger" label="触发条件" />
    <el-table-column prop="component" label="组件" width="150" />
  </el-table>
</el-card>
```

### 1.2 数据来源

前端分析结果从已有的 `GET /api/projects/{id}/analysis` 接口返回的 `frontendResult` 字段获取。v1.11 后端扩展了 FrontendResult 结构，前端直接消费新字段：

```js
const frontend = analysisResult.frontendResult || {}
const frontendForms = frontend.forms || []
const componentStates = frontend.componentStates || []
const domSelectors = frontend.domSelectors || []
const pageFlows = frontend.pageFlows || []
```
