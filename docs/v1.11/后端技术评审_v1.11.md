### 1.2 VueAnalyzer 增强 — 4 个新维度

文件：`backend/src/main/java/com/testagent/analyzer/VueAnalyzer.java`

新增 4 个提取方法：

#### 1.2.1 extractForms(File dir)
扫描所有 `.vue` 文件，提取：
- `<el-form-item prop="xxx">` → 字段名
- `<el-input v-model="form.xxx">` / `<el-select>` / `<el-date-picker>` → 字段类型
- `:rules="rules"` → 从 script 中匹配 `rules: { xxx: [...] }` 提取校验规则
- 输出：`[{component, fields: [{name, type, label, required, rules}], file}]`

#### 1.2.2 extractComponentStates(File dir)
扫描 `.vue` 文件，识别：
- `<el-dialog` / `<el-drawer` → type=dialog/drawer
- `<el-steps` → type=steps
- `<el-tabs` → type=tabs
- 关联 `v-model` / `v-if` 变量名作为 stateVar
- 关联 `@click="xxx = true"` 作为 trigger
- 输出：`[{component, type, stateVar, trigger, file}]`

#### 1.2.3 extractDomSelectors(File dir)
扫描 `.vue` 文件的 `<template>` 部分，提取：
- `data-testid="xxx"` → type=data-testid
- `id="xxx"` → type=id
- `ref="xxx"` → type=ref
- `aria-label="xxx"` → type=aria-label
- 识别元素标签（button/input/select/a/div）
- 输出：`[{component, selectors: [{type, value, element}], file}]`

#### 1.2.4 extractPageFlows(File dir)
扫描 `.vue` 和 `.js/.ts` 文件，提取页面跳转：
- `router.push('/xxx')` / `router.push({ path: '/xxx' })` → 跳转目标
- `<router-link to="/xxx">` → 跳转目标
- 结合路由配置确定 from 页面
- 输出：`[{from, to, trigger, component, file}]`
