# 前端技术评审 v3.16

**版本**：v3.16，一旦确定尽量不要轻易改动
**日期**：2026-08-12

## 变更点

### 1. TestCaseList.vue

- "模板"按钮 → `window.open(xmind-template)`
- 导入 XMind 后跳过明细 ElMessageBox 展示
- 批量评审增加评审人 prompt（默认 local），调用 `reviewTestCases(..., reviewer)`

### 2. ProjectDetail.vue

- 查看操作卡新增"导出备份" → `window.open(/api/projects/{id}/export)`

### 3. ExecutionResult.vue

- `executionSnapshot` computed 解析 testCaseSnapshot JSON
- 新增"执行时用例快照"折叠区（标题/模块/类型/优先级）

## 向后兼容性

纯新增；旧执行记录无快照时折叠区不显示。
