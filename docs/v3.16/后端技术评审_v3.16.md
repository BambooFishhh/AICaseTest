# 后端技术评审 v3.16

**版本**：v3.16，一旦确定尽量不要轻易改动
**日期**：2026-08-12

## 变更点

### 1. 执行快照

- `ExecutionRecord` 新增 `testCaseSnapshot`（TEXT）
- `ExecutionService.execute()` 保存快照（标题/模块/类型/优先级/前置/步骤/预期/结构化步骤）

### 2. XMind 模板与校验明细

- `XmindService.generateTemplateFile()`：内置一个示例用例生成模板文件
- `TestCaseController` 新增 `GET /testcases/xmind-template`
- `TestCaseService.importFromXmind` 返回 `skippedDetails`（标题为空原因）

### 3. 项目导出备份

- 新增 `BackupService.buildProjectBackup`：打包 project.json / prd.md / testcases.json / coverage.json / executions.json 为 ZIP
- `ProjectController` 新增 `GET /projects/{id}/export`
