# PRD v3.16 — 数据与协作

**版本**：v3.16
**基线**：v3.15
**日期**：2026-08-12
**主题**：XMind 模板与导入校验明细 + 执行时用例快照 + 评审审计 + 项目导出备份

## 一、背景与痛点

1. XMind 导入依赖固定结构约定，用户不知道结构怎么写，且跳过原因只有数字
2. 用例被编辑后，历史执行无法还原"当时跑的什么用例"
3. 批量评审无评审人记录，协作留痕缺失
4. 项目数据（PRD/用例/覆盖率/执行记录）无法整体导出，删除即永久丢失

## 二、范围

### In scope

- XMind 导入模板下载 + 跳过明细（标题为空等原因）
- 执行时用例快照（ExecutionRecord.testCaseSnapshot）+ 结果页展示
- 批量评审评审人录入（审计留痕）
- 项目导出备份 ZIP（project.json/prd.md/testcases.json/coverage.json/executions.json）

### Out of scope

- 安全、并发、性能

## 三、功能详情

### 3.1 XMind 模板与校验明细

- 用例列表"模板"按钮下载 `xmind_template.xmind`（含示例用例说明结构）
- 导入结果跳过明细：标题为空等，前端弹出明细列表

### 3.2 执行时用例快照

- 执行启动时把用例关键字段 JSON 存入 ExecutionRecord
- 执行结果页新增"执行时用例快照"折叠区

### 3.3 评审审计

- 批量评审时弹窗录入评审人（默认 local），随接口提交并展示

### 3.4 项目导出备份

- 项目详情"导出备份"下载 ZIP 包

## 四、验收标准

1. 模板可下载、导入跳过明细可见
2. 新执行记录带快照，结果页可查看
3. 批量评审带评审人
4. 备份 ZIP 含 5 个文件
5. mvn test + npm run build 通过
