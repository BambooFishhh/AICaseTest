## 2. 改动详情

### 2.1 TestCaseList.vue 流式进度文案

**当前**（v3.6）：
```javascript
const streamingAlertBody = computed(() => {
  if (streaming.value) {
    return `${streamProgress.value}（已收到 ${streamedCases.value.length} 条）`
  }
  return ''
})
```

**改造后**（v3.7）：
```javascript
const streamingAlertBody = computed(() => {
  if (streaming.value) {
    const count = streamedCases.value.length
    if (count === 0) {
      return `${streamProgress.value}（正在接收 LLM 流式响应...）`
    }
    return `${streamProgress.value}（已收到 ${count} 条）`
  }
  return ''
})
```

### 2.2 流式面板增加字符计数（可选增强）

在流式 alert 中显示已接收的用例数 + 首条到达时间提示：

```html
<el-alert v-if="streaming" type="success" :closable="false" show-icon>
  <template #title>
    {{ streamingAlertTitle }}
  </template>
  <div class="streaming-alert-body">
    {{ streamingAlertBody }}
  </div>
</el-alert>
```

无需新增响应式变量，复用 `streamProgress` 和 `streamedCases`。

## 4. 数据流

```
SSE case 事件（更早到达）
  → EventSource onmessage
  → streamedCases.push(testCase)
  → displayTestCases computed 合并已有+新用例
  → 表格实时显示
```

数据流完全不变，仅 case 事件到达时间从 40~120 秒后批量到达变为 ~5 秒起逐条到达。
