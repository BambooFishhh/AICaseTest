# 后端技术评审 v2.8 — 执行链路切换 + 录屏升级为视频

> 版本：v2.8 | 基线：v2.7 | 一旦确定尽量不要轻易改动

## 一、改动概述

ExecutionService 和 ExecutionAgent 的 `@Autowired BrowserSkill` 切换为 `@Autowired PlaywrightRecordSkill`，录屏从图片序列升级为 WebM 视频。

## 二、变更点

### 2.1 ExecutionService.java

| 改动点 | 旧（BrowserSkill） | 新（PlaywrightRecordSkill） |
|--------|---------------------|---------------------------|
| 依赖注入 | `@Autowired BrowserSkill browserSkill` | `@Autowired PlaywrightRecordSkill playwrightSkill` |
| 启动浏览器 | `browserSkill.browserLaunch(true, 1280, 800)` | `playwrightSkill.browserLaunch(true, 1280, 800)` |
| 开始录屏 | `browserSkill.startRecording(sessionId, dir)` | 删除（launch 时自动开始） |
| 停止录屏 | `browserSkill.stopRecording()` → List<String> | `playwrightSkill.stopRecording(videoPath)` → String |
| 截图 | `browserSkill.takeScreenshot(sessionId)` | `playwrightSkill.takeScreenshot(sessionId)` |
| 截图标注 | `browserSkill.takeScreenshotWithMarker(...)` | `playwrightSkill.takeScreenshotWithMarker(...)` |
| DOM 点击 | `browserSkill.domClick(...)` | `playwrightSkill.domClick(...)` |
| 视觉点击 | `browserSkill.visualClick(...)` | `playwrightSkill.visualClick(...)` |
| 页面状态 | `browserSkill.getPageStatus(sessionId)` | `playwrightSkill.getPageStatus(sessionId)` |
| 关闭 | `browserSkill.closeSession(sessionId)` | `playwrightSkill.closeSession(sessionId)` |
| 录屏存储 | `recordingFrames`（JSON 图片数组） | `recordingVideoPath`（WebM 路径） |

### 2.2 ExecutionAgent.java

所有 `browserSkill.xxx(sessionId, ...)` 调用替换为 `playwrightSkill.xxx(sessionId, ...)`，方法签名相同。

### 2.3 ExecutionRecord.java

```java
/** v2.8: 录屏视频文件路径（WebM 格式） */
private String recordingVideoPath;
```

### 2.4 ExecutionController.java

```java
@GetMapping("/executions/{executionId}/video")
public ResponseEntity<Resource> downloadVideo(@PathVariable String executionId) {
    // 返回 WebM 视频文件流
}
```

## 三、文件变更清单

| 文件 | 操作 | 说明 |
|------|------|------|
| `service/ExecutionService.java` | 重写 | BrowserSkill → PlaywrightRecordSkill + 录屏改视频 |
| `agent/ExecutionAgent.java` | 修改 | BrowserSkill → PlaywrightRecordSkill |
| `entity/ExecutionRecord.java` | 修改 | 新增 recordingVideoPath 字段 |
| `controller/ExecutionController.java` | 修改 | 新增视频下载 API |

## 四、向后兼容

- recordingFrames 字段保留（旧数据可查），新执行不填充
- BrowserSkill 保留不动（v2.9 清理）
- 前端仍可显示截图（screenshotBefore/After 不变）

## 五、测试验证

1. `mvn compile` 编译通过
2. 触发执行 → recordingVideoPath 指向 .webm 文件
3. `GET /api/executions/{id}/video` 返回视频流
