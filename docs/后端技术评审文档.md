## 一、技术栈最终选型

| 组件 | 选型 | 版本 | 理由 |
|------|------|------|------|
| 语言 | Java | JDK 17 (LTS) | 长期支持版本，Spring Boot 3 最低要求 |
| Web 框架 | Spring Boot | 3.2+ | 企业级标准，自动配置，内嵌 Tomcat |

| 容器化 | Docker | 24+ | eclipse-temurin:17-jre 基础镜像 |

### 2.2 请求处理流程

```
前端请求 → Nginx(反向代理) → Spring Boot (Tomcat) → DispatcherServlet → Controller → 返回JSON
                                                          ↓
                                                    同步请求：直接返回
                                                    异步请求：@Async 线程池 → 轮询查询状态
```

### 2.3 异步任务流程（分析/生成）

```
1. 前端 POST /api/projects/:id/analyze → 后端返回 202 + task started
2. 后端调用 @Async 方法，立即返回
3. 异步线程执行：
   a. 更新项目状态 → analyzing
   b. 执行代码分析
   c. 提取状态机
   d. 更新项目状态 → analyzed
4. 前端轮询 GET /api/projects/:id（每3秒），检查 status 字段
5. 状态变为 analyzed 后，前端请求分析结果
```

**项目状态机**：

```
created → analyzing → analyzed → generating → completed
    ↓         ↓                      ↓
  (可删除)  failed                 failed
```

- Content-Type: application/json（POST/PUT 请求）
- 路径参数用 `{id}` 表示

**响应格式**：

成功响应：
```json
{
  "code": 0,
  "message": "操作成功",
  "data": { ... }
}
```

```json
{
  "code": 40001,
  "message": "项目不存在",
  "data": null

@Data

**GlobalExceptionHandler.java**：
```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BusinessException.class)
    public ResponseEntity<ApiResponse<Void>> handleBusiness(BusinessException e) {
        return ResponseEntity.status(e.getHttpStatus())
            .body(ApiResponse.error(e.getCode(), e.getMessage()));
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<ApiResponse<Void>> handleValidation(MethodArgumentNotValidException e) {
        String msg = e.getBindingResult().getFieldErrors().stream()
            .map(f -> f.getField() + ": " + f.getDefaultMessage())
            .collect(Collectors.joining(", "));
        return ResponseEntity.badRequest()
            .body(ApiResponse.error(40002, "参数无效: " + msg));
    }

    @ExceptionHandler(Exception.class)
    public ResponseEntity<ApiResponse<Void>> handleGeneric(Exception e) {
        return ResponseEntity.internalServerError()
            .body(ApiResponse.error(50001, "服务器内部错误: " + e.getMessage()));
    }
}
```

**BusinessException.java**：
```java
@Getter
public class BusinessException extends RuntimeException {
    private final int code;
    private final HttpStatus httpStatus;

    public BusinessException(int code, String message, HttpStatus httpStatus) {
        super(message);
        this.code = code;
        this.httpStatus = httpStatus;
    }

    // 便捷工厂方法
    public static BusinessException notFound(String message) {
        return new BusinessException(40001, message, HttpStatus.NOT_FOUND);
    }

    public static BusinessException invalidParam(String message) {
        return new BusinessException(40002, message, HttpStatus.BAD_REQUEST);
    }

    public static BusinessException pathNotFound(String path) {
        return new BusinessException(40003, "项目路径不存在: " + path, HttpStatus.BAD_REQUEST);
    }

    public static BusinessException invalidState(String message) {
        return new BusinessException(40004, message, HttpStatus.CONFLICT);
    }
}

@EnableAsync
public class AsyncConfig {

    @Bean("analysisExecutor")
    public Executor analysisExecutor() {
        ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
        executor.setCorePoolSize(2);
        executor.setMaxPoolSize(4);

### 6.3 Controller 示例

**ProjectController.java**：
```java
@RestController
@RequestMapping("/api/projects")
@CrossOrigin
public class ProjectController {

    @Autowired
    private ProjectService projectService;

    @GetMapping
    public ApiResponse<List<ProjectDTO>> listProjects() {
        return ApiResponse.success(projectService.listProjects());
    }

    @PostMapping
    public ApiResponse<ProjectDTO> createProject(@Valid @RequestBody CreateProjectRequest req) {
        return ApiResponse.success(projectService.createProject(req), "项目创建成功");
    }

    @GetMapping("/{projectId}")
    public ApiResponse<ProjectDTO> getProject(@PathVariable String projectId) {
        return ApiResponse.success(projectService.getProject(projectId));
    }

    @DeleteMapping("/{projectId}")
    public ApiResponse<Void> deleteProject(@PathVariable String projectId) {
        projectService.deleteProject(projectId);
        return ApiResponse.success(null, "项目已删除");
    }

    @PostMapping("/{projectId}/analyze")
    public ResponseEntity<ApiResponse<Void>> triggerAnalysis(
            @PathVariable String projectId) {
        projectService.triggerAnalysis(projectId);
        return ResponseEntity.accepted()
            .body(ApiResponse.accepted("分析任务已启动"));
    }

    @PostMapping("/{projectId}/generate")
    public ResponseEntity<ApiResponse<Void>> triggerGenerate(
            @PathVariable String projectId,
            @RequestBody(required = false) GenerateRequest req) {

### 6.4 Service 层异步方法

**AnalysisService.java**（关键异步逻辑）：
```java
@Service
public class AnalysisService {

    @Autowired
    private ProjectRepository projectRepo;
    @Autowired
    private CodeAnalysisRepository analysisRepo;
    @Autowired
    private StateMachineRepository smRepo;
    @Autowired
    private ProjectScanner projectScanner;
    @Autowired
    private VueAnalyzer vueAnalyzer;
    @Autowired
    private SpringAnalyzer springAnalyzer;
    @Autowired
    private StateMachineAgent stateMachineAgent;

    @Async("analysisExecutor")
    public void runAnalysis(String projectId, String sourcePath) {
        String analysisId = UUID.randomUUID().toString().substring(0, 8);
        CodeAnalysis analysis = new CodeAnalysis(analysisId, projectId);
        analysisRepo.save(analysis);

        try {
            analysis.setStatus("running");
            analysisRepo.save(analysis);

            // 1. 扫描项目
            ScanResult scanResult = projectScanner.scan(sourcePath);
            projectRepo.updateTechStack(projectId, scanResult.getTechStack());

            // 2. 前端分析
            FrontendResult frontendResult = FrontendResult.skipped();
            if (scanResult.getFrontendDir() != null) {
                frontendResult = vueAnalyzer.analyze(scanResult.getFrontendDir());
            }

            // 3. 后端分析
            BackendResult backendResult = BackendResult.skipped();
            if (scanResult.getBackendDir() != null) {
                backendResult = springAnalyzer.analyze(scanResult.getBackendDir());
            }

            // 保存分析结果
            analysis.setFrontendResult(frontendResult);
            analysis.setBackendResult(backendResult);
            analysis.setStatus("completed");
            analysisRepo.save(analysis);

            // 4. 提取状态机
            List<StateMachine> stateMachines = stateMachineAgent.extract(backendResult);
            for (StateMachine sm : stateMachines) {
                sm.setProjectId(projectId);
                smRepo.save(sm);
            }

            // 更新项目状态
            projectRepo.updateStatus(projectId, "analyzed");

        } catch (Exception e) {
            analysis.setStatus("failed");
            analysis.setErrorMessage(e.getMessage());
            analysisRepo.save(analysis);
            projectRepo.updateStatus(projectId, "failed");
        }
    }
}

**LlmService.java**：
```java
@Service
public class LlmService {

    @Value("${llm.provider:deepseek}")
    private String provider;

    @Value("${llm.model:deepseek-chat}")
    private String model;

    @Value("${llm.api-key:}")
    private String apiKey;

    @Value("${llm.base-url:https://api.deepseek.com}")
    private String baseUrl;

    private final OkHttpClient client = new OkHttpClient.Builder()
        .connectTimeout(30, TimeUnit.SECONDS)
        .readTimeout(120, TimeUnit.SECONDS)
        .build();

    private final ObjectMapper objectMapper = new ObjectMapper();

    /**
     * 调用 LLM Chat API
     */
    public String chat(String systemPrompt, String userPrompt, double temperature) {
        if (apiKey == null || apiKey.isBlank()) {
            throw new BusinessException(50002, "LLM API Key 未配置", HttpStatus.BAD_GATEWAY);
        }

        try {
            String url = baseUrl.replaceAll("/$", "") + "/chat/completions";

            Map<String, Object> payload = Map.of(
                "model", model,
                "messages", List.of(
                    Map.of("role", "system", "content", systemPrompt),
                    Map.of("role", "user", "content", userPrompt)
                ),
                "temperature", temperature,
                "max_tokens", 8192
            );

            String json = objectMapper.writeValueAsString(payload);

            Request request = new Request.Builder()
                .url(url)
                .post(RequestBody.create(json, MediaType.parse("application/json")))
                .addHeader("Authorization", "Bearer " + apiKey)
                .build();

            try (Response response = client.newCall(request).execute()) {
                if (!response.isSuccessful()) {
                    throw new BusinessException(50002,
                        "LLM API 错误: HTTP " + response.code(),
                        HttpStatus.BAD_GATEWAY);
                }
                String body = response.body().string();
                JsonNode root = objectMapper.readTree(body);
                return root.path("choices").get(0).path("message").path("content").asText();
            }
        } catch (BusinessException e) {
            throw e;
        } catch (Exception e) {
            throw new BusinessException(50002, "LLM 调用失败: " + e.getMessage(), HttpStatus.BAD_GATEWAY);
        }
    }

    /**
     * 调用 LLM 并解析 JSON 响应
     */
    public Map<String, Object> chatJson(String systemPrompt, String userPrompt, double temperature) {
        String raw = chat(systemPrompt, userPrompt, temperature);
        return parseJsonResponse(raw);
    }

    /**
     * 从 LLM 响应中提取 JSON
     */
    private Map<String, Object> parseJsonResponse(String text) {
        text = text.trim();
        // 处理 markdown 代码块
        if (text.startsWith("```")) {
            int start = text.indexOf("\n") + 1;
            int end = text.lastIndexOf("```");
            if (start > 0 && end > start) {
                text = text.substring(start, end).trim();
            }
        }
        try {
            return objectMapper.readValue(text, new TypeReference<>() {});
        } catch (Exception e) {
            // 尝试提取第一个 { 到最后一个 }
            int first = text.indexOf("{");
            int last = text.lastIndexOf("}");
            if (first >= 0 && last > first) {
                try {
                    return objectMapper.readValue(text.substring(first, last + 1),
                        new TypeReference<>() {});
                } catch (Exception ignored) {}
            }
            throw new BusinessException(50002, "LLM 响应无法解析为 JSON", HttpStatus.BAD_GATEWAY);
        }
    }

    /**
     * 测试连接
     */
    public Map<String, Object> testConnection() {
        String response = chat("你是一个助手", "请回复'连接正常'四个字", 0);
        return Map.of("provider", provider, "model", model, "response_preview",
            response.substring(0, Math.min(response.length(), 100)));
    }
}

### 6.6 SpringAnalyzer（JavaParser 解析）

**SpringAnalyzer.java**（核心方法）：
```java
@Component
public class SpringAnalyzer {

    /**
     * 分析 Spring Boot 项目
     */
    public BackendResult analyze(String backendDir) {
        List<File> javaFiles = listJavaFiles(backendDir);
        List<EndpointInfo> endpoints = new ArrayList<>();
        List<EnumInfo> enums = new ArrayList<>();
        List<EntityInfo> entities = new ArrayList<>();
        List<BusinessRule> rules = new ArrayList<>();

        for (File javaFile : javaFiles) {
            try {
                CompilationUnit cu = StaticJavaParser.parse(javaFile);

                // 提取 Controller 端点
                extractEndpoints(cu, javaFile, endpoints);
                // 提取枚举
                extractEnums(cu, javaFile, enums);
                // 提取实体类
                extractEntities(cu, javaFile, entities);
                // 提取业务规则
                extractBusinessRules(cu, javaFile, rules);

            } catch (Exception e) {
                // 单文件解析失败不影响整体
            }
        }

        return BackendResult.builder()
            .techStack(detectTechStack(backendDir))
            .endpoints(endpoints)
            .enums(enums)
            .entities(entities)
            .businessRules(rules)
            .fileCount(javaFiles.size())
            .status("completed")
            .build();
    }

    /**
     * 提取 Controller 端点（使用 JavaParser AST）
     */
    private void extractEndpoints(CompilationUnit cu, File file,
                                  List<EndpointInfo> endpoints) {
        String classPath = cu.findAll(ClassOrInterfaceDeclaration.class).stream()
            .filter(c -> c.isAnnotationPresent("RestController")
                      || c.isAnnotationPresent("Controller"))
            .findFirst()
            .map(c -> c.getAnnotationByName("RequestMapping")
                .map(a -> extractAnnotationValue(a.toString()))
                .orElse(""))
            .orElse("");

        cu.findAll(MethodDeclaration.class).stream()
            .filter(m -> m.isAnnotationPresent("GetMapping")
                      || m.isAnnotationPresent("PostMapping")
                      || m.isAnnotationPresent("PutMapping")
                      || m.isAnnotationPresent("DeleteMapping"))
            .forEach(m -> {
                String httpMethod = "";
                String path = "";

                if (m.isAnnotationPresent("GetMapping")) {
                    httpMethod = "GET";
                    path = extractAnnotationValue(
                        m.getAnnotationByName("GetMapping").get().toString());
                } else if (m.isAnnotationPresent("PostMapping")) {
                    httpMethod = "POST";
                    path = extractAnnotationValue(
                        m.getAnnotationByName("PostMapping").get().toString());
                } // ... PutMapping, DeleteMapping

                String fullPath = classPath.replaceAll("/$", "") + "/" + path.replaceAll("^/", "");
                endpoints.add(EndpointInfo.builder()
                    .method(httpMethod)
                    .path(fullPath)
                    .function(m.getNameAsString())
                    .file(file.getName())
                    .build());
            });
    }

    /**
     * 提取枚举定义
     */
    private void extractEnums(CompilationUnit cu, File file,
                              List<EnumInfo> enums) {
        cu.findAll(EnumDeclaration.class).forEach(enumDecl -> {
            List<EnumValue> values = new ArrayList<>();
            enumDecl.getEntries().forEach(entry -> {
                values.add(EnumValue.builder()
                    .name(entry.getNameAsString())
                    .value(String.valueOf(values.size()))
                    .build());
            });
            enums.add(EnumInfo.builder()
                .name(enumDecl.getNameAsString())
                .type("enum")
                .values(values)
                .file(file.getName())
                .build());
        });

        // 也提取常量类
        cu.findAll(ClassOrInterfaceDeclaration.class).stream()
            .filter(c -> !c.isInterface())
            .forEach(cls -> {
                List<EnumValue> constants = new ArrayList<>();
                cls.getFields().stream()
                    .filter(f -> f.isStatic() && f.isFinal())
                    .forEach(f -> f.getVariables().forEach(v -> {
                        v.getInitializer().ifPresent(init -> {
                            constants.add(EnumValue.builder()
                                .name(v.getNameAsString())
                                .value(init.toString())
                                .build());
                        });
                    }));
                if (constants.size() >= 3) {
                    enums.add(EnumInfo.builder()
                        .name(cls.getNameAsString())
                        .type("constants")
                        .values(constants)
                        .file(file.getName())
                        .build());
                }
            });
    }
}

@Service
public class XmindService {

    @Value("${app.output-dir:outputs}")
    private String outputDir;

    private final ObjectMapper objectMapper = new ObjectMapper();

    /**
     * 生成 XMind 文件
     */
    public String generateXmind(List<TestCase> testCases, String projectName) throws IOException {
        Files.createDirectories(Paths.get(outputDir));

        // 文件名（ASCII 安全处理）
        String timestamp = LocalDateTime.now()
            .format(DateTimeFormatter.ofPattern("yyyyMMdd_HHmmss"));
        String safeName = projectName.replaceAll("[^a-zA-Z0-9_]", "");
        if (safeName.isEmpty()) safeName = "project";
        String filename = safeName + "_testcases_" + timestamp + ".xmind";
        String filePath = Paths.get(outputDir, filename).toString();

        // 按模块组织用例
        Map<String, List<TestCase>> modules = testCases.stream()
            .collect(Collectors.groupingBy(TestCase::getModule));

        // 构建脑图节点树
        List<Map<String, Object>> children = new ArrayList<>();
        for (Map.Entry<String, List<TestCase>> entry : modules.entrySet()) {
            Map<String, Object> moduleNode = buildModuleNode(entry.getKey(), entry.getValue());
            children.add(moduleNode);
        }

        Map<String, Object> rootTopic = Map.of(
            "id", UUID.randomUUID().toString().replace("-", "").substring(0, 24),
            "class", "sheet",
            "title", "测试用例",
            "rootTopic", Map.of(
                "id", UUID.randomUUID().toString().replace("-", "").substring(0, 24),
                "title", projectName + " 测试用例",
                "children", Map.of("attached", children)
            )
        );

        // 写入 ZIP 文件
        try (ZipOutputStream zos = new ZipOutputStream(
                new FileOutputStream(filePath))) {
            // content.json
            zos.putNextEntry(new ZipEntry("content.json"));
            zos.write(objectMapper.writeValueAsBytes(List.of(rootTopic)));
            zos.closeEntry();
            // metadata.json
            zos.putNextEntry(new ZipEntry("metadata.json"));
            zos.write(objectMapper.writeValueAsBytes(Map.of(
                "creator", Map.of("name", "System-Aware Test Agent", "version", "1.0.0")
            )));
            zos.closeEntry();
            // manifest.json
            zos.putNextEntry(new ZipEntry("manifest.json"));
            zos.write(objectMapper.writeValueAsBytes(Map.of(
                "file-entries", Map.of("content.json", Map.of(), "metadata.json", Map.of())
            )));
            zos.closeEntry();
        }

        return filePath;
    }
}

## 七、Agent 流程设计

### 7.1 代码分析流程

```
AnalysisService.runAnalysis(projectId, sourcePath)  [@Async]
  │
  ├─ 1. 更新项目状态 → analyzing
  │
  ├─ 2. ProjectScanner.scan(sourcePath)
  │     ├─ 识别含 package.json 的目录 → 前端候选
  │     └─ 识别含 pom.xml / src/main/java 的目录 → 后端候选
  │
  ├─ 3. VueAnalyzer.analyze(frontendDir)
  │     ├─ detectTechStack()     → 检测 Vue 版本、UI 框架
  │     ├─ extractRoutes()       → 从 router 文件提取路由（正则）
  │     └─ extractApiCalls()     → 从 api 文件提取接口调用（正则）
  │
  ├─ 4. SpringAnalyzer.analyze(backendDir)
  │     ├─ detectTechStack()     → 检测 MyBatis、Shiro 等
  │     ├─ extractEndpoints()    → JavaParser 解析 Controller
  │     ├─ extractEnums()        → JavaParser 解析枚举/常量
  │     ├─ extractEntities()     → JavaParser 解析实体类
  │     └─ extractBusinessRules() → JavaParser 解析 if/throw
  │
  ├─ 5. StateMachineAgent.extract(backendResult)
  │     ├─ 将枚举 + 业务规则 JSON 序列化传入 LLM
  │     ├─ LlmService.chatJson() → LLM 推断状态机
  │     └─ LLM 失败时降级为规则提取
  │
  ├─ 6. 保存分析结果和状态机到 H2 数据库
  │
  └─ 7. 更新项目状态 → analyzed
```

### 7.2 测试用例生成流程

```
TestCaseService.runGenerate(projectId, request)  [@Async]
  │
  ├─ 1. 更新项目状态 → generating
  │
  ├─ 2. 从数据库读取状态机和分析结果
  │
  ├─ 3. TestGeneratorAgent.generate(stateMachines, backendResult)
  │     ├─ 构建提示词（状态机 + API + 业务规则）
  │     ├─ LlmService.chatJson() → LLM 生成用例
  │     └─ LLM 失败时降级为规则生成
  │
  ├─ 4. 为每个用例分配 ID（TC-001, TC-002...），保存到数据库
  │
  └─ 5. 更新项目状态 → completed
```

### 7.3 LLM 调用降级策略

```
优先调用 LLM API (LlmService.chatJson)
    ↓ 成功
使用 LLM 返回结果
    ↓ 失败（超时/限流/格式错误）
使用规则引擎降级提取
    ↓
返回结果（confidence 降低标记）
```

## 九、Python版 vs Java版 对比

| 维度 | Python 版 (v1.0) | Java 版 (v2.0) | 影响 |
|------|-------------------|-----------------|------|
| 语言 | Python 3.11 | Java 17 | 类型安全，编译期检查 |
| Web 框架 | FastAPI | Spring Boot 3.2 | 企业级生态更完善 |
| 代码解析 | javalang (简单) | JavaParser (AST完整) | 解析精度更高 |
| 数据库 | SQLite | H2 | 都嵌入式，JPA 兼容性更好 |
| ORM | 手写 SQL | Spring Data JPA | 自动 CRUD，少写代码 |
| 异步任务 | BackgroundTasks | @Async + 线程池 | 线程池可配置，更可控 |
| JSON 处理 | json 标准库 | Jackson | 性能更好 |
| 构建工具 | pip | Maven | 依赖锁定更可靠 |
| Docker 镜像 | python:3.11-slim (~150MB) | eclipse-temurin:17-jre (~250MB) | 略大但可接受 |
| 启动速度 | ~1秒 | ~3秒 | Spring Boot 稍慢 |
| 运行性能 | 解释执行 | JIT 编译 | 长期运行更优 |
| API 接口 | 完全一致 | 完全一致 | 前端无需改动 |
| 数据结构 | 完全一致 | 完全一致 | 数据库可直接迁移 |
