## 1. 改动总览

新增 `FilesystemController`，提供目录列表 API，供前端目录选择器懒加载调用。

## 2. 改动点

### 2.1 新增 `controller/FilesystemController.java`

```java
@RestController
@RequestMapping("/api/filesystem")
@CrossOrigin
public class FilesystemController {

    @GetMapping("/dirs")
    public ApiResponse<List<DirItem>> listDirs(@RequestParam(required = false) String path) {
        List<DirItem> items = new ArrayList<>();
        if (path == null || path.isBlank()) {
            // 返回系统根盘符（Windows: C:\, D:\ 等）
            File[] roots = File.listRoots();
            for (File root : roots) {
                items.add(new DirItem(root.getPath(), root.getPath(), false));
            }
        } else {
            // 安全：规范化路径，拒绝路径遍历
            Path normalized = Paths.get(path).normalize();
            if (normalized.toString().contains("..")) {
                throw new IllegalArgumentException("非法路径");
            }
            File dir = normalized.toFile();
            if (dir.exists() && dir.isDirectory()) {
                File[] children = dir.listFiles(File::isDirectory);
                if (children != null) {
                    Arrays.sort(children, Comparator.comparing(File::getName, String.CASE_INSENSITIVE_ORDER));
                    for (File child : children) {
                        items.add(new DirItem(child.getName(), child.getAbsolutePath(), false));
                    }
                }
            }
        }
        return ApiResponse.success(items);
    }
}
```

### 2.2 新增 `dto/DirItem.java`

```java
@Data
@AllArgsConstructor
@NoArgsConstructor
public class DirItem {
    private String name;    // 目录名
    private String path;    // 完整路径
    private boolean isLeaf; // 是否叶子节点（暂不预判，前端懒加载）
}
```

## 3. API 契约

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/filesystem/dirs` | 列出目录。`path` 为空返回根盘符，非空返回子目录 |

返回格式：
```json
{
  "code": 200,
  "data": [
    { "name": "src", "path": "C:\\project\\src", "leaf": false }
  ]
}
```

## 4. 安全考虑

- 路径规范化（`Paths.get(path).normalize()`）防止 `../` 遍历
- 只返回目录，不返回文件
- 本地工具，不做权限控制
