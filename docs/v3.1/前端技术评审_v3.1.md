**版本**: v3.1

## 1. 改动总览

新增 `DirSelector.vue` 目录选择器组件（el-popover + el-tree 懒加载），集成到 `ProjectCreate.vue` 项目路径输入框旁的"浏览"按钮；优化创建表单界面。

## 2. 改动点

### 2.1 新增 `api/filesystem.js`

```js
import request from './request'

export function getDirs(path) {
  return request.get('/api/filesystem/dirs', {
    params: { path: path || undefined }
  })
}
```

### 2.2 新增 `components/DirSelector.vue`

el-popover + el-tree 懒加载目录树：

```vue
<template>
  <el-popover v-model:visible="visible" placement="bottom-start" :width="400" trigger="click">
    <template #reference>
      <el-button :icon="FolderOpened" @click="visible = true">浏览</el-button>
    </template>
    <div class="dir-selector">
      <div class="dir-toolbar">
        <el-button size="small" text @click="goUp" :disabled="!currentPath">返回上级</el-button>
        <span class="current-path">{{ currentPath || '根目录' }}</span>
      </div>
      <el-tree
        ref="treeRef"
        :data="treeData"
        :props="{ label: 'name', children: 'children' }"
        lazy
        :load="loadNode"
        node-key="path"
        highlight-current
        @node-click="handleNodeClick"
        style="max-height: 300px; overflow-y: auto"
      />
      <div class="dir-actions">
        <el-button size="small" @click="visible = false">取消</el-button>
        <el-button size="small" type="primary" @click="confirmSelect">确定</el-button>
      </div>
    </div>
  </el-popover>
</template>
```

核心逻辑：
- `loadNode(node, resolve)`：调用 `getDirs(node.data?.path)` 获取子目录，传给 `resolve()`
- 根节点：调用 `getDirs()` 获取盘符列表
- `handleNodeClick(data)`：记录选中路径
- `confirmSelect()`：emit `select` 事件回传路径

### 2.3 修改 `views/ProjectCreate.vue`

项目路径输入框加 append 按钮：

```vue
<el-form-item v-if="form.sourceType !== 'none'" label="项目路径" prop="sourcePath">
  <el-input v-model="form.sourcePath" placeholder="请输入项目源码路径">
    <template #append>
      <DirSelector @select="handleDirSelect" />
    </template>
  </el-input>
</el-form-item>
```

```js
import DirSelector from '@/components/DirSelector.vue'

function handleDirSelect(path) {
  form.sourcePath = path
}
```

### 2.4 界面优化

- 表单卡片加 `shadow="hover"`
- 表单宽度从 600px 调整为 640px
- 按钮区增加间距
- 来源类型和项目路径之间增加分割提示

## 3. 数据流

```
点击"浏览" → DirSelector 弹出 popover
  → el-tree lazy load → getDirs(path) → 后端 GET /api/filesystem/dirs
  → 选中目录 → 点击"确定" → emit select(path)
  → ProjectCreate form.sourcePath = path
```
