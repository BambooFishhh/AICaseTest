# 前端技术评审 v8.9.4 — 媒体鉴权切换短期票据（任务 12.10/N2）

> 版本 v8.9.4，一旦确定尽量不要轻易改动。基线 v8.9.3。本版唯一前端变更点。

## 一、变更点

### api/execution.js

```js
// 旧：URL 拼 localStorage 长期 JWT
getExecutionVideoUrl(eid)            → ?token=<12h JWT>
getExecutionFileUrl(eid, path)       → &token=<12h JWT>

// 新（v8.9.4）：签名追加 ticket 参数；新增 ensureMediaTicket()
getExecutionVideoUrl(eid, ticket)    → ?ticket=<短期>
getExecutionFileUrl(eid, path, ticket)
export async function ensureMediaTicket()   // 复用 fetchSseTicket，TTL 内可复用
```

不再读取 localStorage——长期 JWT 不进 URL。

### views/ExecutionResult.vue

- 新增 `mediaTicket = ref('')`；onMounted 即调 ensureMediaTicket 异步填充（失败静默，媒体区显示空不阻断页面）；
- currentFrameUrl / recordingVideoUrl / screenshotUrl 三处构造追加 mediaTicket.value；recordingVideoUrl 增加"票据就绪"条件避免空 ticket 先行请求。

## 二、数据流

```
onMounted → ensureMediaTicket() → mediaTicket.value = t
→ <video :src="recordingVideoUrl"> / 截图 URL 自动带上 ?ticket=
→ JwtAuthFilter 媒体白名单校验 ticket 放行
```

TTL 300s 内页面停留无需刷新；超时后再次进入页面重新取票。

## 三、兼容性

- downloadAuth/openAuthPreview 走 Authorization 头不受影响；
- 其余视图未引用这两个 builder（全量检索确认仅 ExecutionResult.vue 使用）。
