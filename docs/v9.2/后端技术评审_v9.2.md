# 后端技术评审 v9.2 — 用例人话化 + 执行器导航与断言修复

> 版本 v9.2，一旦确定尽量不要轻易改动。基线 v9.1。

## 一、变更点

### 1.1 生成链路（TestGeneratorAgent，+420）

- **skill 漂移根因修复**：`skills/test-generation-prd-footer.md` 重写（v5.13 旧文件此前覆盖代码 prompt）——步骤 type 白名单 ui_action/input/state_assert、target 人话描述、禁止 api_call；
- **FEW_SHOT_EXAMPLES 全 UI 化**：旧示例含 3 个 api_call 示例，"示例即行为"必须与执行器能力一致；
- **normalizeModules(result, prdResult, frontendResult)**：模块名候选互包含（"收藏管理"⊂"我的收藏管理"）+ 批内词干投票归一，消除模块碎片化；
- **injectRouteSelectors(result)**：路由形态 target 注入 `uiSelector={type:"route", value:path}`，路由仅从 frontendResult.routes 真实清单选取；
- **范围上下文顺序修复**：`[Scope] endpoint context` = 范围目标集合全量（`scopeRoutePaths`/`coveredEndpointIds`），绕过 G17 关键词过滤。

### 1.2 UiLanguageLinter（+87）

新增检查：接口化话术（调用/请求/POST 路径）、变量占位符裸露（{var}/独立 N/X）、api_call 步骤、断言缺引号文案锚点、引号内占位符提示（`quotedPlaceholders` 供 lint 报告）。

### 1.3 评审层（TestCaseReviewAgent / skills/ai-review.md）

- 全 api_call 用例直接拒绝（评审层兜底，不依赖 LLM 自觉）；
- ai-review.md 增加 v9.2 检查项（与代码 fallback 口径一致）。

### 1.4 执行器（ExecutionService / ExecutionAgent）

- **urlHitsRoute(url, key)**：`#` 后才是路由段——修复 `base/collect#/` 假通过（path 段残留、hash 停首页）；
- **navigateToRoute(sessionId, baseUrl, route)**：结构化模式 route 选择器走确定性导航，history 形式（base/route）未命中自动尝试 hash 形式（base/#/route）；Agent 模式 hash 兜底同步生效。

### 1.5 断言（ExecutionAssert）

- **抽象断言诚实降级**：无引号锚点且命中 ASSERT_VAGUE（加载完成/至少一个/不再显示…）→ skipped，不误报 failed；
- **占位符语义匹配**：引号短语含 `\b[A-Z]\b` 或 `{var}` 时 `placeholderPhraseRegex`——字面段原样 + 占位符段 `\d+`（'共 N 件收藏' → /共 \d+ 件收藏/）。
