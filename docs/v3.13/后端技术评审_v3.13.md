### 2. 聚焦类型过滤

`TestGeneratorAgent.java`：

```java
// 包装 caseCb：仅透传聚焦类型（SSE 与落库一致）
private CaseCallback wrapFocusFilter(GenerationParams params, CaseCallback caseCb) {
    if (caseCb == null || params == null || params.getFocusTypes() == null || params.getFocusTypes().isEmpty()) {
        return caseCb;
    }
    return tc -> {
        if (params.getFocusTypes().contains(tc.getType())) {
            caseCb.onCase(tc);
        }
    };
}
```

- `generate(...)` 返回前按 focusTypes 过滤
- `generateStreaming(...)`：用 `wrapFocusFilter` 替换 caseCb 透传，返回前过滤
- 追加生成复用 generateStreaming，自动生效
