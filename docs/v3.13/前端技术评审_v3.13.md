# 前端技术评审 v3.13

**版本**：v3.13，一旦确定尽量不要轻易改动
**日期**：2026-08-12

## 变更点

### 1. 报告预览

- `ExecutionResult.vue` / `BatchResult.vue`：新增"预览报告"按钮（`/report` inline），原"下载报告"改为 `?download=1`
- `ExecutionHistory.vue`："报告"操作按钮改为 inline 预览

### 2. 用例资产入口（TestCaseList.vue）

- 新增 `downloadBlob(blob, filename)` 工具（URL.createObjectURL）
- 工具栏新增：
  - "导出"下拉：JSON / CSV → `exportTestCases(projectId, format, selectedIds)`
  - "导入 JSON"：隐藏 file input → `importTestCases`
  - "复制到"：对话框选择目标项目（`listProjects`）→ `copyToProject`
- 生成参数对话框提示语更新

## 数据流

- 导出：选中 ids（无选中则全部）→ exportTestCases → blob → 下载
- 复制：ids + targetProjectId → copyToProject → 消息提示

## 向后兼容性

报告 URL 默认行为从下载变为预览，属预期变更；下载按钮显式传 download=1。
