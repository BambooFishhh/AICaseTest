# AICaseTest 运维手册

> vT9：部署、升级、备份、恢复、监控与排障基线。

## 1. 部署

### 1.1 生产全栈（Docker Compose）

```bash
cp .env.example .env
# 编辑 .env：LLM_API_KEY、APP_JWT_SECRET、MYSQL_*、REDIS_PASSWORD 等
docker-compose up -d --build
```

服务组成：

- `aicasetest-mysql`：MySQL 8，宿主端口 3308，Flyway 管理 schema
- `aicasetest-redis`：Redis 7，开启 AUTH
- `etcd` / `minio` / `aicasetest-milvus`：Milvus standalone
- `test-agent-backend`：Spring Boot，prod profile，端口 8000
- `test-agent-frontend`：Nginx，端口 80
- `aicasetest-prometheus`：Prometheus，端口 9090（本机）
- `aicasetest-grafana`：Grafana，端口 3001（本机），预置 AICaseTest SLO 仪表盘

### 1.2 本地开发

```bash
cd backend
mvn spring-boot:run -Dmaven.repo.local=../.m2-repo
cd frontend
npm ci && npm run dev
```

本地默认 H2 + 内存运行态；需要 Redis/Milvus 时设置 `APP_REDIS_ENABLED=true` 等。

## 2. 升级

1. 备份数据库与输出目录（见第 3 节）。
2. 拉取新代码并重新构建镜像。
3. 启动新版本，后端自动执行 Flyway 迁移。
4. 检查 `/api/health` 与 `/actuator/health`。
5. 验证登录、项目列表、用例生成/执行冒烟。

## 3. 备份与恢复

### 3.1 手动备份

```powershell
.\scripts\backup-v5.ps1 -MysqlContainer aicasetest-mysql -MysqlPassword aicasetest123
```

生成 `backups/app-backup-{时间戳}/`，包含 `data/`、`outputs/` 与 `mysql.sql`。

### 3.2 恢复

1. 恢复 H2 开发数据：将备份中 `data/` 覆盖回 `data/`。
2. 恢复 MySQL：

```bash
docker exec -i aicasetest-mysql mysql -uaicasetest -paicasetest123 aicasetest < mysql.sql
```

3. 恢复输出文件：将备份 `outputs/` 覆盖回 `outputs/`。

## 4. 监控

- 健康：`GET /api/health`（含 dataSource/redis/milvus）
- Actuator：`GET /actuator/health`（免认证）、`GET /actuator/metrics`、`GET /actuator/prometheus`（认证）
- 指标采集：Prometheus 抓取 `/actuator/prometheus`，可对接 Grafana
- 仪表盘：`http://127.0.0.1:3001`，账号见 `.env` 的 `GRAFANA_ADMIN_USER/PASSWORD`
- 告警规则：`monitoring/prometheus/alerts.yml`（宕机/5xx/P95/队列积压）
- 链路定位：响应头 `X-Trace-Id`，日志中 `trace_id` 字段
- 队列：`GET /api/tasks/stats` 查看生成/执行排队与运行
- 数据健康（ADMIN）：`GET /api/admin/data/health` 表计数、孤儿数据、Milvus 行数

## 4.1 GHCR 发布与回滚

- 推送 `v*` tag 或手动触发 `.github/workflows/publish.yml`，镜像进入 GHCR。
- 部署：`.\scripts\deploy.ps1 -Environment staging -Tag <tag>`，环境文件为 `.env.<env>`。
- 回滚：`.\scripts\rollback.ps1 -Environment staging -PreviousTag <上一tag>`；数据库结构回滚使用 `.\scripts\mysql-restore.ps1` 恢复备份。
- Flyway 发布前演练：`.\scripts\flyway-staging-drill.ps1 -Password <密码> -MysqlPort 3308`。

## 5. 排障

| 现象 | 检查项 |
|---|---|
| 后端启动失败 | 看 `backend/target/*.log`；确认 MySQL/Redis 健康；Flyway 失败看 `flyway_schema_history` |
| 登录失败 | Redis AUTH 密码是否与 `REDIS_PASSWORD` 一致；`rt:login:*` 是否误锁 |
| 用例执行失败 | 确认 `playwright-mcp-server` 子进程存在；浏览器是否安装（`npx playwright install chromium`） |
| SSE 无进度 | 确认 Nginx 已关闭 proxy_buffering；`?token=` 是否有效 |
| Milvus 不可用 | `APP_MILVUS_ENABLED=true` 时检查 `aicasetest-milvus` 健康；语义功能会自动降级 |

## 6. 安全默认配置

- `.env` 不提交；`.env.example` 提供模板。
- Redis 默认开启 AUTH（`REDIS_PASSWORD`）。
- Nginx 开启安全响应头、登录接口限流、上传大小限制。
- CI：gitleaks 密钥扫描、`npm audit` 生产依赖审计、Docker 镜像构建校验。
- 生产建议：修改 `APP_JWT_SECRET`、`APP_ADMIN_PASSWORD`、MySQL/Redis 密码，并为 MySQL 使用最小权限账号。
