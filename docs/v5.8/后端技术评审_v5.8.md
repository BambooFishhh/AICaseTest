# 后端技术评审 v5.8：数据治理与可观测

> 版本 v5.8，一旦确定尽量不要轻易改动。

## 1. 变更点

### 1.1 保留策略

```java
@Scheduled(cron = "${app.retention.cron:0 0 3 * * *}")
public void cleanOldExecutions() {
    if (retentionDays <= 0) return;
    List<ExecutionRecord> old = executionRecordRepository
            .findByEndTimeBeforeAndStatusIn(cutoff, List.of("passed", "failed", "cancelled"));
    executionStepRepository.deleteAll(executionStepRepository.findByExecutionIdIn(ids));
    deleteRecordingFiles(old);
    executionRecordRepository.deleteAll(old);
}
```

### 1.2 数据健康

- `DataHealthService`：统计 13 张表 count；计算 4 类孤儿；Milvus 三集合 row_count。
- `DataHealthController`：`GET /api/admin/data/health`。
- `SecurityConfig`：`/api/admin/**` 加入 ADMIN 白名单。

### 1.3 dry-run

```java
if (dryRun) {
    try (Connection src = sourceConnection()) {
        for (String table : TABLES) {
            if (tableExists(src, table)) log.info("[DRY-RUN] {} rows={}", table, count(src, table));
        }
    }
    return;
}
```
