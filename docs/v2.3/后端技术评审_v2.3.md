# 后端技术评审文档 v2.3 — LLM 调用全量拆分到 MCP Server

**版本**: v2.3（后端 + MCP Server）
**基线**: v2.2
**日期**: 2026-08-09
一旦确定尽量不要轻易改动

---

## 一、改动概览

### v2.2 架构
```
Agent → LlmService → OkHttp → OpenAI API    （文本对话）
Agent → McpBridgeService → McpClient → MCP Server → OpenAI Vision API  （视觉识别）
```

### v2.3 架构
```
Agent → LlmService → McpClient → MCP Server → OpenAI API    （全部 LLM 调用）
```

LlmService 从"直接调 OpenAI API"变为"通过 MCP 协议调 MCP Server"。

## 二、MCP Server 改动

文件：`mcp-server/index.js`

新增 2 个工具：

### 2.1 llm_chat
```javascript
{
  name: 'llm_chat',
  description: 'LLM 文本对话',
  inputSchema: {
    type: 'object',
    properties: {
      system_prompt: { type: 'string' },
      user_prompt: { type: 'string' },
      temperature: { type: 'number', default: 0.7 }
    },
    required: ['system_prompt', 'user_prompt']
  }
}
```
内部实现：调 `client.chat.completions.create()`，返回 `content[0].text`。

### 2.2 llm_chat_with_image
```javascript
{
  name: 'llm_chat_with_image',
  description: 'LLM 多模态对话（图片+文本）',
  inputSchema: {
    type: 'object',
    properties: {
      system_prompt: { type: 'string' },
      user_text: { type: 'string' },
      image_base64: { type: 'string' }
    },
    required: ['system_prompt', 'user_text', 'image_base64']
  }
}
```
内部实现：构造 content 数组（text + image_url），调 Vision API。

## 三、LlmService 重构

文件：`service/LlmService.java`

### 3.1 依赖变更
```java
// v2.2: OkHttp 直调
@Autowired private OkHttpClient httpClient;
// v2.3: 改为 MCP 客户端
@Autowired private McpClient mcpClient;
```

### 3.2 方法实现变更

```java
// chat() — 从 OkHttp 改为 MCP
public String chat(String systemPrompt, String userPrompt, double temperature) {
    // v2.3: 通过 MCP 协议调用
    String result = mcpClient.callTool("llm_chat", Map.of(
        "system_prompt", systemPrompt,
        "user_prompt", userPrompt,
        "temperature", temperature
    ));
    return result;
}

// chatJson() — 复用 chat() + JSON 解析
public Map<String, Object> chatJson(String systemPrompt, String userPrompt, double temperature) {
    String response = chat(systemPrompt, userPrompt, temperature);
    return objectMapper.readValue(response, Map.class);
}

// chatWithImage() — 从 OkHttp 改为 MCP
public String chatWithImage(String systemPrompt, String userText, String imageBase64) {
    return mcpClient.callTool("llm_chat_with_image", Map.of(
        "system_prompt", systemPrompt,
        "user_text", userText,
        "image_base64", imageBase64
    ));
}

// isConfigured() — 从检查 apiKey 改为检查 MCP 可用性
public boolean isConfigured() {
    return mcpClient.isAvailable();
}

// testConnection() — 试调 llm_chat
public String testConnection() {
    return chat("You are a test assistant.", "Reply: OK", 0.1);
}
```

### 3.3 重试逻辑保留
- LlmService 的重试逻辑保留在 Java 侧
- MCP 调用失败时重试（与 v2.2 相同的指数退避）
