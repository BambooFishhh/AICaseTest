# 前端技术评审 v5.10

**版本**: v5.10
**主题**: PRD 上下文改版与用例级执行历史
**基线**: v5.9 / vP5

> 本评审文档对应 v5.10 前端实现，一旦确定尽量不要轻易改动。

## 一、变更点 + 模板/脚本片段

### 1.1 PrdPanel：其他上下文信息

“额外 Prompt”改名“其他上下文信息”，加载时兼容新旧字段：

```js
otherContextInfo.value = res.data?.otherContextInfo ?? res.data?.extraPrompt ?? ''
```

保存时统一提交新字段：

```js
await updateProjectContext(props.projectId, {
  otherContextInfo: otherContextInfo.value,
  contextDocs: contextDocs.value.map(({ id, title, content, sourceType, sourceRef }) => ({
    id, title, content, sourceType, sourceRef
  }))
})
```

### 1.2 PrdPanel：上下文文档 PRD 式录入

文档对象扩展为 `id/title/content/sourceType/sourceRef`，新增/编辑弹窗内置与主 PRD 一致的来源切换：

```html
<el-radio-group v-model="docActiveTab" size="default">
  <el-radio-button value="text">文本 / Markdown</el-radio-button>
  <el-radio-button value="md">md / txt 上传</el-radio-button>
  <el-radio-button value="pdf">PDF 上传</el-radio-button>
  <el-radio-button value="link">在线链接</el-radio-button>
</el-radio-group>
```

- `md / txt`：前端 `FileReader` 读取后填入 `docForm.content`。
- `PDF`：调用 `uploadContextDoc(projectId, file)` 获取解析结果。
- `链接`：调用 `fetchContextDocUrl(projectId, url)` 获取抓取结果。
- 保存时要求标题非空，来源字段随文档一起持久化。

### 1.3 用例操作列新增执行历史按钮

```html
<el-tooltip content="执行历史" placement="top">
  <el-button link :icon="Clock" @click.stop="goTestCaseExecutions(row)" />
</el-tooltip>
```

```js
function goTestCaseExecutions(row) {
  router.push({
    path: `/projects/${projectId}/executions`,
    query: { testCaseId: row.id, testCaseTitle: row.title || '' }
  })
}
```

### 1.4 ExecutionHistory：按用例过滤

页面读取查询参数并透传给接口：

```js
const params = { page: page.value, pageSize: pageSize.value }
if (filteredTestCaseId.value) params.testCaseId = filteredTestCaseId.value
const res = await getExecutions(projectId, params)
```

有过滤时展示提示条与“查看全部”：

```html
<el-alert v-if="filteredTestCaseId" :title="filterTitle" type="info" :closable="false" show-icon>
  <el-button link type="primary" @click="clearTestCaseFilter">查看全部</el-button>
</el-alert>
```

`clearTestCaseFilter` 通过 `router.replace({ query: {} })` 清空参数并重新加载。

### 1.5 用例卡片执行记录弹窗（收口已有改动）

- `TestCaseCard` 操作区保留“执行记录”按钮。
- 弹窗内调用 `getExecutions(projectId, { page: 1, pageSize: 20, testCaseId: props.testCase.id })`。
- 行点击跳转 `/projects/{projectId}/executions/{id}`。

## 二、props/emit 变化

- `PrdPanel`：无 props/emit 变化。
- `TestCaseCard`：无 props/emit 变化，新增内部弹窗与本地状态。
- `TestCaseList`：无外部契约变化，新增内部导航函数。
- `ExecutionHistory`：无 props，新增路由查询参数读取。

## 三、数据流

1. `PrdPanel` 加载 `GET /context` → `otherContextInfo` + `contextDocs`（含来源字段）。
2. 文档上传/抓取 → 解析接口返回 `{id,title,content,sourceType,sourceRef}` → 用户确认保存 → `PUT /context` 整体持久化。
3. 用例列表点击“执行历史” → 携带 `testCaseId/testCaseTitle` 跳转执行历史页。
4. 执行历史页 → `GET /executions?testCaseId=` → 后端返回过滤后的 items/stats/trend。

## 四、向后兼容性

- `extraPrompt` 旧数据在 PrdPanel 回显为“其他上下文信息”。
- 旧上下文文档无 `sourceType/sourceRef` 时按“文本”展示，仍可编辑保存。
- 执行历史页无查询参数时保持项目全量视图。
- 用例卡片弹窗为新增独立功能，不影响原有执行流程。

## 五、测试验证方案

1. `npm run build` 必须成功。
2. 手工验证：
   - 保存“其他上下文信息”后刷新页面仍回显。
   - 分别通过文本、md/txt、PDF、链接新增上下文文档并保存。
   - 用例列表“执行历史”按钮跳转后仅展示该用例记录。
   - 执行历史页“查看全部”恢复全量。
   - 用例卡片“执行记录”弹窗只展示该用例记录。
