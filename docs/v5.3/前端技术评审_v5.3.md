# 前端技术评审 v5.3：缓存与任务队列

> 版本 v5.3，一旦确定尽量不要轻易改动。

## 1. 变更点

- 新增 `frontend/src/api/task.js`：`getTaskStats()` 调 `/api/tasks/stats`。
- `Dashboard.vue`：新增"任务队列"区块，展示生成/执行队列的排队与运行计数。
- 不新增路由，不改 axios 拦截器。

## 2. 数据流

```text
Dashboard mounted
  └─ Promise.all([getStatsOverview(), getTaskStats()])
        └─ taskStats → queue-section 渲染
```

## 3. 向后兼容性

- 仪表盘原有统计不变，新卡片为增量展示。
- 非管理员访问仪表盘仍由后端权限拦截。

## 4. 测试验证方案

- `npm run build`。
- 管理员登录仪表盘，确认队列卡片加载且数字变化。
