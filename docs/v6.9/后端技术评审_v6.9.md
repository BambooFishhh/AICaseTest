# 后端技术评审 v6.9

> 版本 v6.9，一旦确定尽量不要轻易改动。主题：高可用收口 - 故障演练与容量。

## 1. 变更点

- Flyway `V10__add_agent_task_events.sql`。
- `entity/AgentTaskEvent.java`、`repository/AgentTaskEventRepository.java`。
- `AgentTaskService`：`update`/恢复/TTL 路径自动 `recordEvent`；新增 `timeline(taskId)`。
- `AgentTaskAdminController`：`GET /api/admin/tasks/{id}/timeline`。
- `scripts/ha-fault-drill.ps1`、`scripts/ha-capacity-drill.ps1`。

## 2. API 契约变化

新增：

```text
GET /api/admin/tasks/{id}/timeline
```

返回 `AgentTaskEvent` 列表（phase/status/attempt/error/createdAt），仅 ADMIN。

## 3. 向后兼容性

- 新增表与接口，不影响现有任务状态机。
- 事件写入失败仅告警，不阻断任务。

## 4. 测试验证方案

- 回归 `mvn verify`、`npm run build`。
- 部署后执行一次重试任务，确认 timeline 有排队/运行/终态事件。
