## 一、架构变更

### v2.1 架构（进程内调用）
```
ExecutionAgent → McpBridgeService（Spring Service）
                   → LlmService.chatWithImage()
                   → OpenAI Vision API
```

### v2.2 架构（MCP 协议调用）
```
ExecutionAgent → McpBridgeService（Spring Service）
                   → McpClient（JSON-RPC 2.0 over stdio）
                   → MCP Server（Node.js 子进程）
                   → OpenAI Vision API
```

### 2.3 index.js — MCP Server
```javascript
import { Server } from '@modelcontextprotocol/sdk/server/index.js';
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';
import OpenAI from 'openai';
import fs from 'fs';

const server = new Server({
  name: 'aicasetest-mcp-server',
  version: '1.0.0',
}, { capabilities: { tools: {} } });

// tools/list — 返回工具定义
server.setRequestHandler(ListToolsRequestSchema, () => ({
  tools: [{
    name: 'multimodal_element_locate',
    description: '多模态视觉识别：截图+自然语言描述→控件位置JSON',
    inputSchema: {
      type: 'object',
      properties: {
        image_path: { type: 'string' },
        element_desc: { type: 'string' },
      },
      required: ['image_path', 'element_desc'],
    },
  }],
}));

// tools/call — 执行工具
server.setRequestHandler(CallToolRequestSchema, async (req) => {
  const { image_path, element_desc } = req.params.arguments;
  const imageBase64 = fs.readFileSync(image_path).toString('base64');
  const response = await openai.chat.completions.create({
    model: process.env.OPENAI_MODEL || 'gpt-4o',
    messages: [/* system + user(image) */],
  });
  return { content: [{ type: 'text', text: response }] };
});
```

### 3.2 McpBridgeService.java（修改）
```java
@Service
public class McpBridgeService {
    @Autowired private McpClient mcpClient;

    public LocateResult multimodalElementLocate(String imagePath, String elementDesc) {
        try {
            String resultJson = mcpClient.callTool("multimodal_element_locate",
                Map.of("image_path", imagePath, "element_desc", elementDesc));
            return parseLocateResult(resultJson);
        } catch (Exception e) {
            return LocateResult.fail("MCP 调用失败: " + e.getMessage());
        }
    }
}
```
