### 1.1 TestCaseList.vue — 表格多选（F4）

文件：`frontend/src/views/TestCaseList.vue`

**现状**：el-table 无 selection 列，无多选能力。

**v1.4**：el-table 新增 selection 列 + `@selection-change` 事件。

```html
<el-table

  border
  style="width: 100%"

  @selection-change="handleSelectionChange"

  <!-- 原有列... -->
```

新增状态：

```js
const selectedRows = ref([])

function handleSelectionChange(rows) {
```

### 1.3 批量删除逻辑

```js
async function handleBatchDelete() {
  const count = selectedRows.value.length
  try {
    await ElMessageBox.confirm(
      `确定要删除选中的 ${count} 条用例吗？此操作不可撤销。`,
      '确认批量删除',
      { confirmButtonText: '确定删除', cancelButtonText: '取消', type: 'warning' }
    )
  } catch {
    return
  }
  try {
    const ids = selectedRows.value.map((tc) => tc.id)
    const res = await batchDeleteTestCases(projectId, ids)
    ElMessage.success(`已删除 ${res.data} 条用例`)
    selectedRows.value = []
    await Promise.all([loadList(), loadAllForStats()])
  } catch {
    // 错误已由响应拦截器统一提示
  }
}
```

### 1.4 批量导出选中（F5）

```js
async function handleExportSelected() {
  const ids = selectedRows.value.map((tc) => tc.id)
  try {
    await generateMindmap(projectId, { testcaseIds: ids })
    ElMessage.success('选中用例脑图生成成功')
  } catch {
    // 错误已由响应拦截器统一提示
  }
}
```

### 1.5 api/testcase.js — 新增批量删除

```js
export function batchDeleteTestCases(projectId, ids) {
  return request.delete(`/projects/${projectId}/testcases/batch`, { data: { ids } })
}
```

### 1.6 api/mindmap.js — 扩展 generateMindmap

```js
export function generateMindmap(projectId, data) {
  return request.post(`/projects/${projectId}/mindmap`, data || {})
}
```

（现有 generateMindmap 签名已兼容，只需确认传入 data 参数即可。）

## 三、交互细节

### 3.1 批量操作按钮状态

| 场景 | 批量删除 | 导出选中 |
|------|----------|----------|
| 未选中任何行 | 禁用 | 禁用 |
| 选中 1+ 行 | 启用，显示数量 | 启用，显示数量 |
| 删除/导出中 | loading | loading |
| 操作完成 | 清空选中，刷新列表 | 保持选中 |

### 3.2 行点击与多选冲突处理

- 点击 checkbox 区域：触发多选，不打开详情
- 点击行其他区域：打开详情对话框（现有行为不变）
- el-table 的 `type="selection"` 列会自动阻止行点击事件冒泡
