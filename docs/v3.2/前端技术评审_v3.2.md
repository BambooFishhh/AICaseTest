## 1. 改动总览

新增 `streamGenerate` API 封装（基于浏览器原生 `EventSource`），改造 `TestCaseList.vue` 的"重新生成"为流式模式（实时显示进度 + 逐条入表），`ProjectDetail.vue` 的"生成用例"改为跳转 TestCaseList 并带 `?generate=1` 自动触发流式生成。

## 2. 改动点

### 2.1 新增 `api/testcase.js` — streamGenerate

```js
// v3.2: SSE 流式生成。基于 EventSource，返回事件源对象供调用方 close()
export function streamGenerate(projectId, { onProgress, onCase, onComplete, onError } = {}) {
  const url = `/api/projects/${projectId}/testcases/generate-stream`
  const es = new EventSource(url)

  es.addEventListener('progress', (e) => {
    try { onProgress?.(JSON.parse(e.data).message) } catch {}
  })
  es.addEventListener('case', (e) => {
    try { onCase?.(JSON.parse(e.data).testCase) } catch {}
  })
  es.addEventListener('complete', (e) => {
    try { onComplete?.(JSON.parse(e.data).total) } catch {}
    es.close()
  })
  es.addEventListener('error', (e) => {
    // SSE 原生 onerror：data 可能为空（网络断开）或携带后端 error 事件 data
    let msg = '生成连接异常'
    if (e.data) {
      try { msg = JSON.parse(e.data).message || msg } catch {}
    }
    onError?.(msg)
    es.close()
  })

  return es
}
```

**要点**：
- `EventSource` 仅支持 GET，自动重连机制由浏览器实现（这里我们显式 `close()` 避免重连）
- 后端推送的 `error` 命名事件会触发 `addEventListener('error')`，但 `e.data` 携带我们的 JSON；网络断开时 `e.data` 为空，需区分
- 返回 `es` 供调用方在组件卸载时 `es.close()` 释放

### 2.2 修改 `views/TestCaseList.vue` — 流式生成面板

#### 2.2.1 新增响应式状态

```js
const streaming = ref(false)
const streamProgress = ref('')
const streamedCases = ref([])    // 流式期间实时累积的用例
let streamEs = null              // EventSource 实例，非响应式
```

#### 2.2.2 流式生成函数

```js
async function handleRegenerate() {
  try {
    await ElMessageBox.confirm(
      '即将重新生成测试用例，当前所有用例（含人工修改）将被覆盖删除。确定要继续吗？',
      '确认重新生成',
      { confirmButtonText: '确定生成', cancelButtonText: '取消', type: 'warning' }
    )
  } catch { return }

  // 进入流式模式
  generationError.value = ''
  streaming.value = true
  streamProgress.value = '正在启动生成...'
  streamedCases.value = []
  regenerating.value = true

  streamEs = streamGenerate(projectId, {
    onProgress: (msg) => { streamProgress.value = msg },
    onCase: (tc) => { streamedCases.value.unshift(tc) },
    onComplete: async (total) => {
      ElMessage.success(`用例生成完成，共 ${total} 条`)
      streaming.value = false
      streamProgress.value = ''
      regenerating.value = false
      page.value = 1
      await Promise.all([loadList(), loadAllForStats(), loadCoverageMatrix()])
    },
    onError: (msg) => {
      streaming.value = false
      streamProgress.value = ''
      regenerating.value = false
      generationError.value = msg
      ElMessage.error('用例生成失败')
    }
  })
}
```

#### 2.2.3 流式期间表格数据源切换

// 流式期间展示 streamedCases，否则展示原分页数据
const displayTestCases = computed(() => {

#### 2.2.5 onMounted 自动触发 + onUnmounted 释放

```js
onMounted(async () => {
  await Promise.all([loadList(), loadAllForStats(), loadCoverageMatrix()])
  // v3.2: 来自 ProjectDetail "生成用例"跳转，自动触发流式生成
  if (route.query.generate === '1') {
    // 仅当项目状态允许生成时触发
    const p = projectStore.currentProject
    if (!p || p.status === 'analyzing' || p.status === 'generating') return
    handleRegenerate()
    // 清理 query，避免刷新重复触发
    router.replace({ path: route.path })
  }
})

onUnmounted(() => {
  projectStore.stopPolling()
  // v3.2: 释放 EventSource
  if (streamEs) { streamEs.close(); streamEs = null }
})
```

## 3. 数据流

```
TestCaseList "重新生成" / ProjectDetail "生成用例"
  │
  ├─ [ProjectDetail] router.push('/projects/:id/testcases?generate=1')
  │
  ▼
TestCaseList onMounted
  ├─ loadList + loadAllForStats + loadCoverageMatrix
  └─ route.query.generate==='1' → handleRegenerate()
       │
       ▼
  streamGenerate(projectId, callbacks)
       │  new EventSource('/api/projects/:id/testcases/generate-stream')
       │
       ├─ onProgress → streamProgress.value = msg
       ├─ onCase     → streamedCases.value.unshift(tc)  ← 表格实时更新
       ├─ onComplete → streaming=false; loadList() 拿最终编号
       └─ onError    → streaming=false; generationError=msg
```

## 4. 用户体验细节

| 场景 | 表现 |
|------|------|
| 首条进度到达前 | 按钮 loading + 顶部 alert "正在启动生成..." |
| 进度推送 | alert 描述区显示进度文本（如"基于 PRD 生成用例..."） |
| 用例推送 | 表格顶部逐条插入新行，编号列显示"生成中"，alert 标题实时更新计数 |
| 完成 | alert 消失，表格切换回分页数据（最终编号），ElMessage 提示总数 |
| 失败 | alert 消失，红色 error alert 显示具体错误，ElMessage 提示失败 |
| 流式中刷新/关闭页面 | `onUnmounted` 调 `streamEs.close()`，后端 `onCompletion` 置 clientGone |
| 流式中点其他按钮 | `streaming` 期间禁用分页/导出等操作（按需加 `:disabled="streaming"`） |
