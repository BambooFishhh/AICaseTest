# 后端技术评审 v5.13 — MCP 工具化与 Prompt Skill 化

> 版本：v5.13
> 基线：v5.12
> 主题：MCP 桥接接口 + tools-mcp-server + Prompt Skill 化

## 1. 变更点

### 1.1 MCP 桥接控制器

新增 `McpBridgeController`，统一暴露 6 个只读/工具型能力：

```java
@RestController
@RequestMapping("/api/mcp")
public class McpBridgeController {
    // semantic-search / analyze-requirement-docs / extract-state-machine
    // review-test-cases / analyze-backend / analyze-frontend
}
```

所有接口校验 `X-MCP-Token`，未通过时返回 401。

### 1.2 PromptSkillLoader

新增 `PromptSkillLoader`，从 classpath `skills/{name}.md` 读取 Prompt 模板：

```java
public String load(String name, String fallback) {
    // ClassPathResource("skills/" + name + ".md")
    // 缺失或为空时返回 fallback
}
```

### 1.3 Agent 接入

- `PrdAgent`：PRD 解析 system prompt 改为加载 `prd-analysis.md`
- `StateMachineAgent`：状态机提取与前端增强 prompt 分别加载
- `TestCaseReviewAgent`：AI 评审 prompt 加载 `ai-review.md`
- `TestGeneratorAgent`：代码/PRD 驱动 header/footer 加载对应模板

### 1.4 MCP Server 管理

- `McpClientManager` 新增 `tools` Server 配置
- `application.yml` 新增 `mcp.servers.tools` 与 `app.mcp.bridge-url/bridge-token`
- `tools-mcp-server` 通过 `MCP_BRIDGE_URL`、`MCP_BRIDGE_TOKEN` 访问后端桥接接口

## 3. API 契约变化

新增 6 个内部接口，均需要 `X-MCP-Token`：

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/mcp/semantic-search` | 语义检索 |
| POST | `/api/mcp/analyze-requirement-docs` | 需求文档解析 |
| POST | `/api/mcp/extract-state-machine` | 状态机提取 |
| POST | `/api/mcp/review-test-cases` | 用例评审 |
| POST | `/api/mcp/analyze-backend` | 后端代码分析 |
| POST | `/api/mcp/analyze-frontend` | 前端代码分析 |

## 4. 向后兼容性

- 现有 `/api/**` 业务接口不变
- 现有 llm/playwright MCP Server 不变
- `app.mcp.enabled=false` 时不启动任何 MCP Server
- Skill 文件缺失时回退到原内嵌 Prompt
