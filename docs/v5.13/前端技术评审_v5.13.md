# 前端技术评审 v5.13 — MCP 工具化与 Prompt Skill 化

> 版本：v5.13
> 基线：v5.12
> 主题：前端无功能改动，仅验证构建

## 1. 变更点

本版本为后端能力分层，不修改前端组件、路由、状态管理或 API 调用。

涉及前端构建环境的变化仅来自部署侧：

- 后端镜像新增 `tools-mcp-server` 目录复制与依赖安装
- 不改变前端 Nginx 配置与静态资源

## 2. props / emit 变化

无。

## 3. 数据流

无变化。前端仍通过既有 `/api/projects/**` 调用业务接口。

## 4. 向后兼容性

完全向后兼容，前端无需升级。

## 5. 测试验证方案

- 仓库根目录运行 `npm run build`（等价 `cd frontend && npm run build`）
- 构建成功即通过
