# 后端技术评审 v5.1：H2 → MySQL 全量迁移工具

> 版本 v5.1，一旦确定尽量不要轻易改动。

## 1. 变更点

### 1.1 迁移组件

`com.testagent.migration.H2ToMysqlMigrator`：

- `@Component` + `CommandLineRunner`，`@Order(Ordered.HIGHEST_PRECEDENCE)` 确保先于 `DataInitializer`。
- `@Value("${app.migration.enabled:false}")` 控制开关。
- 方法：`backupH2Files()` → `migrateAll()` → `verifyCounts()` → `writeSummary()`。
- 失败处理：`cleanupTarget(migratedTables)` 反向删除 MySQL 已写入表数据。

```java
@Component
@Order(Ordered.HIGHEST_PRECEDENCE)
public class H2ToMysqlMigrator implements CommandLineRunner {
    private static final List<String> TABLES = List.of(
        "users", "project_groups", "group_members", "projects", "test_cases",
        "test_case_versions", "state_machines", "code_analysis", "mindmaps",
        "test_suites", "execution_record", "execution_step", "system_settings"
    );

    @Override
    public void run(String... args) throws Exception {
        if (!migrationEnabled) return;
        if (rollback) { restoreBackup(); return; }
        backupH2Files();
        try (Connection src = sourceConnection(); Connection dst = targetDataSource.getConnection()) {
            List<String> migrated = new ArrayList<>();
            try {
                for (String table : TABLES) {
                    if (migrateTable(src, dst, table)) migrated.add(table);
                }
                verifyCounts(src, dst);
                writeSummary(migrated);
            } catch (Exception e) {
                cleanupTarget(dst, migrated);
                throw e;
            }
        }
    }
}
```

### 1.2 配置

新增 `application-migrate.yml`：

```yaml
spring:
  profiles:
    include: mysql
app:
  migration:
    enabled: ${APP_MIGRATION_ENABLED:false}
    rollback: ${APP_MIGRATION_ROLLBACK:false}
    backup-dir: ${MIGRATION_BACKUP_DIR:backups}
    source-url: ${H2_MIGRATION_URL:jdbc:h2:file:./data/appdb;DB_CLOSE_DELAY=-1;AUTO_SERVER=TRUE}
    source-user: sa
    source-password: ""
```

### 1.3 SQL 方言处理

- 源 SELECT 列名用 H2 双引号；目标 INSERT 用 MySQL 反引号。
- 保留字列（`action`）由引号包裹，避免方言报错。
- 行写入使用 `PreparedStatement.setObject`，布尔值由 JDBC 驱动适配 BIT(1)。

## 3. API 契约变化

无 REST API 变化；迁移由启动参数触发。

## 4. 向后兼容性

- 默认不启用，不影响现有启动路径。
- H2 文件只在备份时复制，不删除、不覆盖。
- MySQL 目标表需为 v5.0 Flyway 建表后的空库（或人工确认）。

## 5. 测试验证方案

- `mvn compile` BUILD SUCCESS。
- 单元测试：H2 内存库造数 → 迁移逻辑行数校验（如环境允许）。
- 实库冒烟：启动 MySQL（compose）→ `migrate` profile 迁移 → 抽查各表行数。
- 回滚冒烟：设置 rollback=true → 恢复备份文件。
