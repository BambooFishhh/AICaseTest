# 前端技术评审 v6.5

> 版本 v6.5，一旦确定尽量不要轻易改动。主题：高可用 P0 - 任务状态持久化与中断恢复。

## 1. 变更点

- 本版本**无前端源码变更**。
- 后端 `GET /api/tasks/stats` 响应新增 `agentTasks` 状态计数；现有前端任务/批次轮询解析逻辑只读取原有字段，不受影响。
- 新增 `/api/admin/tasks` 管理接口供后续"任务中心"页面使用，v6.5 不新增页面。

## 2. props / emit 变化

无。

## 3. 数据流

- 前端继续通过 `GET /api/tasks/stats` 展示生成/执行队列状态；
- v6.5 在响应中附带 `agentTasks` 状态计数，前端可按需展示或暂不展示。
- 管理端任务列表/详情/重试 API 需 ADMIN 角色访问，前端后续接入时使用现有 axios + Bearer 拦截器。

## 4. 向后兼容性

- `GET /api/tasks/stats` 原字段保持不变，仅新增 `agentTasks` 键；已有调用不做任何改动即可继续工作。
- 新增管理接口不影响现有前端路由与状态管理。

## 5. 测试验证方案

- `npm run build` 回归通过。
- 有权限时手工验证 `/api/tasks/stats` 返回包含 `agentTasks`；无 ADMIN 角色访问 `/api/admin/tasks` 应返回 403。
