## 一、技术栈最终选型

| 组件 | 选型 | 版本 | 理由 |
|------|------|------|------|
| 框架 | Vue 3 | 3.4+ | 当前主流，长期维护 |
| 构建工具 | Vite | 5+ | 开发热更新极快，构建产物小 |

## 三、页面与 API 对接关系

### 3.1 项目列表页（ProjectList.vue）

**页面功能**：展示所有已创建的分析项目

**API 对接**：

| 操作 | 调用接口 | 触发时机 |
|------|----------|----------|
| 加载项目列表 | `GET /api/projects` | 页面 mounted |
| 删除项目 | `DELETE /api/projects/{id}` | 点击删除按钮，二次确认后调用 |

**数据流**：
```
页面加载 → GET /api/projects → 渲染项目卡片列表
                                每张卡片显示：名称、路径、状态、用例数量
点击卡片 → 跳转 /projects/{id}
点击删除 → 确认弹窗 → DELETE /api/projects/{id} → 刷新列表
点击新建 → 跳转 /projects/create
```

**展示字段映射**：

| 展示项 | 数据来源 | 字段 |
|--------|----------|------|
| 项目名称 | 项目对象 | name |
| 项目路径 | 项目对象 | source_path |
| 项目状态 | 项目对象 | status（created/analyzing/analyzed/generating/completed/failed） |
| 状态机数量 | statistics | statistics.state_machines |
| 用例数量 | statistics | statistics.test_cases |
| 创建时间 | 项目对象 | created_at |

**状态显示映射**：

| status | 显示文字 | 标签颜色 |
|--------|----------|----------|
| created | 已创建 | info (灰) |
| analyzing | 分析中... | warning (橙) |
| analyzed | 已分析 | success (绿) |
| generating | 生成中... | warning (橙) |
| completed | 已完成 | success (绿) |
| failed | 失败 | danger (红) |

### 3.3 项目详情页（ProjectDetail.vue）

**页面功能**：项目概览 + 操作入口

**API 对接**：

| 操作 | 调用接口 | 触发时机 |
|------|----------|----------|
| 加载项目详情 | `GET /api/projects/{id}` | 页面 mounted |
| 轮询项目状态 | `GET /api/projects/{id}` | 分析/生成期间每3秒轮询 |
| 触发代码分析 | `POST /api/projects/{id}/analyze` | 点击"开始分析"按钮 |
| 触发用例生成 | `POST /api/projects/{id}/generate` | 点击"生成用例"按钮 |
| 生成XMind | `POST /api/projects/{id}/mindmap/generate` | 点击"生成脑图"按钮 |
| 下载XMind | `GET /api/projects/{id}/mindmap/download` | 点击"下载"按钮 |

**数据流**：

```
页面加载 → GET /api/projects/{id} → 渲染项目信息

操作1：代码分析
  点击"开始分析" → POST /.../analyze → 接收202
    → 启动轮询（3秒间隔）→ GET /api/projects/{id}
    → 检查 status 字段：
        analyzing → 继续轮询，显示进度提示
        analyzed  → 停止轮询，显示分析完成，解锁"生成用例"按钮
        failed    → 停止轮询，显示错误信息

操作2：用例生成
  点击"生成用例" → POST /.../generate → 接收202
    → 启动轮询（3秒间隔）→ GET /api/projects/{id}
    → 检查 status 字段：
        generating → 继续轮询
        completed  → 停止轮询，显示用例统计

操作3：XMind 生成
  点击"生成脑图" → POST /.../mindmap/generate → 显示成功
  点击"下载" → GET /.../mindmap/download → 浏览器下载 .xmind 文件
```

**按钮状态控制**：

| 按钮 | 可用条件 | 说明 |
|------|----------|------|
| 开始分析 | status == created 或 failed | 分析中和已分析时禁用 |
| 生成用例 | status == analyzed 或 completed | 未分析时禁用 |
| 生成脑图 | status == completed 且有测试用例 | 未生成用例时禁用 |
| 下载脑图 | 已生成过 XMind | 未生成时禁用 |
| 查看分析 | status != created | 未分析时禁用 |
| 查看用例 | 有测试用例 | 无用例时禁用 |

**布局**：
```
┌─────────────────────────────────────────┐
│ 项目名称：litemall 商城        [返回列表] │
├─────────────────────────────────────────┤
│ 基本信息                                │
│  路径：E:\java_project\litemall         │
│  状态：[已分析]                         │
│  状态机：3 个    测试用例：85 个         │
├─────────────────────────────────────────┤
│ 操作区                                  │
│  [开始分析]  [生成用例]  [生成脑图]      │
│  [查看分析]  [查看用例]  [下载脑图]      │
├─────────────────────────────────────────┤
│ 进度提示（分析/生成中时显示）            │
│  正在分析代码结构...  ████████░░ 80%    │
```

## 五、API 封装层设计

### 5.1 Axios 实例配置（api/request.js）

```javascript
import axios from 'axios'
import { ElMessage } from 'element-plus'

const request = axios.create({
  baseURL: '/api',   // 通过 Nginx 反向代理到后端
  timeout: 30000      // 30秒超时（LLM调用可能较慢）
})

// 响应拦截
request.interceptors.response.use(
  response => {
    const { code, message, data } = response.data
    // code=0 成功，code=202 异步任务已接受
    if (code === 0 || code === 202) {
      return { code, message, data }
    }
    // 业务错误（40001-50003）
    ElMessage.error(message || '请求失败')
    return Promise.reject(response.data)
  },
  error => {
    // HTTP 级别错误（网络断开、5xx等）
    const msg = error.response?.data?.message || error.message || '网络错误'
    ElMessage.error(msg)
    return Promise.reject(error)
  }
)

export default request
```

## 六、状态管理设计（Pinia）

### 6.1 stores/project.js

```javascript
import { defineStore } from 'pinia'
import { ref } from 'vue'
import { getProject } from '@/api/project'

export const useProjectStore = defineStore('project', () => {
  const currentProject = ref(null)
  const pollingTimer = ref(null)

  // 获取项目详情
  async function fetchProject(id) {
    const res = await getProject(id)
    currentProject.value = res.data
    return res.data
  }

  // 启动轮询（分析/生成期间）
  function startPolling(id, onStatusChange) {
    stopPolling()
    pollingTimer.value = setInterval(async () => {
      const project = await fetchProject(id)
      if (project.status === 'analyzed' || project.status === 'completed' || project.status === 'failed') {
        stopPolling()
        if (onStatusChange) onStatusChange(project.status)
      }
    }, 3000)
  }

  // 停止轮询
  function stopPolling() {
    if (pollingTimer.value) {
      clearInterval(pollingTimer.value)
      pollingTimer.value = null
    }
  }

  return { currentProject, fetchProject, startPolling, stopPolling }
})
```

## 八、Nginx 配置（反向代理）

```nginx
    # 前端静态文件

        root /usr/share/nginx/html;
        index index.html;
        try_files $uri $uri/ /index.html;

    # 后端 API 反向代理
    location /api/ {
        proxy_pass http://backend:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        # LLM调用可能较慢，延长超时
        proxy_read_timeout 120s;
        proxy_connect_timeout 10s;
    }

    # Swagger 文档代理
    location /docs {
        proxy_pass http://backend:8000/docs;
    }
    location /openapi.json {
        proxy_pass http://backend:8000/openapi.json;
    }
}
```
