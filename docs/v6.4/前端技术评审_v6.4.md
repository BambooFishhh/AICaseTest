# 前端技术评审 v6.4 — RAG 切片化与多源检索增强

> 版本 v6.4，一旦确定尽量不要轻易改动。

## 1. 变更点

本版本无前端业务代码变更。RAG 切片、RRF 重排、失败经验注入全部发生在后端生成链路，前端不需要新增 props/emit/API。

## 2. 对外行为

- 生成请求与响应格式不变。
- 由于 RAG 命中内容质量提升，用户可见的间接变化为：长 PRD 尾部约束、上下文文档、历史失败经验对生成用例的约束更准确。
- Milvus 未启用时与 v6.3 行为一致，前端无需感知降级。

## 3. 数据流

```text
前端发起生成
  -> POST /api/projects/{id}/testcases/generate
  -> 后端 OrchestratorAgent 加载 PRD + 上下文文档 + 补充需求
  -> SemanticService 切片索引检索 + RRF 融合
  -> 后端组装 prompt（ragContexts + ragFailures）
  -> SSE 流式返回生成用例（格式不变）
```

## 4. props / emit / 组件变化

无。

## 5. 向后兼容性

前端所有 API 契约保持不变，旧版本浏览器可直接兼容；生成返回的数据结构未改动。

## 6. 测试验证方案

- 运行 `npm run build`，确认构建成功。
- 在 Docker 全栈环境手动发起一次生成，确认 SSE 正常返回。
