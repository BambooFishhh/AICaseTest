# PRD v3.17 — 平台化打磨

**版本**：v3.17
**基线**：v3.16
**日期**：2026-08-12
**主题**：全局仪表盘 + 系统级默认生成参数 + 内嵌 API 文档 + 用例详情抽屉 + 项目内导航/面包屑

## 一、背景与痛点

1. 系统缺少全局"健康度"总览，项目/用例/覆盖率/通过率分散在各页
2. 每个项目都要单独配置生成参数，没有系统级默认
3. 接口文档只靠 README 手写，易过时
4. 用例详情 900px 弹窗承载结构化步骤/数据/版本，已显局促
5. 项目多页面之间靠"返回"跳转，缺少层级导航

## 二、范围

### In scope

- 全局仪表盘（统计卡 + 用例类型分布 + 项目覆盖率）
- 系统级默认生成参数（新建项目自动初始化）
- 内嵌 Swagger API 文档（springdoc）
- 用例详情弹窗 → 大抽屉
- 侧边栏项目内二级导航 + 顶栏面包屑

### Out of scope

- 安全、并发、性能

## 三、功能详情

### 3.1 仪表盘

- 后端 `GET /api/stats/overview`：项目数/用例数/执行次数/通过率/平均覆盖率/类型分布/各项目覆盖率
- 前端 `/dashboard`：统计卡 + 类型分布饼图 + 项目覆盖率柱状图

### 3.2 默认生成参数

- 后端 `GET/PUT /api/settings/generation-params`（SystemSetting 存储）
- 新建项目时初始化默认参数
- 前端设置页新增"默认生成参数"区

### 3.3 API 文档

- pom 引入 springdoc-openapi；设置页"API 文档"按钮打开 `/swagger-ui/index.html`

### 3.4 用例详情抽屉

- TestCaseList 用例详情从 el-dialog 升级为 el-drawer（62% 宽）

### 3.5 导航

- 侧边栏新增"仪表盘"入口；项目内页面显示"当前项目"二级导航
- 顶栏面包屑（项目列表 → 项目详情 → 子页面）

## 四、验收标准

1. 仪表盘数据正确、图表渲染正常
2. 默认参数保存后新项目初始化生效
3. Swagger UI 可访问
4. 抽屉、二级导航、面包屑正常
5. mvn test + npm run build 通过
