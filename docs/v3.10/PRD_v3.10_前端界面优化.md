# PRD v3.10 — 前端界面优化（视觉升级）

**版本**：v3.10
**基线**：v3.9
**日期**：2026-08-12
**主题**：前端界面整体视觉升级——全局设计系统 + 顶部导航 + 项目卡片 + 项目详情流程化 + 用例列表信息重组

---

## 一、迭代背景与痛点

系统功能已迭代到 v3.9，覆盖 PRD 驱动、流式生成、树状用例、XMind、执行回放等完整能力，但界面仍停留在"能用"阶段：

1. **全局样式未生效**：`src/styles/index.scss` 中沉淀的设计规范从未被入口文件引入，属于死代码，页面只能依赖各组件零散的 scoped 样式，观感不一致。
2. **顶部导航简陋**：蓝色渐变头部仅有两个文字链接，无图标、无层级、无氛围感，与"AI 驱动"的产品定位不匹配。
3. **项目列表单调**：卡片只有文字 + 标签，缺少状态视觉区分与信息层级。
4. **项目详情操作杂乱**：7 个操作按钮平铺一行，用户无法直观感知"创建 → 分析 → 生成 → 脑图"的流程进度。
5. **用例列表信息过载**：头部 9+ 个按钮一字排开、统计卡千篇一律（灰底数字）、树状模块行缺少视觉引导。

## 二、范围

### In scope

- 建立全局设计系统（主题色、背景、卡片、滚动条、通用工具类）并接入入口
- 顶部导航视觉升级（渐变 Logo、图标导航、active 状态）
- 项目列表卡片重设计（状态色条 + 图标头像 + 信息层级）
- 项目详情新增流程步骤条（创建 → 分析 → 生成 → 脑图），操作按钮分组
- 用例列表：统计卡升级（图标 + 渐变色）、工具栏分组、树状模块行美化
- 自定义 SVG favicon

### Out of scope

- 不改动任何后端接口、数据模型与业务逻辑
- 不改动路由结构、组件 props/emit 契约
- 不做暗色主题（留待后续迭代）
- 不引入新的 UI 组件库（继续使用 Element Plus）

## 三、功能详情

### 3.1 全局设计系统（styles/index.scss 接入并升级）

- 通过 CSS 变量覆盖 Element Plus 主题色（primary → 靛蓝 #4C6FFF 系）
- body 背景改为柔和渐变 + 装饰性光晕，提升整体质感
- 卡片统一圆角（12px）、边框、阴影与 hover 浮起效果
- 页面标题加左侧渐变色条，建立一致的标题视觉
- 保留并增强原有工具类（flex / mt-* / status-tag / empty-state 等），确保既有页面不回归

### 3.2 顶部导航（App.vue）

- 深靛蓝渐变头部 + 装饰光斑，Logo 图标升级为渐变圆角块 + 发光效果
- 导航项增加图标（项目列表 / 系统设置），active 为圆角胶囊高亮

### 3.3 项目列表（ProjectList.vue）

- 卡片顶部按状态显示彩色渐变条（创建=灰 / 分析中=橙 / 已完成=绿 / 失败=红）
- 卡片头部：状态色渐变图标头像 + 项目名 + 状态标签
- 路径行：文件夹图标 + 源码路径，footer 显示创建时间与删除操作

### 3.4 项目详情（ProjectDetail.vue）

- 基本信息卡保留 descriptions，增加状态横幅式展示
- 新增流程步骤条：创建项目 → 代码分析 → 用例生成 → 脑图导出，按项目状态自动高亮
- 操作按钮按"主线操作 / 查看操作"分组展示，逻辑与禁用条件完全不变

### 3.5 用例列表（TestCaseList.vue）

- 统计卡升级：总计/正向/异常/边界/数据 各配图标 + 渐变底色 + 语义色数字
- 工具栏按语义分组：生成区 / 批量区 / 用例区，组间分隔线，小屏自动换行
- 树状表格：模块行加文件夹图标 + 数量徽标，表头浅色底，行 hover 提升
- 流式生成面板、覆盖率面板样式微调

### 3.6 其他

- 新增 `frontend/public/favicon.svg` 并在 index.html 引用，替换默认 vite 图标
- 脑图预览页统计卡自动继承全局统计卡样式

## 四、验收标准

1. `npm run build` 构建成功，无新增警告
2. 所有既有按钮/表单/表格功能保持不变（不改变任何 API 调用与数据流）
3. 项目列表、项目详情、用例列表三个页面在浏览器中视觉明显提升
4. 小屏（≤768px）下工具栏与统计卡不破版
5. 后端无任何代码改动，`mvn compile` 通过

## 五、风险与规避

| 风险 | 影响 | 规避 |
|---|---|---|
| 全局样式与 scoped 样式冲突 | 部分页面样式错乱 | 保留原工具类名与语义；全局只改通用类，组件内部用 scoped 覆盖 |
| 按钮/标签丢失功能 | 操作不可用 | 只改 class 与布局容器，不改绑定与事件 |
| 表格树结构样式回归 | 模块分组显示异常 | 仅增强 module-row 样式，不改 treeData 逻辑 |
