  background: #f2f5fb radial-gradient(...) ;       // 柔和渐变背景

### 2. 顶部导航（App.vue）

- 头部保持 `el-header` 布局，视觉升级为深靛蓝渐变 + 光斑装饰
- Logo 图标：渐变圆角块 + 文字发光；导航项加图标与胶囊 active 态
- 无 template 结构变化，仅 class 与样式重写

### 3. 项目列表（ProjectList.vue）

- 卡片结构新增：状态渐变条（`.project-accent`）、图标头像（`.project-avatar`）
- 复用全局 `.project-card`，scoped 样式重写卡片内布局
- 事件绑定（`goDetail` / `handleDelete`）与数据流不变

### 4. 项目详情（ProjectDetail.vue）

- 新增 `el-steps` 流程步骤条：创建项目 → 代码分析 → 用例生成 → 脑图导出
- `activeStep` 计算属性由 `project.status` 推导：

```js
const activeStep = computed(() => {
  const s = project.value?.status
  if (s === 'created') return 1        // 创建完成，分析为下一步
  if (s === 'analyzing') return 1
  if (s === 'analyzed') return 2       // 分析完成，生成为下一步
  if (s === 'generating') return 2
  if (s === 'completed') return 4      // 全部完成（> 3 使所有步骤 finish）
  if (s === 'failed') return 1         // 失败回到分析阶段
  return 1
})
```

- 操作按钮仅分组（主线操作 / 查看操作），禁用条件、点击函数全部保持不变

### 5. 用例列表（TestCaseList.vue）

- 统计卡：`stat-card` 增加 `stat-icon`（Files/CircleCheck/CircleClose/Aim/Coin）与语义色渐变
- 工具栏：按钮包进三个 `.tb-group`（生成区 / 批量区 / 用例区），组间 1px 分隔线
- 树状表格：`.module-row` 增加文件夹图标（`FolderOpened`）与数量徽标，表头浅色底
- 所有按钮的 `@click`、`v-if`、`:disabled` 条件不变

### 6. favicon

- 新增 `frontend/public/favicon.svg`（渐变圆角方块 + AI 字样），`index.html` 引用 `/favicon.svg`
