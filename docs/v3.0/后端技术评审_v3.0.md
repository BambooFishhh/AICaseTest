# 后端技术评审 v3.0 — PRD 驱动流程改造

**版本**: v3.0
**基线**: v2.9
**日期**: 2026-08-10
**一旦确定尽量不要轻易改动**

---

## 1. 改动总览

将创建项目流程从"代码路径必填"改为"代码路径可选"，并在生成用例时增加 PRD/代码分析至少一项的前置校验。后端生成链路（OrchestratorAgent/TestGeneratorAgent）v1.10 已支持纯 PRD 驱动，无需改动。

## 2. 改动点

### 2.1 `dto/CreateProjectRequest.java` — sourcePath 改为可选

```java
// 改造前
@NotBlank
private String sourcePath;

// 改造后：移除 @NotBlank，保留默认值
private String sourcePath;
```

### 2.2 `service/ProjectService.java` — createProject 跳过空路径校验

```java
// 改造前（L66-69）
File path = new File(req.getSourcePath());
if (!path.exists()) {
    throw BusinessException.pathNotFound("源码路径不存在: " + req.getSourcePath());
}

// 改造后：sourcePath 为空时跳过校验
if (req.getSourcePath() != null && !req.getSourcePath().isBlank()) {
    File path = new File(req.getSourcePath());
    if (!path.exists()) {
        throw BusinessException.pathNotFound("源码路径不存在: " + req.getSourcePath());
    }
}
```

sourceType 为 "none"（无代码）时 sourcePath 为空，跳过校验。其余逻辑不变。

### 2.3 `service/TestCaseService.java` — runGenerate 前置校验

在 `orchestratorAgent.generate` 调用前（L87 之前）增加校验：

```java
// v3.0: 前置校验——PRD 和代码分析至少一项
Project project = projectRepository.findById(projectId)
        .orElseThrow(() -> new IllegalArgumentException("项目不存在: " + projectId));
boolean hasPrd = project.getPrdContent() != null && !project.getPrdContent().isBlank();
CodeAnalysis analysis = codeAnalysisRepository.findByProjectId(projectId).orElse(null);
boolean hasAnalysis = analysis != null && "completed".equals(analysis.getStatus());
if (!hasPrd && !hasAnalysis) {
    throw new IllegalStateException("请先输入 PRD 或完成代码分析，至少需要一项才能生成用例");
}
```

TestCaseService 已注入 `projectRepository` 和 `codeAnalysisRepository`，无需新增依赖。

## 3. 文件变更清单

| `dto/CreateProjectRequest.java` | 修改 | 移除 sourcePath 的 @NotBlank |
| `service/ProjectService.java` | 修改 | createProject 在 sourcePath 为空时跳过路径存在校验 |
| `service/TestCaseService.java` | 修改 | runGenerate 前置校验 PRD/代码分析至少一项 |

## 4. API 契约变化

`POST /api/projects` 创建项目接口：
- `sourcePath` 从必填变为可选
- 新增 `sourceType: "none"` 表示无代码（纯 PRD）项目

其余接口无变化。

## 5. 向后兼容

- 历史项目（有 sourcePath）不受影响，仍可正常分析
- 历史项目无 PRD 但有代码分析的，生成用例校验通过（hasAnalysis=true）
- 历史项目既无 PRD 也无代码分析的，点生成用例会被新校验拦截，提示先输入 PRD
