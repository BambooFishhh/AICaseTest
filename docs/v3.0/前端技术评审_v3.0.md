# 前端技术评审 v3.0 — PRD 驱动流程改造

**版本**: v3.0
**基线**: v2.9
**日期**: 2026-08-10
**一旦确定尽量不要轻易改动**

---

## 1. 改动总览

将创建项目表单的"代码路径"从必填改为可选，来源类型新增"无代码（纯 PRD）"选项；项目详情页调整布局，PRD 面板上提到操作区上方，"开始分析"按钮在无代码路径时禁用。

## 2. 改动点

### 2.1 `views/ProjectCreate.vue` — 创建表单改造

#### Template 改动

来源类型新增"无代码（纯 PRD）"选项，项目路径改为条件显示：

```vue
<el-form-item label="来源类型" prop="sourceType">
  <el-select v-model="form.sourceType" placeholder="请选择来源类型">
    <el-option label="本地路径" value="local_path" />
    <el-option label="Git 地址" value="git_url" />
    <el-option label="无代码（纯 PRD）" value="none" />
  </el-select>
</el-form-item>
<el-form-item v-if="form.sourceType !== 'none'" label="项目路径" prop="sourcePath">
  <el-input
    v-model="form.sourcePath"
    placeholder="请输入项目源码路径"
  />
</el-form-item>
```

#### Script 改动

`sourcePath` 校验改为条件必填（仅非 "none" 时必填）：

```js
const form = reactive({
  name: '',
  sourceType: 'local_path',
  sourcePath: ''
})

// 动态校验：sourceType 为 none 时不校验 sourcePath
const rules = {
  name: [
    { required: true, message: '请输入项目名称', trigger: 'blur' },
    { min: 1, max: 200, message: '长度在 1 到 200 个字符', trigger: 'blur' }
  ],
  sourcePath: [
    {
      validator: (rule, value, callback) => {
        if (form.sourceType !== 'none' && (!value || !value.trim())) {
          callback(new Error('请输入项目路径'))
        } else {
          callback()
        }
      },
      trigger: 'blur'
    }
  ]
}
```

选"无代码"时清空 sourcePath：

```js
watch(() => form.sourceType, (newType) => {
  if (newType === 'none') {
    form.sourcePath = ''
  }
})
```

### 2.2 `views/ProjectDetail.vue` — 布局调整

#### Template 改动

PRD 面板上提到操作区上方；操作区按钮顺序与禁用逻辑调整：

```vue
<!-- v3.0: PRD 面板上提为主线 -->
<PrdPanel v-if="project" :project-id="projectId" />

<el-card class="action-card">
  <template #header>操作</template>
  <div class="action-buttons">
    <!-- v3.0: 生成用例作为主操作 -->
    <el-button type="primary" :disabled="!canGenerate" @click="handleGenerate">生成用例</el-button>
    <!-- v3.0: 开始分析标注为可选上下文，无代码路径时禁用 -->
    <el-button
      type="primary"
      :disabled="!canAnalyze"
      :title="!hasSourcePath ? '未配置代码路径，可直接用 PRD 生成用例' : ''"
      @click="handleAnalyze"
    >开始分析<span v-if="!hasSourcePath">（可选）</span></el-button>
    <el-button type="primary" :disabled="!canMindmap" @click="handleMindmap">生成脑图</el-button>
    <el-button :disabled="!canDownload" @click="handleDownload">下载脑图</el-button>
    <el-button :disabled="!canViewAnalysis" @click="goAnalysis">查看分析</el-button>
    <el-button :disabled="!canViewTestcases" @click="goTestcases">查看用例</el-button>
    <el-button @click="goMindmap">脑图预览</el-button>
  </div>
</el-card>
```

#### Script 改动

新增 `hasSourcePath` 计算属性，调整 `canAnalyze` 逻辑：

```js
// v3.0: 是否有代码路径
const hasSourcePath = computed(() => {
  return !!project.value?.sourcePath && project.value.sourcePath.trim() !== ''
})

// 开始分析：需要有代码路径（v3.0 改为依赖 hasSourcePath）
const canAnalyze = computed(() => {
  return hasSourcePath.value && project.value?.status !== 'analyzing'
})
```

## 3. 数据流

```
创建项目（sourcePath 可选）
    ↓
项目详情页
    ↓ PRD 面板（主线，上提）
    ↓ 操作区
        ├─ 生成用例（主操作，后端校验 PRD/代码分析至少一项）
        └─ 开始分析（可选，无 sourcePath 时禁用）
```

## 4. 向后兼容

- 历史项目（有 sourcePath）：所有按钮行为不变
- 新项目（无 sourcePath）："开始分析"禁用，"生成用例"仍可用（需先填 PRD）

## 5. 测试验证

```powershell
cd frontend; npm run build
```

预期：构建成功。

手测：
1. 创建项目选"无代码（纯 PRD）"→ 项目路径输入框隐藏 → 创建成功
2. 创建项目选"本地路径"→ 项目路径必填校验生效
3. 项目详情页：PRD 面板在操作区上方
4. 无代码路径的项目：开始分析按钮禁用，hover 有提示
5. 无 PRD 无代码分析点生成用例 → 报错提示
