# 前端技术评审 v4.2

**版本**：v4.2，一旦确定尽量不要轻易改动
**日期**：2026-08-13

## 变更点

### 1. BatchResult.vue

- 统计卡新增"排队中（queued）""已取消（cancelled）"
- 运行中/排队中时显示"取消批次"按钮 → `cancelBatch(batchId)` → 刷新
- status 映射补充 `cancelled: 已取消`；completed = passed+failed+cancelled

### 2. ExecutionResult.vue / ExecutionHistory.vue

- 状态映射补充 `cancelled`（已取消，info）

### 3. api/execution.js

- 新增 `cancelBatch(batchId)`

## 数据流

批次页轮询 getBatch → queued/running/cancelled 计数 + 记录状态；取消 → cancelBatch → 刷新。
