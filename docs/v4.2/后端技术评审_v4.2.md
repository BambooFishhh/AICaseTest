# 后端技术评审 v4.2

**版本**：v4.2，一旦确定尽量不要轻易改动
**日期**：2026-08-13

## 变更点

### 1. 线程池参数化 + 独立执行池（AsyncConfig）

```yaml
app:
  executor:
    analysis:   { core: 2, max: 4, queue: 20 }
    generation: { core: 2, max: 4, queue: 20 }
    execution:  { core: 2, max: 8, queue: 200 }   # 新增，批量执行专用
    project-execution-max: 3                        # 每项目执行并发配额
```

`runAgentAsync`/`runAsync` 改挂 `executionExecutor`。

### 2. 项目级执行并发配额（ProjectExecutionLimiter）

`ConcurrentHashMap<String, Semaphore>`，permit = 配额；执行任务启动时 acquire、结束 release。

### 3. 批量排队与取消（ExecutionService）

- 批量记录初始状态 `pending`（排队中），任务真正启动（acquire 后）置 `running`
- `getBatchStatus` 增加 `queued`/`cancelled` 计数
- `cancelBatch(batchId)`：pending → cancelled（未开始）；running → 置执行取消标志，步骤循环检查点停止
- 新增 `executionCancellations` 标志表（仿 generation cancellationFlags）
- 幂等：单条执行前检查该用例是否已有 running 记录，有则拒绝

### 4. 接口

- `POST /api/batches/{batchId}/cancel`（认证 + 归属校验）
