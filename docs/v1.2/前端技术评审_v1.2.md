## 一、v1.2 前端改动点

### 1.1 TestCaseList.vue — 覆盖率面板

文件：`frontend/src/views/TestCaseList.vue`

在现有统计卡片（stats-bar）下方新增覆盖率面板：

```html
<el-card v-if="coverage" class="coverage-card">
  <template #header>覆盖率度量</template>
  <el-row :gutter="16">
    <el-col :span="12">
      <div class="coverage-item">
        <div class="coverage-label">状态转换覆盖率</div>
        <el-progress
          :percentage="Math.round(coverage.stateTransition.rate * 100)"
          :color="coverageColor(coverage.stateTransition.rate)"
        />
        <div class="coverage-detail">
          {{ coverage.stateTransition.covered }} / {{ coverage.stateTransition.total }}
        </div>
      </div>
    </el-col>
    <el-col :span="12">
      <div class="coverage-item">
        <div class="coverage-label">接口覆盖率</div>
        <el-progress
          :percentage="Math.round(coverage.apiEndpoint.rate * 100)"
          :color="coverageColor(coverage.apiEndpoint.rate)"
        />
        <div class="coverage-detail">
          {{ coverage.apiEndpoint.covered }} / {{ coverage.apiEndpoint.total }}
        </div>
      </div>
    </el-col>
  </el-row>
</el-card>
```

数据来源：`listTestCases` 响应新增 `coverage` 字段，`loadList()` 中提取。

### 1.2 TestCaseList.vue — 表格新增质量列

在 el-table 中新增"质量"列（位于优先级列后）：

```html
<el-table-column label="质量" width="120">
  <template #default="{ row }">
    <el-progress
      v-if="row.qualityScore > 0"
      :percentage="row.qualityScore"
      :color="qualityColor(row.qualityScore)"
      :stroke-width="14"
      :show-text="true"
    />
    <span v-else class="text-muted">未评分</span>
  </template>
</el-table-column>
```

### 1.3 TestCaseList.vue — script 改动

新增响应式变量：
```js
const coverage = ref(null)
```

`loadList()` 提取 coverage：
```js
coverage.value = data.coverage || null
```

新增辅助方法：
```js
function coverageColor(rate) {
  if (rate >= 0.8) return '#67c23a'
  if (rate >= 0.5) return '#e6a23c'
  return '#f56c6c'
}
function qualityColor(score) {
  if (score >= 80) return '#67c23a'
  if (score >= 50) return '#e6a23c'
  return '#f56c6c'
}
```

### 1.4 TestCaseCard.vue — 质量分展示

文件：`frontend/src/components/TestCaseCard.vue`

在元信息 el-descriptions 中新增质量分项（执行状态后）：

```html
<el-descriptions-item label="质量评分">
  <el-progress
    v-if="testCase.qualityScore > 0"
    :percentage="testCase.qualityScore"
    :color="qualityColor(testCase.qualityScore)"
    :stroke-width="14"
  />
  <span v-else class="text-muted">未评分</span>
</el-descriptions-item>
```

新增 `qualityColor` 方法（与列表页一致）。

## 二、数据流

```
后端 listTestCases 响应（新增 coverage + 每条 testCase.qualityScore）
  → api/testcase.js（透传，无需改动）
  → TestCaseList loadList()（提取 coverage + 透传 qualityScore）
  → 覆盖率面板渲染 coverage
  → 表格质量列渲染 row.qualityScore
  → TestCaseCard 渲染 testCase.qualityScore
```

无新增 API 调用。

---

## 三、向后兼容

| 场景 | 处理 |
|------|------|
| coverage 为 null（旧响应） | `v-if="coverage"` 不渲染面板 |
| qualityScore 为 0/undefined | 显示"未评分" |
| 旧用例无 qualityScore | 兜底显示"未评分" |
