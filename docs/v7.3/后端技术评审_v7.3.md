### 2.1 L1 — per-request 取消（LlmService）

现状问题：`activeStream` 只存最后一个流的 Disposable，`streamCancelled` 是全局布尔——A 取消 set(true) 后 B 的 `doOnNext` 立即抛 `GenerationCancelledException`。

```java
private LlmCallResult chatStreamingWithUsage(..., BooleanSupplier cancelSignal, boolean enableThinking) {
    ...
    // 每轮 attempt 内：局部 Disposable，无全局注册
    Disposable disposable = flux.doOnNext(response -> {
        if (cancelSignal != null && cancelSignal.getAsBoolean()) {
            throw new GenerationCancelledException("用户取消生成");
        }
        ...
    }).doOnError(errorRef::set)
      .doOnComplete(done::countDown)
      .doOnCancel(done::countDown)
      .subscribe();
    try {
        while (!done.await(200, TimeUnit.MILLISECONDS)) {

                disposable.dispose();
                throw new GenerationCancelledException("用户取消生成");
            }
        }
    } finally {
        if (!disposable.isDisposed()) {
            disposable.dispose();
        }
    }
    if (cancelSignal != null && cancelSignal.getAsBoolean()) {
        throw new GenerationCancelledException("用户取消生成");
    }
    ...
}
```

### 2.2 L2 — 按通道熔断（LlmCircuitBreaker）

```java
@Component
public class LlmCircuitBreaker {
    public static final String CHANNEL_TEXT = "text";
    public static final String CHANNEL_MULTIMODAL = "multimodal";

    private static class CircuitState {
        final AtomicInteger consecutiveFailures = new AtomicInteger();
        volatile long openedUntil = 0;
    }
    private final ConcurrentHashMap<String, CircuitState> channels = new ConcurrentHashMap<>();

    private CircuitState state(String channel) {
        return channels.computeIfAbsent(channel == null || channel.isBlank()
                ? CHANNEL_TEXT : channel, k -> new CircuitState());
    }

    public boolean isOpen(String channel) { return System.currentTimeMillis() < state(channel).openedUntil; }
    public boolean allowRequest(String channel) { return !isOpen(channel); }
    public void onSuccess(String channel) { CircuitState s = state(channel); s.consecutiveFailures.set(0); s.openedUntil = 0; }
    public void onFailure(String channel) {
        CircuitState s = state(channel);
        if (s.consecutiveFailures.incrementAndGet() >= failureThreshold) {
            s.openedUntil = System.currentTimeMillis() + openSeconds * 1000;
        }
    }
    // 兼容旧签名（默认 text 通道，现有测试 LlmCircuitBreakerTest 不动）
    public boolean isOpen() { return isOpen(CHANNEL_TEXT); }
    public boolean allowRequest() { return allowRequest(CHANNEL_TEXT); }
    public void onSuccess() { onSuccess(CHANNEL_TEXT); }
    public void onFailure() { onFailure(CHANNEL_TEXT); }
}
```

LlmService 调用侧：
- chat / chatStreaming / chatJson → `"text"`；
- chatWithImage → `"multimodal"`；
- 失败收口处：`if (LlmRetryPolicy.isRetryable(lastException)) { breaker.onFailure(channel); }`——4xx 配置类错误（非可重试）不计入。

### 2.3 L5 — SPA 生效判断最小版（ExecutionAgent）

```java
// 点击后等待 SPA 异步渲染（最小版 800ms）
private static final long EFFECT_CHECK_DELAY_MS = 800;

// 无 LLM 时的三指纹比较
static boolean pageChanged(Map<String, String> before, Map<String, String> after) {
    if (before == null || after == null) {
        return false;  // 状态获取失败时保守判"未生效"（与旧行为一致）
    }
    return !before.getOrDefault("url", "").equals(after.getOrDefault("url", ""))
            || !before.getOrDefault("title", "").equals(after.getOrDefault("title", ""))
            || !before.getOrDefault("textSnippet", "").equals(after.getOrDefault("textSnippet", ""));
}

private boolean askLlmIfEffective(Map<String, String> statusBefore, Map<String, String> statusAfter, String action) {
    if (!llmService.isConfigured()) {
        return pageChanged(statusBefore, statusAfter);  // L5: URL→三指纹
    }
    // LLM 路径：注入 before/after textSnippet 作为证据（E6 最小版雏形）
    String systemPrompt = "你是测试执行Agent。请根据操作前后页面文本快照判断操作是否生效。"
            + "文本快照出现差异（新元素/提示/列表变化）即视为生效。"
            + "返回 JSON：{\"effective\": true/false, \"reason\": \"...\"}";
    String userPrompt = "步骤: " + action
            + "\n操作前URL: " + ...
            + "\n操作后URL: " + ...
            + "\n操作后标题: " + ...

            + "\n操作后页面文本快照: " + truncate(statusAfter.get("textSnippet"), 300)
            + "\n请判断操作是否生效：";
    ...
}
```

### 2.4 L8 — 截断检测与抢救（StreamingTestCaseParser）

```java
public class StreamingTestCaseParser {
    private boolean truncated = false;
    private int recovered = 0;

    /** 流结束后调用：检测未闭合对象，尝试局部补全抢救最后一条。返回是否发生截断。 */
    public boolean finish() {
        if (braceDepth > 0 && objStart >= 0) {
            truncated = true;
            String text = buffer.toString();
            String tail = text.substring(objStart);
            String completed = completeTruncated(tail);
            if (completed != null) {
                try {
                    parseAndCallback(completed);
                    recovered = 1;
                    log.warn("流式响应截断，已局部补全抢救最后一条用例（部分字段可能缺失）");
                } catch (Exception e) {
                    log.warn("流式响应截断且补全解析失败，最后一条用例丢失: {}", e.getMessage());
                }
            } else {
                log.warn("流式响应截断（maxTokens={}），最后一条用例不完整已丢弃", "…");
            }
        }
        return truncated;
    }

    /**
     * 截到最后一个字符串外逗号（不含），按深度栈补齐 ']' '}'。
     * 无安全截断点（如截断发生在 title 字符串中间且无前导逗号）返回 null。
     */
    private String completeTruncated(String tail) {
        // ① 字符串感知扫描：记录最后一个字符串外的 ',' 位置 lastComma；
        //    同时维护括号栈（'{'/'[' push，'}'/']' pop）
        // ② 截断点 cut = lastComma（截掉尾逗号）；无逗号则 cut = tail 末尾字符串外位置
        // ③ 取 partial = tail.substring(0, cut)，扫描字符串外括号栈，逆序补闭合符
        // ④ 生成 "partial + 闭合符序列"
    }

    public boolean isTruncated() { return truncated; }
    public int getRecovered() { return recovered; }
}
```

### 2.6 G20 层2 — UiLanguageLinter（新增类）

```java
package com.testagent.agent;

/** v7.3(G20层2): 预期结果 UI 语言 lint。只标记不删改。 */
public final class UiLanguageLinter {

    // 规则1: HTTP 状态码形态（"返回401" / "响应码：403" / "HTTP 500错误"）
    private static final Pattern HTTP_CODE = Pattern.compile(
            "(返回|响应|状态码|HTTP|http)[^\\d]{0,4}[45]\\d{2}|[45]\\d{2}\\s*(错误|状态码)");
    // 规则2: 机器常量（全大写下划线 ≥2 段，如 PENDING_PAYMENT / ERROR_CODE）
    private static final Pattern UPPER_CONST = Pattern.compile("\\b[A-Z]{2,}(?:_[A-Z0-9]+)+\\b");
    // 规则3: 后端字段赋值（errorMsg=xxx / status=xxx / code=xxx）
    private static final Pattern FIELD_ASSIGN = Pattern.compile(
            "\\b(errMsg|errorMsg|status|code|message|respCode|errCode)\\s*[:=]\\s*\\S+");

    public static List<String> lint(TestCase tc) {
        // ① expectedResults 每条
        // ② structuredSteps 中 type ∈ {ui_action, state_assert} 的 expected
        // 命中 → "expectedResults[0] '接口返回400' 疑似HTTP状态码，应写页面可感知现象"
        // 保守原则：api_call 步骤 expected 不 lint（接口语义合法）
    }
}
```
