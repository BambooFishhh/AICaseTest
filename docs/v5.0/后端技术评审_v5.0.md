# 后端技术评审 v5.0：数据层准备

> 版本 v5.0，一旦确定尽量不要轻易改动。

## 1. 变更点

### 1.1 Maven 依赖

```xml
<dependency>
    <groupId>org.flywaydb</groupId>
    <artifactId>flyway-core</artifactId>
</dependency>
<dependency>
    <groupId>org.flywaydb</groupId>
    <artifactId>flyway-mysql</artifactId>
</dependency>
<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <scope>runtime</scope>
</dependency>
```

版本由 Spring Boot 3.2.5 BOM 管理。

### 1.2 配置变化

`application.yml`（默认 H2）：

```yaml
spring:
  flyway:
    enabled: false
```

新增 `application-mysql.yml`：

```yaml
spring:
  datasource:
    url: ${MYSQL_URL:jdbc:mysql://localhost:3308/aicasetest?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true}
    driver-class-name: com.mysql.cj.jdbc.Driver
    username: ${MYSQL_USERNAME:aicasetest}
    password: ${MYSQL_PASSWORD:aicasetest123}
  jpa:
    hibernate:
      ddl-auto: none
  flyway:
    enabled: true
    locations: classpath:db/migration/mysql
    baseline-on-migrate: true
```

`application-prod.yml` 改为 `spring.profiles.include: mysql`，容器生产环境走 MySQL。

### 1.3 Flyway V1 基线

`backend/src/main/resources/db/migration/mysql/V1__init_schema.sql`：

- 覆盖全部 13 张业务表，字符集 `utf8mb4`。
- 与 JPA 实体字段一一对应：projects、test_cases、test_case_versions、execution_record、execution_step、state_machines、code_analysis、mindmaps、test_suites、users、project_groups、group_members、system_settings。
- 建立必要的唯一约束与索引：users.username、test_case_versions 查询索引、execution_record 项目/批次索引、state_machines 项目索引等。

## 2. 文件变更清单

| 文件 | 变更 | 说明 |
|---|---|---|
| backend/pom.xml | 新增 flyway-core / flyway-mysql / mysql-connector-j | 数据库迁移与 MySQL 驱动 |
| backend/src/main/resources/application.yml | 新增 spring.flyway.enabled=false | H2 开发环境不启用 Flyway |
| backend/src/main/resources/application-mysql.yml | 新增 | MySQL profile |
| backend/src/main/resources/application-prod.yml | 改为 include mysql | 生产走 MySQL |
| backend/src/main/resources/db/migration/mysql/V1__init_schema.sql | 新增 | MySQL 基线 schema |
| docker-compose.yml | 新增 aicasetest-mysql | 数据库容器 |

## 3. API 契约变化

无。本版本不修改任何 REST API。

## 4. 向后兼容性

- 默认 H2 profile 行为不变，存量 `data/appdb` 可继续使用。
- 新增依赖不影响旧接口。
- MySQL profile 仅在显式激活时生效。

## 5. 测试验证方案

- `mvn compile` 验证依赖与编译。
- `mvn test` 验证现有 2 个单测。
- 本地启动 `--spring.profiles.active=mysql` 连接空 MySQL，确认 Flyway 建表成功、JPA 无缺表报错。
- `npm run build` 回归前端。
