# 前端技术评审 v5.0：数据层准备

> 版本 v5.0，一旦确定尽量不要轻易改动。

## 1. 变更点

本版本为纯后端/部署基建改动，**前端无代码变更**。

- 不新增页面。
- 不修改路由、组件、API 封装。
- 数据源切换对前端完全透明，API 契约不变。

## 2. 数据流

前端仍通过 `/api/**` 访问后端，后端内部数据源从 H2 / MySQL 切换不影响 axios 层。

## 3. 向后兼容性

- 登录态、项目列表、用例生成/执行等所有现有流程不受影响。
- 前端构建依赖不变。

## 4. 测试验证方案

- `npm run build` 确认构建成功。
- 人工回归：项目列表、项目详情、用例列表正常加载。
