## 一、变更点

### 1.1 告警规则（9.5.5）

`monitoring/prometheus/alerts.yml` 新增组 aicasetest-generation-quality：

| 告警 | 表达式 | 持续 | 级别 |
|---|---|---|---|
| AICaseTestVectorPendingOpsStuck | `vector_pending_ops_size > 0` | 1h | warning |
| AICaseTestParseSkipRatioHigh | `rate(gen_parse_skipped_total[10m]) / clamp_min(rate(gen_cases_generated_total[10m]) + rate(gen_parse_skipped_total[10m]), 0.001) > 0.3` | 10m | warning |
| AICaseTestExecutorRejected | `increase(executor_rejected_total[5m]) > 0` | 即时 | critical |

promtool check rules SUCCESS（该文件现共 9 条规则）。既有 rule_files 挂载不变（compose 整目录挂 /etc/prometheus）。

### 1.2 看板（9.5.5）

- `generation-quality.json`（uid aict-gen-quality）：轮次结果分布 / 产出与解析跳过 / 跳过率健康线(阈值 30% 红) / 契约违规·重试·截断 / RAG P95 与均值延迟。
- `data-consistency.json`（uid aict-consistency）：补偿积压 / 对账漂移率 Gauge(阈值 2%) / Milvus 失败与截断。
- 数据源走 `${DS_PROMETHEUS}` 模板变量，兼容既有 provisioning datasources.yml；目录级自动 provisioning（dashboards.yml path 不变）。

### 1.3 评测体系（9.5.7–9.5.9）

**数据集**（eval/datasets/{small,medium,large}/）：prd.md（合成脱敏）、expected.json（requirements/endpoints/p0Points/requirementIdMap 双口径召回标注）、fixture-response.json（chatResponse 夹具 + tokens/durationMs 登记值；故意畸形条目以 `"__malformed__": true` 显式标注，剔除健康线分母）。

**`backend/src/main/java/com/testagent/eval/EvalRunner.java`**（独立 main，无 Spring 依赖）：

- 回放：parseItems 逐段容错（非对象条目计畸形）→ 单条包数组过 LlmSchemaValidator(test-cases) → structurePass/parseSkipped
- 召回双口径：用例标题包含期望名 OR 用例 requirementIds ∩ expected.requirementIdMap[期望名]
- 覆盖：coverageRefs.endpointIds 并集 ∩ expected.endpoints
- 报告：`{mode:"mock", generatedAt, gitSha, healthLine, overall, datasets}` → eval/results/{yyyyMMdd-HHmmss}-{sha}.json
- compare 子命令：四指标 delta + REGRESSION 判定（跳过率反向），回归退出码 2

**流程固化（9.5.9）** 写入 eval/README.md：prompt 模板/预算参数（app.prd.*、app.generation.*、llm.max-*）任何改动必须先跑评测 + compare 无回归才可合入；真实模式（--live 预留）用于生成质量复核。
