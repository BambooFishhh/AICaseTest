# 后端技术评审 v8.3 — 覆盖率口径重构

> 对应 PRD：PRD_v8.3_覆盖率口径重构.md
> 一旦确定尽量不要轻易改动

## 1. 现状调用链

```
CoverageService.getCoverageMatrix(projectId)          ← 分母=全部 SM 转换（v7.8 双栏 planned/executed）
CoverageService.uncoveredEndpoints(projectId)         ← 分母=最新分析接口全集
TestCaseService.calculateCoverage / buildCoverageForReview ← 同全量口径
StatsController.projectCoverage                       ← Dashboard 逐项目覆盖率
```

## 2. 改造设计

### 2.1 CoverageService

注入 `ScopeSlicingService` + `ScopeItemRepository`：

```java
public Map<String,Object> getCoverageMatrix(String projectId) {
    ScopeSlice slice = scopeSlicingService.loadForGeneration(projectId);
    if (slice.isEmpty()) return引导态(scoped=false, message);
    // SM 循环：仅遍历 sprintTransitionsBySmId 中的 SM；
    //   sprintKeys = transitionKeys(slice.sprint...)；每条 transition 附 inScope=sprintKeys.contains(key)
    //   planned/executed 双栏统计仅对 inScope=true 计算
    // endpoints 循环：分母 = slice.targetEndpointIds()；covered 口径不变（refs ∪ 已执行 apiEndpoints）
    // summary：现有 plannedRate/executedRate/rate 字段语义保留，分母为本期集合
    // affectedItems = itemRepository.findByDefinition... changeKind==AFFECTED 的 {itemType,itemRef,note}
}
```

- transitionKey 归一化复用 ScopeSlicingService.normalizeStateCode（from->to 小写键），与切片分类同源，杜绝两处口径漂移
- endpoint id 归一化沿用 normalizeEndpointIdForCoverage（大写+空白折叠），匹配前对 scope id 同步归一

### 2.2 uncoveredEndpoints

EMPTY → 引导态；否则 totalEndpoints = slice.targetEndpointIds，covered 计算逻辑保持（refs ∪ 已执行用例 apiEndpoints），输出差集。

### 2.3 TestCaseService.calculateCoverage / buildCoverageForReview

- 注入 ScopeSlicingService；EMPTY → `{scoped:false, stateTransition:{rate:0,...}, apiEndpoint:{rate:0,...}}`
- 非空 → 与 CoverageService 相同口径计算（转换分母=sprint 转换、接口分母=target ids）

### 2.4 StatsController.projectCoverage

逐项目调用 TestCaseService.calculateCoverage 等价口径（或直接读 coverageService 新方法）；未 scoped 项目 rate=null 输出。

## 3. API 契约变化

- `/coverage/matrix`、`/coverage/uncovered-endpoints` 响应新增顶层 `scoped`(bool)；scoped=false 时其余字段为空/提示文案——**破坏性变更**（前端同步适配）
- matrix 每个 transition 新增 `inScope`(bool)；summary 数值分母变化
- 用例列表响应内联 coverage 增加 `scoped` 字段

## 4. 向后兼容

无范围项目从"出全量数字"变为"不出数字"——产品决策已确认；前端引导文案兜底。
